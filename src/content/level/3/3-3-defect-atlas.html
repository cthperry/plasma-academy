3.3 缺陷圖鑑

⏱ 4.0 小時 🔬 A20 · A21 互動元件 ★ L3 旗艦模組
🎯 學習目標
📋 前置知識 3.1 蝕刻機制 3.2 主要蝕刻應用
⚡ 5 分鐘摘要

這是工程師最常回頭查的一章。它的價值不在「認識 18 種缺陷的名字」, 而在「看到這個症狀,下一步該做什麼實驗」。

  • 症狀 ≠ 成因。同一個症狀常常有 2–4 個可能成因, 圖鑑真正有用的欄位是「診斷區分」 —— 怎麼把它們分開。
  • ARDE 不是一個效應,是四個傳輸限制疊加:Knudsen 傳輸、 離子遮蔽、產物排出、孔底充電。A20 讓你把它們一個一個關掉。
  • 延長時間救不了 ARDE —— 窄溝槽越刻越慢, 多給的時間寬的拿走得比窄的多,差距反而拉大。
  • 充電效應是一整族缺陷的共同成因:notching、twisting、 footing、ARDE 的第四項。它們的共同前提是絕緣下層, 共同解方是脈衝電漿。
  • 每個對策都有副作用。看到只講好處的建議要提高警覺。

3.3.1 圖鑑條目的固定格式

每一條缺陷固定五個欄位,順序就是現場查閱的順序:

欄位回答什麼問題
症狀我看到的是不是這個?
物理成因為什麼會這樣?(完整因果鏈,依可能性排序)
診斷區分怎麼跟長得像的其他缺陷分開?
對策動哪個旋鈕、往哪個方向、會付出什麼代價
相關還要看哪幾條
💡 為什麼「診斷區分」才是圖鑑的價值

認出 bowing 不難 —— 側壁鼓出來,看一眼就知道。難的是 「它為什麼鼓」:是遮罩肩部被削出斜面把離子反射到中段, 還是中段的鈍化不足?兩者的對策完全不同,而剖面看起來一樣。

所以圖鑑不能只給「症狀 → 對策」的對照表。那種表會讓人動錯旋鈕, 而且因為「有時候剛好會好」,錯誤的因果會被長期保留下來。

3.3.2 深寬比與負載相關

① ARDE / RIE Lag

症狀:窄溝槽比寬溝槽淺。同時蝕刻,深度卻不同。

成因是四個獨立的傳輸限制疊在一起 —— 這是本節最重要的一句話,因為四個成因的對策各不相同:

成因物理主要對策
Knudsen 傳輸限制 自由基要在孔壁上彈很多次才到得了底,途中被吸附掉 降低自由基黏著係數
離子遮蔽 有角度分佈的離子被孔口攔截 降壓(減少鞘層碰撞 → 角度收斂)
產物排出困難 SiF₄ 出不來,佔住表面 降壓、提高抽速
孔底充電 電子角度分佈較寬,先被孔壁擋掉 → 孔底淨正電 → 排斥離子 脈衝電漿(off 期讓電子中和)
📊 A20 實測:四個成因各貢獻多少

典型條件(20 mTorr、黏著係數 0.25、連續波),五種 CD 並排, 蝕到最寬的那條達到深度 3 為止 —— ARDE 36.8 %。 把成因逐一關掉:

關掉哪一項ARDE 少掉
Knudsen 傳輸限制12.6 個百分點
孔底充電8.8 個百分點
離子遮蔽3.7 個百分點
產物排出困難1.5 個百分點

四項全部關掉時 ARDE 歸零 —— 深度差不是憑空冒出來的,就是這四項的總和。 而它們的量級差了將近十倍:先動哪個旋鈕不是隨便選的。

⚠️ 常見誤解:「刻久一點,窄的就會追上來」

正解:延長時間會讓差距拉大,不是縮小。

A20 實測(同一組參數,只改時間):

時間最寬 CD 深度最窄 CD 深度ARDE
42.371.5634.2 %
83.482.1538.1 %
164.862.9240.0 %
326.623.9240.8 %

原因很直接:速率隨深寬比持續下降,而窄溝槽的深寬比一直比寬的高。 多給的每一秒,寬溝槽都比窄溝槽多刻一些 —— 時間是站在寬溝槽那一邊的。

② Inverse RIE Lag(反向 ARDE)

症狀:窄的反而深。
成因:聚合物前驅物是大分子、黏著係數接近 1, 比自由基更進不去窄孔 → 窄孔的鈍化反而薄 → 刻得比寬孔快。
診斷意義:看到這個現象就代表製程落在高聚合區 —— 它本身就是一條線索,不只是一個缺陷。

📐 A20 在這一條的已知限制

A20 做得到「高聚合區把 ARDE 壓小」(實測 27 % → 18 %), 但做不到翻負(窄的反而更深)。

原因:模型裡聚合物在深寬比趨近 0 時供應最大, 所以在它強到足以翻轉深度排序之前,會先把最寬的溝在開口就封死 —— 那變成 etch stop(第 ⑯ 條),不是反向 ARDE。 要跨過這一步得把「離子驅動的聚合物清除」也算進去, 而那一項又會把深度依賴反轉回來,需要完整的聚合物收支。

所以 A20 的「高聚合區」預設請當成「ARDE 被壓小」來看, 不要當成反向 ARDE 的重現。這一項記在 docs/11 的待辦裡。

③④ Microloading 與 Macroloading

比較的對象成因怎麼確認
ARDE不同深寬比的圖形 傳輸限制(上面四項)換 CD 就重現
Microloading不同圖形密度的區域 局部自由基被大量消耗換密度才重現
Macroloading不同開口率的晶圓 全腔體自由基被消耗換開口率的片子就重現

三者的區別只在「比較的對象」。 這也是為什麼診斷時第一個問題永遠是 「你是拿什麼跟什麼比?」 —— 問清楚這一句,三選一就先去掉兩個。

🔬 A20 ARDE 深寬比效應

A20 把四個成因一個一個關掉
此元件建議在較大螢幕使用。

3.3.3 Profile 形狀缺陷

缺陷症狀診斷區分的關鍵
⑤ Undercut遮罩下方被橫向咬入 最寬處在最頂端(緊貼遮罩)
⑥ Bowing側壁中段向外鼓出,像個桶子 最寬處在中段 —— 量剖面最寬處的深度就能和 undercut 分開
⑦ Taper上寬下窄 側壁有明顯角度,不是局部鼓出
⑧ Notching底部界面處橫向凹口 只在陣列邊緣,而且有方向性 —— undercut 是普遍發生
⑨ Microtrenching溝底兩側各一道更深的小溝 看溝底的形狀,不是側壁
⑩ Footing底部界面處外擴的「腳」 中段正常,只有最底下沒清乾淨
⑪ TwistingHAR 孔在深處歪掉、甚至相交 要剖到深處才看得到;淺處正常
⑫ Striation側壁垂直細紋 紋路沿深度連續 → 來自遮罩邊緣粗糙度(LER)
💡 充電效應是一整族缺陷的共同成因

Notching、twisting、footing,以及 ARDE 的第四項 —— 這四個看起來完全不同, 但物理是同一個:電子的角度分佈比離子寬, 先被結構擋掉,於是絕緣的底部或孔底累積正電荷,把後續離子的軌跡推歪。

  • 共同前提:下層是絕緣體(電荷跑不掉)
  • 共同解方:脈衝電漿 —— off 期電子進得來,把累積的正電中和掉
  • 共同的確認實驗:換一片導電下層跑同一支配方。 症狀消失 → 就是充電

把這四條當成一族來記,比分開記省力得多 —— 而且在現場,認出「這是充電族」就已經把對策範圍縮到很小了。

📐 A18 輪廓模擬器在這一節的涵蓋範圍

圖鑑的診斷區分,能用 A18 親手做出來的目前有五種: 垂直、Taper、Footing、 Faceting、Etch stop,外加 ARDE 的多溝槽比較。

做不出來的三種:Undercut、Bowing、Microtrench。 不是課文寫錯,是模擬器尚未收斂 —— 目前的判別指標把 「遮罩開口變寬」同時算給 faceting 與 undercut,兩者先天分不開; bowing 與 microtrench 則卡在「溝底中央永遠比兩側快」。 技術診斷記在 docs/11。

所以這三條請以本頁的文字與 A21 的判別方法為準, 不要因為 A18 做不出來就以為現場不會發生 —— 它們是最常見的 profile 缺陷之一。

3.3.4 遮罩相關

缺陷成因後果
⑬ Faceting(肩部削角) 濺鍍產額的角度依賴(3.1.6)—— 45–70° 面被削得最快 CD 放大、遮罩過早消耗
⑭ 遮罩耗盡 選擇比不足CD 失控、圖形消失
⑮ Resist Wiggling 光阻高深寬比 + 應力 + 加熱軟化圖形倒塌

三者的對策高度重疊:降 bias、加聚合、換硬遮罩(非晶碳或金屬)。 這不是巧合 —— 它們都是「遮罩撐不住製程強度」的不同表現。

Faceting 特別值得記住,因為它把 3.1.6 的 Y(θ) 直接搬到了遮罩上:斜面比平面濺得快,所以直角的肩部會自己變成斜角, 而且一旦變成斜角就會加速擴大。

3.3.5 殘留與污染

缺陷症狀對策
⑯ Etch Stop HAR 孔蝕到一半完全停住 降聚合、加 O₂、提高離子能量、分段 recipe
⑰ 聚合物殘留 / Veil 圖形周圍一圈膜狀殘留 加 O₂ 灰化步、濕式清洗、降低鈍化強度
⑱ 金屬腐蝕 Al 線路出腔數小時後斷線、長白色生成物 強制後處理 + 等待時間管制
🔴 金屬腐蝕:唯一會在「出腔之後」持續惡化的缺陷

殘留的 Cl 遇到大氣中的濕氣生成 HCl,而 HCl 腐蝕 Al 又會釋放出更多 Cl —— 這是一個自我維持的反應。所以它不是「量到才算數」的缺陷: 出腔時量起來好好的,幾小時後才斷線。

對策必須是流程上的強制規定,不是製程參數: H₂O 電漿 / NH₃ 處理 / DI 沖洗,而且出腔到後處理的等待時間必須管制。 這一條在 A21 裡標記為高風險。

🔬 A21 缺陷診斷器

A21 症狀 → 可能成因排序 → 怎麼區分 → 動哪個旋鈕
💡 診斷器刻意不給單一答案

勾選條件只會改變成因的排序,不會把選項刪掉。 這是刻意的設計:一個看起來很篤定的答案,比一個誠實的清單危險得多 —— 因為它會讓人跳過驗證直接動旋鈕,而「有時候剛好會好」會把錯誤的因果保留下來。

每一種缺陷都會列出至少 4 個判別方法,其中包含可以真的去做的實驗 (轉片、換 CD、換密度、換下層、比首片與第 25 片)。 診斷的產出應該是「下一個實驗」,不是「下一個參數」。

3.3.6 診斷收斂流程

問題不是「這是什麼缺陷」,而是「下一步做什麼」。 四個問題,每個都把範圍砍一半:

1. Recipe 有沒有動過?
有 → 對照 2.6 因果鏈回推。 這一步最常被跳過,也最浪費時間 —— 有人改了參數, 卻先去拆機台查硬體。
2. 是全片還是局部?
全片均勻 → 電漿整體(氣體、功率、壓力、腔體結垢)
中心/邊緣 → 均勻度問題,轉到 3.6
陣列邊緣 → 充電效應
隨機分佈 → 微粒、缺陷
3. 是這台還是每台?
單台 → 腔體狀態(匹配位置、He 洩漏、閥位、零件壽命)
全部 → 上游製程、材料批次、量測系統
4. 是這批還是每批?
首片異常 → first wafer effect / seasoning(見 3.6.5)
逐片漂移 → 腔體累積、零件消耗
💡 這四個問題的共同點:都不需要動製程

四個問題全部靠既有資料或一片測試片就能回答 —— 不必改配方、不必拆機、不必等備品。

而它們合起來能把「18 種缺陷 × 各自 2–4 個成因」縮到剩下一兩個候選。 先問完這四題再動旋鈕,是這一章最實用的一句話。

✅ 自我檢測

  1. 剖面看到側壁最寬處在中段,和最寬處在頂端 —— 分別是什麼缺陷?對策差在哪?
  2. ARDE 的四個成因各是什麼?它們的對策為什麼不能混用?
  3. 為什麼延長蝕刻時間會讓 ARDE 變嚴重?
  4. ARDE、microloading、macroloading 的差別只在一件事,是什麼?各用什麼實驗確認?
  5. 看到反向 ARDE(窄的反而深),這告訴你製程落在什麼狀態?
  6. notching、twisting、footing、ARDE 的第四項有什麼共同的物理? 共同的確認實驗是什麼?
  7. Faceting 的成因和 3.1.6 的哪一條直接相關?為什麼它一旦開始就會加速?
  8. 金屬腐蝕為什麼不能只靠製程參數解決?它和其他 17 種缺陷最大的差別是什麼?
  9. 診斷流程的第一個問題是什麼?為什麼它最常被跳過?
  10. 為什麼說「一個看起來很篤定的診斷答案,比一個誠實的清單危險」?

題庫與作答功能於 P4 測驗中心實作。
