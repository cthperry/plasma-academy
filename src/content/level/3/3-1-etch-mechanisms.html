3.1 蝕刻機制

⏱ 3.0 小時 🔬 A17、A18 互動元件 L3 進階 · 機制章
🎯 學習目標
📋 前置知識 2.6 參數因果鏈
⚡ 5 分鐘摘要

L2 把旋鈕與電漿參數的關係建好了。這一章開始問材料到底是怎麼被移除的。

答案只有四種機制,而現代電漿蝕刻是後兩種的組合: 離子輔助協同 + 側壁鈍化。

  • 協同效應是相乘的。1979 年 Coburn–Winters:化學 5、物理 2、 兩者同時 55。5 + 2 = 7,實測 55 —— 差了近八倍。
  • 異向性不是額外機制,是協同的直接後果。溝底同時有離子與自由基(55), 側壁只有自由基(5)。底部快 11 倍,側壁自然就垂直了。
  • 選擇比幾乎永遠是鈍化做出來的。所以「提高選擇比」的三個手段 ——加聚合性氣體、降 bias、降 O₂ ——全部都會降蝕刻率。 這是根本性的 trade-off,不是調得好就能兩全。

兩個元件:A17 重現原始實驗, A18(★★ 旗艦)讓你用五個旋鈕直接把這些機制推到極端,看輪廓怎麼變形。

3.1.1 四種機制

材料要離開晶圓,必須變成揮發性的分子然後被抽走。 達成這件事的路徑只有四條:

機制驅動Profile選擇比蝕刻率
物理濺鍍 純離子動量轉移 異向,但有 45° 斜面效應 極差(對誰都差不多) 低
純化學蝕刻 中性自由基 完全等向 極佳 高
離子輔助(RIE) 離子 + 自由基協同 異向 好 高
抑制劑輔助(側壁鈍化) 離子 + 自由基 + 聚合物 高度異向 極佳 中
💡 為什麼前兩種在量產上都不能用

純物理:方向性最好,但它對任何材料的濺鍍產額都在同一個數量級 —— 蝕刻 SiO₂ 的同時把光阻和下層一起削掉,選擇比接近 1。 而且速率太低,產能撐不起來。

純化學:選擇比可以做到幾百,速率也漂亮,但自由基是等向入射的 —— 側壁與底部一樣快。圖案還沒刻到底,CD 就已經吃掉了。 灰化(ashing)這種不在乎 profile 的製程才用純化學。

兩個都不行,但把它們疊起來卻同時解決了兩個問題。 這件事在 1979 年之前並沒有人預期得到 —— 下一節就是那個實驗。

3.1.2 Coburn–Winters 實驗:整個領域的奠基實驗

實驗設計非常乾淨:一片 Si,一道 XeF₂ 氣流(純化學,可獨立開關), 一束 Ar⁺ 離子(純物理,可獨立開關)。分三個階段量 Si 的蝕刻率。

階段條件Si 蝕刻率(相對)
1只有 XeF₂ 氣體~5
2XeF₂ + Ar⁺ 離子束~55
3只有 Ar⁺ 離子束~2
📊 5 + 2 = 7,但一起用得到 55

這就是協同效應(synergy)。 兩者同時作用的速率是各自相加的 7.9 倍。

所以協同不能寫成加法模型。A17 的模型是 R = 5·g + 2·i + 48·g·i —— 那個 g·i 的乘積項就是協同, 而 48 這個係數是從 55 − 5 − 2 反推的,不是調出來的。

機制:離子的工作不是自己刻

只有自由基:F 吸附在 Si 表面 → 生成 SiFx 層 → 反應停在那裡,SiFx 脫附很慢 → 速率被脫附卡住
加上離子:打斷 Si–Si 鍵產生懸鍵(新的反應位置)、把 SiFx 打成揮發性的 SiF₄ 立刻脫附、混合表面層讓 F 進得更深 → 脫附瓶頸被打開
只有離子:表面沒有 SiFx 可打,只剩純動量濺鍍 → 效率極低
離子提供的是活化能,不是移除量 —— 這句話是整章的鑰匙
💡 現場意義:離子與自由基是兩個獨立旋鈕,但效果不獨立

因為速率是乘積型的,缺哪一邊都會塌。 自由基不足時加 bias 幾乎沒用(乘上一個小數); 離子不足時加流量也幾乎沒用。

這解釋了一個現場常見的困惑:「我明明加了功率,速率卻沒動。」 —— 通常是另一邊已經飽和了,你加在乘積裡已經被鎖住的那一項上。 回頭看 2.6 的 source/bias 兩條鏈, 判斷你缺的是密度還是能量。

3.1.3 異向性的根本:同一個機制,兩個位置

這是本章最重要的一段推導,而且它不需要任何新假設 —— 只要把上一節的乘積模型套到溝槽的兩個位置上:

位置自由基離子速率
溝底有(等向入射,進得去)有(鞘層加速,垂直入射)55
側壁有幾乎沒有(垂直入射打不到)5

底部比側壁快 11 倍 → 垂直側壁。 異向性的來源就是鞘層把離子整成單一方向 (1.5),而協同效應把「有沒有離子」放大成 11 倍的速率差。

⚠ 常見誤解:「離子把材料撞掉,所以往下刻」

如果真是離子撞掉材料,速率上限就是階段 3 的那個 2 —— 比純化學還慢,而且選擇比接近 1。實際製程用的是 55, 也就是化學在刻,離子只是開門。

這個區別在調機時很實際:當你以為速率靠離子時,不足就會一直加 bias, 結果選擇比崩掉、損傷上升,而速率沒怎麼動。

🔬 A17 Coburn–Winters 實驗重現

A17 協同效應 —— 為什麼 5 + 2 = 55
💡 A17 的紅色虛線是重點

圖上那條紅色虛線畫在 7 的位置 —— 也就是「如果協同可以相加」該有的高度。 兩個開關都打開時,曲線衝到 55,把虛線遠遠留在下面。

那段落差就是整個電漿蝕刻產業存在的理由。 沒有它,乾式蝕刻不會比濕式好。

3.1.4 側壁鈍化:第二層保險

協同效應給了 11 倍的速率差,但側壁那個「5」不是零 —— 刻得越深、時間越久,側壁被化學蝕刻咬掉的量就越可觀。深孔製程尤其明顯。

所以現代製程加上第二個機制:在側壁長一層保護膜。

來源鈍化層成分典型製程
氟碳聚合物CFx 聚合物介電質蝕刻(C₄F₈)
氧化型鈍化SiOBr / SiOClPoly-Si 蝕刻(HBr/Cl₂ + O₂)
光阻濺鍍再沉積碳質膜早期製程,現多視為缺陷來源

運作邏輯 —— L3 最重要的一張圖像

鈍化層均勻沉積在所有表面(它是中性物種,等向入射)
溝底:垂直離子轟擊持續把它打掉 → 露出材料 → 蝕刻繼續
側壁:離子打不到 → 鈍化層保留並持續增厚 → 蝕刻停止
結果:垂直側壁,而且側壁那個「5」也被關掉了

注意這個機制的選擇器仍然是離子的方向性 —— 和協同效應是同一個選擇器。所以兩個機制不是並列的兩招, 而是同一個原理用在兩件事上:一個開門讓蝕刻發生,一個關門讓蝕刻停止。

📊 這也是選擇比的來源

遮罩頂部雖然一直被離子轟擊,但如果鈍化沉積速率夠快, 淨消耗就低。同樣地,當蝕刻穿到下層材料時, 若下層沒有辦法消耗聚合物,聚合物就會累積起來把蝕刻擋住 —— 這就是自動停止。

A18 用的輪廓引擎只有三條規則(離子通量、自由基通量、聚合物收支), 沒有為任何一種缺陷寫規則。低 F/C 條件下它算出 SiO₂ 照刻而 Si 完全停住 —— 選擇比是聚合物收支自己解出來的。

這個機制寫對了以後,連 ARDE(深寬比效應) 都會自己出現: 深窄溝的自由基通量被立體角削掉 → 表面覆蓋率跟著掉 → 即使離子照樣打得到,速率還是慢。把 A18 切到多溝槽視圖就看得到, 而那並不是另外寫的規則。

3.1.5 選擇比的三種來源

S = Rtarget / Runderlayer
選擇比 —— 兩個速率的比值,但「怎麼做出這個比值」有三條不同的路
來源機制範例
化學選擇性 產物揮發性差異 F 蝕刻 Si 快、蝕刻 SiO₂ 慢(需離子破 Si–O)
鈍化選擇性 聚合物在不同材料上的淨累積差異 SiO₂ 有氧可消耗聚合物 → 蝕刻;Si 無 → 停止
閾值選擇性 濺鍍閾值能量差異 把 IEDF 壓到低於下層材料的閾值

實務要求

製程要求為什麼那麼高
Poly gate 對 gate oxide> 100oxide 只有 1–2 nm,打穿就完蛋
接觸孔 SiO₂ 對 Si> 20深度不均時最深的孔會先到底
SiN spacer 對 Si> 10過蝕刻會咬進源汲極
💡 工程師直覺:選擇比幾乎永遠是鈍化做出來的

化學選擇性通常只有個位數到十幾倍,閾值選擇性的窗又很窄。 要 100 倍以上,只有鈍化辦得到。

所以「提高選擇比」實務上就是這三招: 加聚合性氣體、降 bias、降 O₂。 而這三招在 2.6 的 trade-off 矩陣裡 全部都指向蝕刻率下降。

選擇比與蝕刻率是根本性的 trade-off —— 因為它們共用同一個旋鈕、方向相反。 這不是「調得好就能兩全」,而是必須選一個位置站。 唯一真正繞開這個 trade-off 的是 ALE(4.4):把沉積與移除分成兩個時間段, 不讓它們在同一瞬間互相抵銷。

3.1.6 濺鍍產額與角度效應

Y(E) ∝ ( √E − √Eth )
Sigmund 近似(閾值附近)—— Eth 是濺鍍閾值能量,低於它幾乎不濺鍍

但真正造成 profile 缺陷的不是能量依賴,而是角度依賴:

📊 濺鍍產額在入射角 45–70° 最大 —— 不是 0°

垂直入射(0°)時離子把能量帶進材料深處,反衝原子往下走,反而不容易噴出表面。 斜向入射時能量沉積在表層,反衝方向更接近表面法線的反面 —— 最容易噴出來。 角度太大(> 70°)則變成掠過,產額回落。

兩個直接後果

Faceting:遮罩肩部一開始只是個直角,但直角附近的局部斜面正好落在高產額角度 → 被削成 45° 斜面 → 斜面持續擴大 → 遮罩開口自己變寬,CD 失控
Microtrenching:斜面成了反射面 → 離子鏡面反射後集中打在溝底兩側 → 兩邊各刻出一道深溝
兩個缺陷、同一個成因 —— 完整圖鑑見 3.3
⚠ 常見誤解:把 faceting 當成 undercut

兩者在剖面上都是「上面比下面寬」,只看膜裡的溝分不開。 差別在遮罩:

  • Undercut —— 遮罩完好,只有膜被側蝕。遮罩開口沒變。
  • Faceting —— 遮罩自己被削寬了。這時量膜的 CD 已經沒有意義, 因為定義 CD 的那個遮罩已經不是原來的尺寸。

A18 因此把「遮罩開口(倍)」列成獨立的讀數 —— 它是這一組判別的關鍵, 也是模擬器判定 faceting 的依據。

A18 把這條角度依賴直接放進模型(Yamamura 型,峰值在 60°、約 1.8 倍), 所以你在 faceting 預設下看到的斜面不是畫上去的,是產額的角度依賴算出來的 —— 遮罩開口因此從 1.00 被撐到 1.77 倍。

📊 兩種移除機制的角度依賴不一樣

物理濺射(削遮罩、打掉聚合物)是動量轉移,60° 附近有明顯峰值。 但離子輔助化學蝕刻(3.1.2 的協同)靠的是離子提供活化能, 速率主要由自由基覆蓋率決定 —— 它的角度依賴弱得多。

這個區別不是細節:把完整的角度峰值也套在化學項上,任何斜面都會被清得特別快, 模擬出來的溝會變成完美的矩形 —— 比真實製程乾淨太多, taper 與 footing 會直接被抹平。

🔬 A18 蝕刻輪廓模擬器

A18 八種 profile —— L3 的旗艦元件
此元件建議在較大螢幕使用。
💡 A18 為什麼可以當診斷工具用

引擎只有三條規則:離子通量(垂直、被遮蔽)、自由基通量(等向、隨深寬比衰減)、 聚合物收支。八種 profile 沒有一種是寫死的 —— 全部是這三條規則在不同參數下的自然結果。

所以反過來也成立:當你在機台上看到某個 profile, 在 A18 上把它調出來所需要的參數,就是機台上真正偏掉的那個方向。 這正是 3.3 缺陷圖鑑 與 A21 診斷器的基礎。

預設參數也不是 A18 自己定的,而是直接讀 缺陷圖鑑的資料 —— 圖鑑改了模擬器就跟著改,兩邊不可能講不一樣的話。

📊 三組值得動手驗的對照
  • Etch stop 不是機台壞了:鈍化拉到最高時蝕刻幾乎不動,降下來就恢復 —— 「降聚合性氣體」的效果直接看得到,而且是聚合物收支自己算出來的。
  • Faceting 不是 undercut:切到 Faceting 預設,注意「遮罩開口」從 1.00 變大 —— 遮罩自己被削寬了。切回其他預設,這個數字回到 1.00。
  • ARDE:打開多溝槽視圖,三個不同 CD 同時蝕刻,窄的明顯較淺 (實測落差約 45 %)。沒有任何一行程式在處理「深寬比」—— 它來自自由基通量的立體角衰減。
⚠ 這個元件目前的限制,請一併知道

A18 的驗收條件是「八種 profile 全部可重現」。 目前確實做得到的是五種:垂直、Taper、Footing、Faceting、Etch stop (外加多溝槽視圖的 ARDE)。 Undercut、Bowing、Microtrench 這三種還沒收斂。

其中 Undercut 做不出來,其實是模型是對的。 A18 的目標膜是 SiO₂,而 F 自由基要蝕 SiO₂ 得先靠離子破 Si–O —— 這正是本節 3.1.4 講的化學選擇性,所以純化學的側蝕本來就很小。 Undercut 是 poly-Si / 金屬蝕刻的缺陷,不是介電質蝕刻的缺陷; 要示範它,得讓目標膜可以換成 Si。

Bowing 與 Microtrench 則是模型結構的限制:側壁的鈍化層會累積到飽和, 擋住的比例直接變成 0 或 1,沒有中間的梯度 —— 所以側壁不可能出現「中段比上下段多被咬一點」。

這些寫在這裡而不是藏起來,因為模擬器做不出來的形狀,圖鑑就沒有依據。 具體診斷與修法記在 docs/11-build-roadmap.md 的 A18 狀態表, 驗收測試是 npm run check:shapes(目前 21 / 32)。

3.1.7 這一章收束成一句話

離子的工作是開門(提供活化能),化學才是移除量的來源
門只在離子打得到的地方開 → 這就是異向性,也是選擇比
關門的機制(鈍化)與開門的機制共用同一個旋鈕 → 選擇比與速率必然衝突
離子的角度一旦不乾淨(發散、反射),缺陷就跟著出現

3.2 會把這套機制套到五個真實製程上(poly gate、接觸孔、spacer、金屬、 Bosch 深矽); 3.3 則把「離子角度不乾淨」的各種後果整理成缺陷圖鑑。
