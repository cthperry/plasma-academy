### 模板 4:實驗室頁

28 個元件的網格。每格:縮圖(元件的靜態截圖或 SVG 示意)、名稱、所屬章節、旗艦標記、複雜度。

## 導覽設計

```
[Logo] 學習路徑  實驗室  氣體百科  缺陷圖鑑  公式  術語  │ [搜尋] [進度] [🌓]

### 麵包屑

`首頁 › L2 中階 › 2.2 製程氣體選用學 › F/C 比與聚合物`

### 章節間導覽

上一章/下一章固定於內容底部,並支援鍵盤 `←` / `→`。

### 全站搜尋

**純前端**,建置時產生倒排索引 JSON:

- 索引範圍:章節標題、小節標題、正文、術語、氣體名、缺陷名
- 支援中英文混合查詢(中文以雙字元 bigram 切分,英文以詞邊界)
- 結果分類顯示:章節 / 術語 / 氣體 / 缺陷 / 互動元件
- 索引檔預估 < 400 KB,首次搜尋時才載入

## 進度追蹤

  chapters: {

  bookmarks: ["2-2", "3-3"],
  settings: { theme: "auto", reducedMotion: false, showEnglishTerms: true }

```

### 進度計算

- **章節完成** = 造訪 + 學習目標全勾 + 自我檢測 ≥ 60%
- **模組完成** = 所有章節完成
- **階段完成** = 所有模組完成 + 結業測驗通過

### 匯出與匯入

`/progress/` 提供 JSON 匯出/匯入。用途:
- 換裝置時搬移
- 企業導入時,學員把結果交給訓練承辦人
- **不做後端**,避免導入時的資安審查成本

**明確告知**:頁面上要清楚寫「進度只存在這台裝置的瀏覽器,清除瀏覽資料會遺失」,並提示可匯出備份。

## URL 與檔案對應

因為是純靜態多頁站,每個 URL 對應一個實體 HTML 檔:

```
/level/1/1-1-fourth-state/  →  level/1/1-1-fourth-state/index.html
```

**優點**:可直接以 `file://` 開啟離線使用(需相對路徑)、部署簡單、SEO 友善、瀏覽器原生的前進/後退與書籤全部正常。

**代價**:共用的頁首頁尾需要在建置時展開到每個檔案。這由一支簡單的 Node 建置腳本處理(讀模板 + 內容片段 → 輸出完整 HTML),不引入框架。

## 資源載入策略

```
每個頁面載入:
  base.css          設計 token + reset + 排版          ~12 KB
  layout.css        版面與導覽                          ~8 KB
  components.css    內容元件(公式卡/警示方塊/表格)     ~10 KB
  app.js            導覽、主題、進度、tooltip           ~15 KB

章節頁額外:
  chapter.css       章節專用                            ~4 KB
  該頁用到的互動元件 JS(動態載入,進入視窗才載)      ~10–30 KB each

實驗室頁:
  只載入被開啟的元件
```

**三層載入策略**(P0 實作後的實測值):

| 層 | 內容 | 大小 | 何時載入 |
|---|---|---|---|
| **關鍵路徑** | HTML + 4 支 CSS + 8 支核心 JS | **約 104 KB / 15 個資源** | 每一頁 |
| **按需** | `data/glossary.js`(41 KB)、`js/lab/` 六支共用模組(48 KB) | 約 92 KB | 頁面有 `.pa-term` 或 `[data-lab]` 時 |
| **延遲** | 個別互動元件(約 10–30 KB/支)、搜尋索引(120 KB) | 視使用 | 元件捲進視窗前 200 px;搜尋索引按下搜尋鈕才抓 |

實作方式:`js/app.js` 提供 `loadScripts()`,以注入 `<script>` 的方式依序載入(不用 dynamic import,
這樣 `file://` 直接開啟也能運作)。元件層再由 `js/lab/lifecycle.js` 的 `IntersectionObserver` 控制。

> **實作記錄**:初版規劃寫「章節頁初始載入 < 50 KB」,實作後量到 194 KB —— 因為術語表與
> lab 共用模組被無條件載入。改為按需後關鍵路徑降到 104 KB。50 KB 對一個含 4 支 CSS 與
> 完整導覽的中文教材站並不現實,正式門檻改訂為 **關鍵路徑 < 120 KB**,由 `tools/smoke.mjs` 斷言。

## 響應式斷點

| 斷點 | 版面 |
|---|---|
| < 640 px | 單欄;側欄收合;互動元件改直式佈局,控制面板在下 |
| 640–1024 px | 單欄 + 可收合側欄;互動元件維持橫式但縮小 |
| 1024–1440 px | 左側欄 + 主內容 |
| > 1440 px | 左側欄 + 主內容 + 右側大綱(完整三欄) |

**互動元件的行動版策略**:不是等比縮小(會看不清),而是**重新佈局** —— Canvas 區域維持可辨識的最小尺寸,控制面板改為下方的可捲動區,數值面板改為橫向捲動的卡片列。

**極複雜元件(A16、A18)** 在 < 640 px 時顯示提示:「此元件建議在較大螢幕使用」,並提供簡化版(減少同時顯示的參數)。

## 離線與部署

- **無後端、無 API 呼叫**,所有內容為靜態檔
- 可選加上 Service Worker 做離線快取(Phase 4 再評估,非必要)
- 部署:任何靜態主機皆可(Vercel / Netlify / GitHub Pages / 內網 nginx / 甚至隨身碟)
- **內網部署是重要場景** —— 許多廠區限制外網,教材必須能放在內部伺服器或本機

## CSP 相容性

即使獨立部署,仍遵守嚴格 CSP 的寫法,讓網站能直接放進有安全政策的企業環境:

```
default-src 'self';
script-src 'self';
script-src-attr 'none';
style-src-elem 'self';
style-src-attr 'unsafe-inline';
img-src 'self' data:;
font-src 'self';
connect-src 'self';
base-uri 'self';
form-action 'self';
frame-ancestors 'none';
```

**這代表**:
- 所有 JS 在外部 `.js` 檔,無 inline `<script>`
- 所有 CSS 在外部 `.css` 檔,**無 inline `<style>` 區塊**(`style-src-elem 'self'`)
- 無 `onclick=` 等事件屬性,一律 `addEventListener`(`script-src-attr 'none'`)
- 無 `eval` / `new Function`
- 字型自行打包或使用系統字型堆疊
- 圖片內嵌為 SVG 或 `data:` URI

**為什麼 `style-src-attr` 放行 `'unsafe-inline'`**:
tooltip 的定位、Canvas 元件的動態尺寸、以及建置期寫入的 `style="--level-color:…"`
都需要 inline `style` **屬性**。style 屬性無法執行程式碼,風險與 `<style>` 區塊不同量級,
因此業界慣例是把 `style-src-elem` 鎖死、只放行 `style-src-attr`。
裝飾性的 inline style 仍應改用 class —— 只有真正動態的值(座標、尺寸)才寫進屬性。

`tools/serve.mjs` 在本機開發時就送出與正式部署相同的 CSP,違規在開發階段就會被 console 攔下,
`tools/smoke.mjs` 也會斷言「無 CSP 違規」。
