# 09 — 內容撰稿規範

## 語氣與人稱

**對象假設**:一位聰明、忙碌、有工程訓練但沒學過電漿的同事。你在他桌邊解釋,不是在講台上授課。

| 要 | 不要 |
|---|---|
| 「壓力調低,離子碰撞變少,所以側壁比較直」 | 「根據前述理論,吾人可推知⋯⋯」 |
| 「這一句話是整章的重點」 | 「值得注意的是⋯⋯」 |
| 直接說「你」 | 「學習者應當⋯⋯」 |
| 承認「這個數字各家差很多」 | 假裝所有數字都是定論 |

**人稱**:正文用「你」稱呼讀者。不用「我們」除非真的在講「業界」或「本教材」。

**禁用**:「顯而易見」「不難看出」「眾所周知」。如果真的顯而易見就不用寫;如果要寫,就代表不顯而易見。

---

## 敘事結構

每個概念固定四步:

```
1. 現場現象   → 「點火時要先衝壓力再降下來,為什麼?」
2. 物理圖像   → 用文字與圖描述機制,不出現公式
3. 數學關係   → 公式卡,可展開推導
4. 典型數值   → 產業常見範圍,讓抽象變具體
```

**不要跳過第 1 步。** 直接從定義開始的段落一律退回重寫。

## 術語處理

### 首次出現

```
鞘層(Sheath)
平均自由徑(Mean Free Path, MFP)
電子能量分佈函數(Electron Energy Distribution Function, EEDF)
```

中文在前、英文在括號、有常用縮寫時一併給。**同一章內第二次出現後可只用中文**,但全站的 tooltip 永遠可查。

### 何時保留英文

以下情況直接用英文,不強行中譯:

| 類型 | 範例 |
|---|---|
| 業界口語 | recipe、profile、bias、gap、seasoning、dummy、golden chamber |
| 已成專有名詞 | Bosch process、Paschen curve、Langmuir probe、Child–Langmuir |
| 縮寫比全稱常用 | ICP、CCP、PECVD、ALE、ARDE、OES、EPD、FDC、ESC、HAR |
| 缺陷名稱 | bowing、footing、notching、microtrenching、undercut、scallop |

**理由**:現場工程師講的就是這些詞。強行寫「弓形效應」反而增加閱讀阻力,也讓學員在跟同事討論時對不上。

### 中譯選用原則

同一概念有多種中譯時,選**台灣半導體業界慣用**的:

| 採用 | 不用 |
|---|---|
| 電漿 | 等離子體(中國大陸用法) |
| 鞘層 | 鞘、護套 |
| 蝕刻 | 刻蝕(中國大陸用法) |
| 光阻 | 光刻膠 |
| 晶圓 | 硅片 |
| 沉積 | 澱積 |
| 濺鍍 | 濺射 |
| 遮罩 | 掩膜 |
| 深寬比 | 縱橫比、長寬比 |
| 選擇比 | 選擇性(易混淆) |
| 自由基 | 遊離基 |

**術語表(`10-glossary.md`)是唯一來源。** 撰稿時遇到新術語,先加進術語表再寫,不要各章各自翻譯。

## 數字與單位

### 單位規範

| 量 | 主單位 | 備註 |
|---|---|---|
| 壓力 | **mTorr / Torr** | 業界慣用;首次出現附 Pa 換算 |
| 流量 | **sccm** | 大流量用 slm |
| 溫度(電子) | **eV** | 首次出現附「1 eV = 11,605 K」 |
| 溫度(氣體/晶圓) | **°C** | 物理推導時用 K |
| 密度 | **cm⁻³** | 業界慣用,不用 m⁻³ |
| 長度 | 依尺度:nm / µm / mm / cm | 不混用 |
| 能量 | eV | |
| 功率 | W | |
| 頻率 | MHz / kHz | |

**數字與單位之間留一個空格**:`20 mTorr`、`13.56 MHz`、`500 W`。例外:`°C` 與 `%` 不留空格(`80°C`、`75%`)。

### 數字的誠實度

- **典型值必須標明是「典型」**,不要寫成定值。用「約」「典型 5–50」「量級 10¹⁰」
- **量級比精度重要**。教材要建立的是「這是 10¹⁰ 還是 10¹²」的直覺,不是小數點後兩位
- **來源不確定的數字要說**。例如「不同文獻的 q 值從 1 到 2.5 都有,實測通常落在 1.5 附近」
- **不要編造精確數字**。寧可寫「數百伏」也不要寫「427 V」

### 換算的呈現

首次出現非 SI 單位時給換算,之後不重複:

```
製程壓力典型 20 mTorr(≈ 2.7 Pa)
```

全站常駐的單位換算工具列涵蓋:Torr ↔ Pa ↔ mbar、sccm ↔ slm、eV ↔ K ↔ J、cm⁻³ ↔ m⁻³。

## 圖說規範

每張圖(SVG 示意圖、互動元件截圖)都要有圖說:

```
圖 2-4 鞘層內的電位分佈。注意電位降幾乎全部落在鞘層內,
       bulk 區域幾乎沒有電場 —— 這就是為什麼離子只在最後
       這幾毫米被加速。
```

**圖說要說「看什麼」,不是重複標題。** 「圖 2-4 鞘層電位分佈」這種圖說等於沒寫。

編號規則:`圖 <章>-<序>`,如 `圖 2-4`。互動元件用編號 `A05` 不另編圖號。

## 互動元件的引導文字

每個嵌入的互動元件下方必須有「📌 觀察點」,包含 2–4 條引導:

**好的觀察點**:
- 「把 n_e 調高十倍,遮蔽圈縮小多少?驗證 λ_D ∝ 1/√n_e」
- 「這兩個設定的平均能量一樣,但分佈完全不同。哪一個選擇比會比較好?」

**壞的觀察點**:
- 「調整參數觀察變化」(沒有指向性)
- 「這個元件展示了 Debye 遮蔽」(重複標題)

**原則**:觀察點應該是**一個可執行的動作 + 一個要注意的結果**,最好帶點懸念。

## 章節結構模板

每章必須包含,順序固定:

```markdown
# <編號> <標題>

**時數** X h · **互動元件** Axx

## 🎯 學習目標
- 3–5 條,用可驗證的動詞(說出、解釋、計算、判斷、設計)
- 不用「了解」「認識」「熟悉」這種無法驗證的詞

## 📋 前置知識
- 連回相依章節,一句話說明為什麼需要

## ⚡ 5 分鐘摘要
- 200–400 字,趕時間的人只讀這段也有收穫
- 必須是完整的敘述,不是條列

## <小節>
...正文...

## 🔬 互動元件
...嵌入 + 觀察點...

## ✅ 自我檢測
...5–8 題...

## 📚 延伸閱讀
- 教科書:書名 + 章節
- 論文:作者、年份、標題(經典文獻優先)
```

| 單位 | 建議長度 |
|---|---|
| 5 分鐘摘要 | 200–400 字 |
| 小節 | 400–1,200 字 |

## 審閱流程

每個章節在發佈前必須經過三道:

| 關卡 | 檢查什麼 | 誰 |
|---|---|---|
| **1. 技術正確性** | 物理是否正確、公式與數值是否無誤、有無過度簡化到失真 | 具電漿背景的資深工程師或學界人士 |
| **2. 教學有效性** | 目標讀者(0–3 年工程師)讀得懂嗎?哪裡卡住? | 目標讀者本人試讀 |
| **3. 一致性** | 術語、單位、格式、交叉引用是否與規範一致 | 撰稿統籌 |

**第 1 關是最大的專案風險**(見 `11-build-roadmap.md`)。技術審閱必須排進時程,不能事後補。

### 技術審閱特別注意項

以下是最容易寫錯或過度簡化的地方,審閱時要重點看:

- [ ] T_e 與功率的關係(常被錯寫成「加功率電子溫度上升」)
- [ ] 游離度的量級(常被誇大)
- [ ] 「電漿很熱」的誤導
- [ ] 鞘層厚度與 Debye 長度的關係(不是相等)
- [ ] 面積比指數 q 的值(理論 4 與實際 1–2.5 的差異必須說明)
- [ ] F/C 比與 O₂/H₂ 的作用方向
- [ ] NF₃ 的 GWP 高但實際排放低(常被誤解)
- [ ] Actinometry 的三個前提(常被略過導致誤用)
- [ ] ALE window 的兩個閾值
- [ ] 氣相複合 vs 器壁複合(低壓下以器壁為主)
- [ ] 互動元件的物理模型是否會產生誤導性的結論

### 互動元件的額外驗收

除了規格書列的驗收條件,每個元件還要檢查:

- [ ] 極端參數下不會產生荒謬結果(例如負的密度、無限大的蝕刻率)
- [ ] 若模型有刻意誇大(如 A01 的游離度),**必須在畫面上誠實標註**
- [ ] 數值面板的單位與 `09` 的單位規範一致
- [ ] 深淺主題都正確重繪
- [ ] `prefers-reduced-motion` 下仍可完整傳達概念
- [ ] 行動版可用
