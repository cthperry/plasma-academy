# 00 — 課程總地圖

## 設計原則

1. **每一章都要能回答「這跟我的 recipe 有什麼關係」**
   物理推導可以留在展開的公式卡裡,但主線敘事永遠是「參數 → 電漿狀態 → 晶圓結果」。

2. **先給直覺,再給公式,最後給數字**
   每個概念的順序固定:現場現象 → 物理圖像 → 數學關係 → 典型數值範圍。

3. **能動的就不要只用畫的**
   凡是牽涉到「調 A 會怎樣影響 B」的概念,一律配互動元件,不用靜態曲線圖交代。

4. **術語一律中英並列**
   首次出現寫成 `鞘層(Sheath)`,之後可單用中文,但全站 hover tooltip 永遠可查。

5. **階與階之間可獨立進入**
   L3 的人不必重看 L1,但每章的「前置知識」區塊會列出可回頭補的連結。

## 能力矩陣

完成各階段後,學員應具備的能力:

### L1 完成後

- 能對非工程背景同事解釋電漿是什麼、為什麼會發光
- 看到 recipe 上的 `Pressure 20 mT / RF 500 W / Ar 100 sccm`,知道每個數字大概代表什麼物理量
- 能說明為什麼離子會垂直往下打,而不是四面八方亂飛
- 知道自己負責的製程屬於哪一類電漿應用、典型參數窗在哪

### L2 完成後

- 拿到一份陌生 recipe,能推論每支氣體在裡面扮演什麼角色
- 能解釋為什麼加 O₂ 會讓某些製程蝕刻率上升、某些下降
- 能區分 CCP 與 ICP 機台的行為差異,知道 source power 與 bias power 分別在控什麼
- 反射功率跳高時,知道要往哪個方向查
- 能畫出「壓力↑ → ? → ? → 蝕刻率?」的完整因果鏈

### L3 完成後

- 看 SEM 剖面照片,能命名 profile 缺陷(bowing / footing / notching / microtrench)並推論成因
- 能提出對應的參數調整方向並說明預期的副作用
- 理解 ARDE 為什麼存在、為什麼不能只靠延長時間解決
- 能解釋 HDP-CVD 為什麼填得進去而 PECVD 會夾 void
- 拿到均勻度 map,能區分是氣流、溫度還是電場造成的

### L4 完成後

- 能讀懂 Langmuir 探針 I-V 曲線與 OES 光譜,推得 n_e / T_e / 主要自由基
- 能設計終點偵測策略,並判斷低開口率製程何時該放棄 OES 改用時間模式
- 能評估製程的電漿誘發損傷風險,並提出天線規則或脈衝電漿等對策
- 能主導 chamber matching,設計指紋比對項目
- 能規劃 DOE 找製程窗,並用診斷資料收斂異常

## 學習路徑建議

### 路徑 A:新人完整訓練(建議 3 個月)

L1 → L2 → L3 → L4 全走。每週 5 小時,搭配每階段結業測驗。

### 路徑 B:蝕刻工程師快速上手(建議 6 週)

`1.1–1.6` → `2.2 氣體選用` → `2.4 鞘層物理` → `2.6 因果鏈` → `3.1–3.3` → `4.2 終點偵測`

### 路徑 C:薄膜工程師快速上手(建議 5 週)

`1.1–1.6` → `2.1 真空` → `2.3 電漿化學` → `2.5 電漿源` → `3.4 沉積` → `3.5 PVD` → `3.6 均勻度`

### 路徑 D:設備工程師(建議 4 週)

`1.1–1.5` → `2.1 真空` → `2.5 電漿源與匹配` → `3.6 腔體工程` → `4.1 診斷` → `4.6 量產與安全`

### 路徑 E:資深工程師補強(自選)

直接進 L4,以各章「前置知識」連結回頭補洞。
