## 4.1 電漿診斷(3.5 h)

### 學習目標
- 讀懂 Langmuir 探針 I-V 曲線,求出 n_e、T_e、V_p、V_f
- 讀懂 OES 光譜,做 actinometry 定量
- 對指定問題選出適當的診斷手段

### 4.1.1 診斷方法總覽

| 方法 | 量什麼 | 侵入性 | 可否量產線上 |
|---|---|---|---|
| **Langmuir 探針** | n_e, T_e, V_p, V_f, EEDF | **侵入** | 否(研發/機台驗收) |
| **OES 光發射光譜** | 相對物種濃度、終點 | 非侵入 | **是,最普及** |
| **VI Probe / 阻抗分析** | RF 電壓/電流/相位/諧波 | 非侵入 | **是** |
| **RGA 質譜** | 氣體與產物組成 | 抽樣 | 部分 |
| FTIR 排氣分析 | 排氣分子種類 | 非侵入 | 環保監測 |
| 微波干涉 | 線積分電子密度 | 非侵入 | 研發 |
| **RFEA / 離子能量分析儀** | **IEDF** | 侵入 | 否 |
| SEERS | n_e、碰撞率 | 非侵入 | 部分 |

### 4.1.2 Langmuir 探針:電漿診斷的黃金標準

**原理**:插一根小金屬探針,掃描偏壓,量流入的電流。

**I-V 曲線的三個區**:

```
  I
  ↑                                    ┌── 電子飽和區
  │                                ╱───┘   (V > V_p,收集所有電子)
  │                            ╱
  │                      ╱  ← 過渡區(指數區)
  │                  ╱       半對數作圖斜率 = 1/T_e
──┼──────────────╱──────────────────────→ V
  │  ────────  ↑
  │  離子飽和   V_f (I = 0)
  │  (只收離子)
```

**四個參數怎麼求**:

| 參數 | 方法 |
|---|---|
| **V_f** | I = 0 的電壓 |
| **T_e** | 過渡區取 ln(I_e) vs V,**斜率倒數即 T_e [eV]** |
| **V_p** | dI/dV 的極大值處(或半對數圖的轉折點) |
| **n_e** | 由離子飽和電流 I_sat = 0.61 · n · e · u_B · A 反推 |
| **EEDF** | **Druyvesteyn 公式**:f(E) ∝ d²I_e/dV² |

**Druyvesteyn 公式的價值**:它不假設 Maxwellian,直接由二次微分得到真實的 EEDF。這是唯一能實驗確認 2.3.2 那些分佈形狀的方法。

**四個實務陷阱**(這是新手最常踩的):

1. **RF 補償必不可少** —— RF 電漿中 V_p 以 13.56 MHz 振盪。未補償的探針量到的是被 RF 塗抹過的曲線,T_e 會被高估數倍。需加 RF 扼流圈與補償電極
2. **探針會被鍍膜** —— 在沉積或聚合性製程中,探針表面幾秒內就被絕緣層覆蓋,量不到東西。需要離子轟擊清洗或加熱
3. **探針擾動電漿** —— 探針面積相對於接地面積不能太大,否則抽走的電子會改變電漿
4. **磁化電漿不適用** —— ECR 或有磁場的系統,標準理論失效

**因此 Langmuir 探針在量產線上幾乎不用**,但它是機台驗收、模型校驗、研發的必備工具。

### 4.1.3 OES:量產線上的眼睛

**原理**:激發態粒子退激發放光,譜線波長是物種的指紋,強度與該物種濃度相關。

**關鍵譜線表**(高價值速查):

| 波長 (nm) | 物種 | 用途 |
|---|---|---|
| **703.7 / 685.6** | **F** | 氟系蝕刻主監控 |
| **750.4 / 811.5** | **Ar** | **Actinometry 內標** |
| 777.4 / 844.6 | O | 氧自由基、灰化終點 |
| **483.5 / 519** | **CO** | **SiO₂ 蝕刻終點主訊號** |
| 251.6 / 288.2 | Si | Si 蝕刻產物 |
| 387.1 / 388.3 | CN | 含氮有機物 |
| 516.5 | C₂ | 聚合物 |
| 656.3 | H(Hα) | 含氫製程 |
| 837.6 / 725.7 | Cl | 氯系蝕刻 |
| 470 / 478 | Br | 溴系蝕刻 |
| 336 / 357 | N₂ | 氮系 |
| 306 / 309 | OH | 水氣污染 **← 洩漏偵測** |

**OH 譜線是免費的洩漏偵測器**:腔體有微漏或水氣殘留時,306 nm 附近會出現 OH 帶。這條線應該納入每台機的常態監控。

### 4.1.4 Actinometry:把相對強度變成相對濃度

**問題**:譜線強度 I ∝ n_species × (激發速率係數),而激發速率係數依賴 n_e 與 T_e。所以**強度變化可能是濃度變了,也可能只是電漿條件變了**。直接看強度會誤判。

**解法**:加入少量已知濃度的惰性追蹤氣體(通常 1–5% 的 Ar),取比值:

```
[F] / [Ar] ∝ I_F(703.7) / I_Ar(750.4)
```

因為 F(703.7 nm)與 Ar(750.4 nm)的**激發閾值能量相近(約 14–14.5 eV)**,兩者的激發速率係數對 T_e 的依賴幾乎相同 → **相除後 T_e 的影響被消掉**,剩下的就是純粹的濃度比。

**這是 OES 從「定性」變成「半定量」的關鍵技術。**

**Actinometry 的三個前提**(用錯會得到假數據):
1. 追蹤氣體濃度必須夠低,不改變電漿
2. 兩條譜線的激發閾值必須接近
3. 物種必須以**直接電子激發**為主(若有解離激發貢獻,關係就不成立)

### 4.1.5 VI Probe 與諧波分析

裝在 RF 饋入端,量 V、I、相位 → 得到電漿阻抗。

**能看出什麼**:
- 電漿阻抗的變化 = 腔體狀態的變化(比匹配電容位置更靈敏)
- **諧波成分**(2ω、3ω…)反映鞘層的非線性程度 → 可推鞘層電壓與離子能量
- 異常放電、arcing 的即時偵測

**優勢**:完全非侵入、可 100% 監控每片、資料量大適合機器學習。這是現代 FDC 的核心感測器之一。

### 4.1.6 RGA 與排氣分析

**RGA(殘餘氣體分析儀)**:四極質譜,量 m/z 分佈。

用途:
- 量測真實的腔內組成(對照 2.1.2 的分壓誤區)
- 洩漏偵測(m/z = 28 N₂、32 O₂、18 H₂O 的比例 → 空氣漏 vs 水氣)
- 終點偵測(產物訊號)
- PM 後的腔體潔淨度確認

### 4.1.7 診斷選擇決策表

| 問題 | 建議工具 |
|---|---|
| 蝕刻率掉了,不知道是自由基少還是離子少 | OES(actinometry 看自由基) + VI probe(看功率耦合) |
| 懷疑腔體洩漏 | RGA、OES 的 OH/N₂ 線、升壓率測試 |
| 機台間結果不同 | VI probe 指紋 + OES 全譜比對 + 匹配位置 |
| 想知道實際打到晶圓的離子能量 | RFEA(研發);量產以 VI probe 諧波推估 |
| 想校驗模擬模型 | Langmuir 探針 + RFEA |
| 找終點 | OES、干涉、RF 諧波 |

## 4.2 終點偵測與先進製程控制(2.5 h)

### 學習目標
- 為指定製程設計終點偵測策略
- 判斷何時 OES 終點會失效,以及替代方案
- 說明 R2R 控制與 FDC 的運作邏輯

### 4.2.1 為什麼需要終點

固定時間蝕刻(timed etch)的問題:蝕刻率會因腔體狀態、開口率、膜厚而變。過蝕會傷下層,欠蝕會殘留。終點偵測讓製程跟著**實際狀態**走。

### 4.2.2 OES 終點

**原理**:蝕到界面時,產物訊號消失、反應物訊號上升。

| 製程 | 監控訊號 | 變化方向 |
|---|---|---|
| SiO₂ 接觸孔 | CO 483 nm | **下降**(產物沒了) |
| Poly-Si | SiCl / Si 288 nm | 下降 |
| Poly-Si | Cl 837 nm | **上升**(反應物不再被消耗) |
| 光阻灰化 | CO 483 / OH 309 | 下降 |
| SiN | CN 387 | 下降 |

**通常同時監控「產物下降」與「反應物上升」兩條線並取比值**,SNR 比單條線好得多。

### 4.2.3 SNR 問題:低開口率的困境

**訊號強度 ∝ 開口率(open area)**。

| 開口率 | OES 終點 |
|---|---|
| > 10% | 訊號明確,容易 |
| 1–10% | 需要演算法輔助 |
| 0.1–1% | 困難,需高解析光譜儀 + 多變量 |
| **< 0.1%** | **OES 基本失效** |

先進的接觸孔製程開口率常常只有 0.01–0.1%。這時的手段:

1. **多變量統計** —— 不看單條線,把整個光譜(數百通道)做 PCA 或 PLS,找出最能代表變化的主成分
2. **提高光譜儀解析度與積分時間**
3. **改用干涉式終點(IEP)** —— 訊號不依賴開口率
4. **改用 RF 諧波終點** —— 阻抗變化不依賴開口率
5. **回到時間模式 + R2R 補償**

### 4.2.4 干涉式終點(IEP)

**原理**:雷射或白光照射膜面,上下界面的反射光干涉。膜厚變化 λ/2n 產生一個完整條紋週期。

```
數條紋 → 直接得到已蝕刻的厚度
```

**優勢**:
- 提供**即時厚度與蝕刻率**,不只是終點
- 適用於透明膜(SiO₂、SiN、poly)
- 不依賴開口率(但需要足夠大的量測區,通常打在特定測試區或大面積 pad)

**限制**:膜必須透明且足夠平坦;圖形密集區的散射會破壞條紋。

### 4.2.5 其他終點方法

- **RF 諧波 / 阻抗終點**:界面變化改變電漿負載 → 阻抗變化。適用金屬蝕刻等 OES 訊號弱的場合
- **偏壓電壓終點**:V_dc 的微小變化
- **質譜終點**:直接看產物

### 4.2.6 演算法

實務訊號充滿雜訊與漂移,需要處理:

| 方法 | 用途 |
|---|---|
| 移動平均 / Savitzky-Golay | 平滑 |
| **一階微分** | 找最大變化率點 —— 最常用的終點判準 |
| 二階微分 | 找轉折 |
| 歸一化(除以總強度) | 消除光源與視窗透光率的漂移 |
| **PCA / PLS** | 低 SNR 的多變量終點 |
| 樣板比對 | 與 golden run 比對整段曲線 |

**視窗汙染是 OES 的頭號敵人**:觀測窗被沉積物覆蓋 → 訊號逐日衰減 → 終點時間漂移。對策:歸一化處理、定期清窗、窗前加 purge、把窗況納入 PM 項目。

### 4.2.7 R2R 控制與 FDC

**Run-to-Run(R2R)控制**:
```
量測前一批結果 → 與目標比較 → 用模型調整下一批的 recipe 參數(通常是時間)
```
常用 EWMA(指數加權移動平均)控制器。能補償緩慢漂移(腔體結垢、零件消耗),但補不了突變。

**FDC(Fault Detection & Classification)**:
- 收集每片的**全部感測器時間序列**(壓力、閥位、功率、反射功率、匹配位置、He 洩漏、OES、VI)
- 建立統計模型,偵測偏離
- 目標是**在良率受損前抓到異常**

**虛擬量測(VM)**:用感測器資料預測製程結果,不必真的量。降低量測負擔、提高抽樣密度。

**工程師直覺**:FDC 的價值不在演算法多先進,而在**選對監控項目**。最有價值的幾個往往是最樸素的:節流閥位置、匹配電容位置、He 洩漏率、反射功率、OES 基線。這五個能抓到八成的腔體異常。

## 4.3 電漿誘發損傷(2.5 h)

### 學習目標
- 說明充電損傷的機制與天線比的意義
- 列出五種主要損傷型式及其對策
- 評估製程的損傷風險

### 4.3.1 充電損傷與天線效應

**機制**:

```
電漿中電子與離子到達晶圓表面的**空間分佈不同**
   ↓
電子有熱速度分佈(等向),離子被鞘層加速(垂直)
   ↓
在高深寬比結構中,電子被結構側壁遮蔽(electron shading)
   而離子筆直打到底
   ↓
導體圖形累積淨正電荷
   ↓
電荷經由連接的導線匯集
   ↓
若導線最終連到閘極,電荷全部灌進閘極氧化層
   ↓
穿隧電流 → 氧化層缺陷 → **Vt 漂移 / TDDB 壽命縮短 / 直接崩潰**
```

**天線比(Antenna Ratio)**:

```
AR = 連接到閘極的導體面積 / 閘極面積
```

**為什麼是面積比**:收集電荷的量正比於導體面積,而承受電荷的是閘極面積。比值越大,閘極承受的電流密度越大。

**設計規則**:各代製程都有 AR 上限(典型 100–1000)。超過的線路必須加**天線二極體(antenna diode)** —— 一個接地的二極體,在電漿製程中提供洩放路徑,正常操作時逆偏不導通。

**製程端能做什麼**:
- 降低電漿的**不均勻度**(充電損傷主要由電漿不均勻造成的橫向電流驅動)
- **脈衝電漿** —— off 期電子可自由到達,中和正電荷。**這是最有效的手段**
- 降低離子能量與電子溫度
- 縮短高風險步驟時間

### 4.3.2 五種主要損傷

| 型式 | 機制 | 影響 |
|---|---|---|
| **充電損傷** | 上述天線效應 | 閘極氧化層崩潰、Vt shift、可靠度下降 |
| **UV / 光子損傷** | 電漿放出的 VUV 光子(< 200 nm)穿透介電質產生電子-電洞對 | 介電質陷阱、Vt shift;**無法用天線二極體防護** |
| **離子轟擊損傷** | 高能離子在表面下數 nm 造成晶格損傷、非晶化 | 接面漏電、遷移率下降 |
| **污染 / 摻雜** | 腔體零件濺鍍出的金屬進入晶圓;鹵素殘留 | 深層能階、腐蝕 |
| **Low-k 損傷** | O 自由基抽走 SiCOH 中的甲基 → 碳耗盡 → 親水 → 吸濕 | **k 值上升**、漏電、可靠度 |

**UV 損傷常被忽略**:它不需要導電路徑,天線二極體救不了。對策只能從電漿端下手 —— 降低 T_e(減少高能激發)、用低 T_e 電漿源(微波/表面波)、加遮蔽層。

**Low-k 損傷是先進 BEOL 的核心難題**:所有含 O 的電漿步驟(灰化、蝕刻、清潔)都會傷 low-k。這是業界改用 **N₂/H₂ 灰化**、**CO₂ 基化學**、以及後續**矽烷化修復(silylation repair)** 的原因。

### 4.3.3 損傷的量測

| 方法 | 量什麼 |
|---|---|
| **天線測試結構(Antenna PCM)** | 不同 AR 的電容,量 Vt shift 與崩潰率 |
| **CHARM-2 監測晶圓** | 專用晶圓,直接記錄製程中的電位與 UV 劑量 |
| C-V 量測 | 界面態密度 D_it |
| TDDB / 電荷至崩潰 Q_bd | 氧化層可靠度 |
| 橢圓偏光 / FTIR | Low-k 的碳含量與 k 值變化 |

### 4.3.4 電弧(Arcing)

**成因**:局部電場集中(尖角、剝落處、微粒)、絕緣件表面帶電、Paschen 谷底的寄生放電。

**後果**:晶圓局部熔毀、零件損傷、大量微粒、製程中斷。

**對策**:
- RF 電源的 arc detection 與快速切斷
- 消除腔內尖角與鬆動的沉積物(PM)
- He 稀釋(提高崩潰電壓)
- 避免功率快速跳變(ramp 而非 step)

## 4.4 先進技術(3.5 h)

### 學習目標
- 說明脈衝電漿的三種模式與各自解決的問題
- 解釋 ALE 的自限制機制與協同度定義
- 說出 HAR 蝕刻的技術路線

### 4.4.1 脈衝電漿

**三種脈衝模式**:

| 模式 | 脈衝什麼 | 主要效益 |
|---|---|---|
| **Source pulsing** | Source power | 調控自由基組成、降低解離度、降 T_e |
| **Bias pulsing** | Bias power | 中和充電、控制 IEDF |
| **Synchronized pulsing** | 兩者同步(可設相位差) | 最大彈性,先進製程主流 |

**脈衝帶來的四個好處**:

1. **中和充電** —— off 期鞘層塌陷,電子可自由到達深孔底部與絕緣表面,中和累積的正電荷 → **直接解決 notching 與 twisting**
2. **負離子可以出來** —— 電負性電漿在 off 期鞘層消失,負離子得以抵達晶圓。**負離子中和正充電的效果比電子更好**(質量大,能進深孔)
3. **調控自由基比例** —— 縮短 on 期抑制多階解離 → 例如在氟碳電漿中提高 CF₂/F 比 → 提高選擇比
4. **降低 T_e 平均值** —— off 期電子快速冷卻 → 減少 UV 與高能損傷

**關鍵參數**:
- **脈衝頻率**(典型 0.1–10 kHz)—— 必須讓 off 期長到足以讓鞘層塌陷、電荷中和,但短到電漿不會熄滅
- **佔空比 Duty cycle**(典型 10–90%)—— 決定平均功率與自由基組成

**代價**:平均蝕刻率下降(功率只在 on 期給),需要更長的製程時間。

### 4.4.2 原子層蝕刻(ALE)

**動機**:當閘極只有幾 nm、鰭片只有十幾 nm 時,連續蝕刻的控制精度不夠。需要「一次移除一個原子層」。

**理想 ALE 循環(四步)**:

```
1. [改質]  通入反應氣體(如 Cl₂),**自限制**吸附/反應形成一薄改質層
2. [Purge] 抽走多餘氣體
3. [移除]  低能量 Ar⁺ 轟擊,能量刻意設在
             「移除改質層」與「濺鍍原始材料」的閾值之間
           → **自限制**:改質層移除完就停
4. [Purge] 抽走產物
   ↓ 重複,每循環移除 ~0.05–0.2 nm
```

**兩個自限制是 ALE 的靈魂**:第 1 步的吸附飽和,第 3 步的能量窗。兩者都讓製程「做完就停」,所以厚度只由循環數決定。

**ALE Window(能量窗)**:

```
E_th(移除改質層) < E_ion < E_th(濺鍍原始材料)
```

典型窗口 20–60 eV。窗口越寬,製程越 robust。

**協同度(ALE Synergy)** —— 量化 ALE 品質的指標:

```
S = ( EPC − α − β ) / EPC × 100%
```
- EPC = 每循環蝕刻量(Etch Per Cycle)
- α = 只做步驟 1、2 的蝕刻量(純化學貢獻)
- β = 只做步驟 3、4 的蝕刻量(純物理貢獻)

**理想 ALE 的 S 接近 100%** —— 表示蝕刻幾乎完全來自兩步的協同,沒有寄生的連續蝕刻。這是 3.1.2 Coburn–Winters 協同效應的定量化版本,兩章前後呼應。

**ALE 的三大優勢**:
1. 原子級厚度控制
2. **極佳的均勻度**(自限制 → 不依賴通量均勻性)
3. 極低的表面損傷與粗糙度

**代價**:**速率極慢**。每循環數秒、每循環 0.1 nm → 蝕 10 nm 要數分鐘。所以量產上通常只用在最關鍵的最後幾 nm(**主蝕刻用連續模式,收尾用 ALE**),或是用 **Quasi-ALE**(部分自限制,速度快很多)。

**Directional ALE vs Isotropic ALE**:離子驅動的是方向性 ALE;用熱能驅動移除步驟(如 HF + 金屬有機物)則是等向性 ALE,用於環繞閘極(GAA)的通道釋放。

### 4.4.3 高深寬比(HAR)蝕刻

**挑戰**:3D NAND 的通道孔已達 AR > 60:1,深度超過 6 µm,而 CD 只有幾十 nm。

**技術路線**:

| 手段 | 解決什麼 |
|---|---|
| **極高離子能量**(數 kV) | 讓離子有能量抵達並反應到孔底 |
| **低溫 / Cryo 蝕刻**(−20 ~ −60 °C) | 提高側壁鈍化效率、提高選擇比、抑制 bowing |
| **脈衝 + 負離子** | 中和孔底充電,防止 twisting |
| **方波 / 客製化偏壓波形** | 把 IEDF 壓成單能量峰,精準控制 |
| **高選擇比硬遮罩**(非晶碳、金屬) | 承受長時間蝕刻 |
| **高聚合氣體**(C₄F₆、C₄F₈) | 側壁保護 |

**低溫蝕刻為什麼有效**:低溫下鈍化層(聚合物或凝結的反應物)在側壁更穩定,而孔底因離子轟擊仍持續移除 → **底部與側壁的差異被放大** → profile 更垂直、選擇比更高。這是近年 HAR 蝕刻最重要的進展之一。

### 4.4.4 其他前瞻方向

- **選擇性沉積(Area-Selective Deposition, ASD)** —— 只在特定材料上長膜,用於自對準製程,減少微影層數
- **客製化偏壓波形(Tailored Waveform)** —— 用非正弦波形直接控制 IEDF 形狀
- **原子層清潔與表面平坦化**
- **機器學習輔助的 recipe 優化與虛擬量測**

## 4.5 電漿模擬與資料(2.0 h)

### 學習目標
- 說出四種模擬層級各自能回答什麼問題
- 讀懂模擬報告並判斷其可信度
- 知道製程工程師該向模擬團隊要什麼

### 4.5.1 四個模擬層級

| 層級 | 尺度 | 能回答 | 計算量 |
|---|---|---|---|
| **0-D 全域模型** | 整個腔體平均 | n_e、T_e、自由基密度隨參數的變化趨勢 | 秒 |
| **流體模型(Fluid)** | 腔體空間分佈 | 均勻度、電漿分佈、氣流 | 小時 |
| **PIC-MCC** | 動力學(粒子級) | EEDF、IEDF、鞘層細節 | 天 |
| **輪廓演化(Profile)** | 特徵尺寸(nm) | Profile 形狀、ARDE、充電 | 分鐘~小時 |

### 4.5.2 0-D 全域模型:工程師最該懂的一個

只用兩條平衡方程:

**粒子平衡** —— 產生 = 損失
```
k_iz · n_e · n_g · V  =  Γ_wall · A_eff
```

**能量平衡** —— 輸入功率 = 損失功率
```
P_abs = e · Γ_i · A_eff · ( E_c + E_i + E_e )
```
- E_c:每產生一個電子離子對的碰撞能量成本(含激發、解離的損失)
- E_i、E_e:離子與電子帶走的動能

**能推出的兩個關鍵結論**(這是全課程許多論述的理論依據):

1. **T_e 由粒子平衡決定** —— 只依賴 `n_g × L`(壓力 × 尺寸)與氣體種類,**與功率無關**
2. **n_e 由能量平衡決定** —— **正比於吸收功率**

這正是 2.6.3 說「加功率主要加密度、不加溫度」的出處。0-D 模型雖然簡單,卻抓住了電漿最重要的行為。

### 4.5.3 流體模型與 PIC-MCC

**流體模型**:把電子與離子當成連續流體,解連續方程 + 動量 + 能量 + 泊松方程。適合算空間分佈與均勻度,但**假設了 EEDF 形狀**(通常 Maxwellian),在低壓下不準。

**PIC-MCC(粒子網格 + 蒙地卡羅碰撞)**:追蹤大量代表粒子的實際軌跡,碰撞用蒙地卡羅抽樣。**不假設 EEDF**,是最可信的方法,但計算量巨大,通常只做 1-D 或 2-D 的鞘層區域。

**輪廓演化模擬**:輸入通量與能量角度分佈(從上述模型或實驗來),用 level-set 或 string 方法演化表面形狀。這是唯一能直接預測 profile 缺陷的工具。

### 4.5.4 資料來源與可信度

模擬的品質取決於輸入資料:

- **碰撞截面資料庫** —— **LXCat** 是公開標準來源
- **反應機制集(reaction set)** —— 氟碳電漿的完整機制有數百條反應,不同文獻的係數可能差數倍
- **表面反應係數** —— 最大的不確定來源。黏著係數、複合係數往往只能由實驗擬合

**讀模擬報告時該問的五個問題**:
1. 用的是哪個層級的模型?適合回答我的問題嗎?
2. 反應機制集從哪來?有多少條反應?
3. 表面反應係數是量測的還是擬合的?
4. 有沒有跟實驗校驗過?校驗了哪些量?
5. 給的是**趨勢**還是**絕對值**?(多數情況只有趨勢可信)

**工程師直覺**:模擬最有價值的用途不是預測絕對數字,而是**排除假設**與**指出方向**。當實驗結果與模擬趨勢相反時,通常代表有一個你沒想到的機制在作用 —— 那才是最有價值的資訊。

## 4.6 量產、良率與安全(2.0 h)

### 學習目標
- 設計 chamber matching 的指紋比對項目
- 用 DOE 定義製程窗
- 說出電漿製程的主要安全與環保議題

### 4.6.1 Chamber Matching

**目標**:讓 N 台同型機的製程結果落在同一個分佈內。

**分三層比對**:

| 層級 | 比對項目 |
|---|---|
| **硬體層** | 零件料號與版本、零件壽命(kWh、RF hour)、ESC 型號、聚焦環高度、噴淋頭孔況、管路長度 |
| **電漿層(指紋)** | **匹配電容位置**、反射功率、VI probe 阻抗與諧波、**OES 全譜**、節流閥位置、He 洩漏率、壓力控制響應 |
| **製程層** | 蝕刻率與均勻度、選擇比、CD、profile、缺陷數 |

**方法論**:
1. 選一台表現最好的當 **golden chamber**
2. 用同一片 monitor wafer 跑同一支 recipe
3. 收集三層資料,找出偏差最大的項目
4. **先修硬體與電漿層,不要直接改 recipe 補製程層** —— 用 recipe 補出來的匹配是脆弱的,下次 PM 又會跑掉

**最常見的不匹配根源**(依出現頻率):
1. 零件版本/壽命不一致(尤其聚焦環與噴淋頭)
2. 腔體 seasoning 狀態不同
3. 溫控校正偏差
4. RF 饋入路徑的接地阻抗差異
5. 流量計校正偏差

### 4.6.2 製程窗與 DOE

**製程窗定義**:所有規格(蝕刻率、CD、選擇比、均勻度、缺陷)同時滿足的參數區域。

**兩階段 DOE**:

| 階段 | 設計 | 目的 |
|---|---|---|
| **篩選** | Plackett-Burman、部分因子(2^(k-p)) | 從 8–10 個因子中找出真正重要的 3–4 個 |
| **優化** | 響應曲面(CCD、Box-Behnken) | 建立二次模型,找最佳點與製程窗邊界 |

**電漿製程做 DOE 的四個特殊注意事項**:
1. **因子間交互作用強** —— 壓力 × 功率、O₂ × bias 幾乎必然有交互作用,不能只做主效應設計
2. **腔體會漂移** —— 實驗順序必須隨機化,並穿插重複的中心點監控漂移
3. **有些因子不獨立** —— 例如流量與壓力(節流閥會補償),要確認實際變化的是什麼
4. **響應常有最佳點而非單調** —— O₂ 比例是典型例子,線性模型會完全誤導

### 4.6.3 COO 與 PM

**擁有成本(Cost of Ownership)** 的組成:
- 機台折舊
- **消耗件**(聚焦環、噴淋頭、內襯、ESC)—— 先進蝕刻機台的大宗
- 氣體(尤其 C₄F₆、NF₃ 等特殊氣體)
- 電力(RF 電源效率、泵浦)
- **停機損失**(PM 時間 + seasoning 時間 + 重新驗證)
- 廢氣處理

**PM 週期的決定**:不是固定時間,而是由**製程漂移速率**與**微粒趨勢**決定。理想是用 FDC 指標做**預測性維護**,而非固定排程。

### 4.6.4 安全

**氣體安全分級與管制**(呼應 2.2.4):

| 風險 | 管制措施 |
|---|---|
| **自燃(SiH₄, B₂H₆, PH₃)** | 雙套管、氣體偵測連鎖、限流孔、緊急關斷、專用氣瓶櫃 |
| **劇毒(Cl₂, HBr, WF₆, F₂, NF₃)** | 偵測器、負壓排氣、SCBA、洩漏應變程序 |
| **腐蝕(BCl₃, HBr, HF 產物)** | 材質相容、乾燥管路、定期檢漏 |
| **窒息(N₂, Ar, He)** | 密閉空間管制、氧濃度監測 |

**RF 安全**:射頻輻射洩漏、高壓電、匹配盒內的高電壓(即使功率關閉,電容仍可能帶電)。

**廢氣處理(Scrubber)型式**:

| 型式 | 適用 |
|---|---|
| 濕式(Wet) | 水溶性酸性氣體(HCl、HBr、HF) |
| 乾式(Dry / 吸附) | 毒性氣體(SiH₄ 副產物、AsH₃) |
| **燃燒式(Burn / Thermal)** | **PFC 分解** —— CF₄、SF₆、NF₃ |
| 電漿式 | PFC 分解,能耗較低 |

### 4.6.5 環保:PFC 減量

半導體業的溫室氣體排放主要來自 **PFC(全氟化物)**。

| 氣體 | GWP(100 年) |
|---|---|
| CO₂ | 1 |
| CF₄ | 6,630 |
| C₂F₆ | 11,100 |
| **NF₃** | **16,100** |
| **SF₆** | **23,500** |

**四種減量策略**:
1. **製程優化** —— 提高氣體利用率,減少未反應的逃逸(最有效)
2. **氣體替代** —— C₂F₆ → NF₃(雖然 NF₃ 的 GWP 更高,但**分解率接近 100%**,實際排放遠低)
3. **尾氣處理** —— 燃燒式或電漿式 scrubber 分解 PFC
4. **回收再利用**

**關鍵觀念**:GWP 高不代表排放多。真正重要的是 **GWP × 逃逸量**。NF₃ 在遠端電漿源中幾乎完全分解,所以雖然 GWP 高,實際的碳當量排放遠低於 C₂F₆。這是常被誤解的一點。

### 4.6.6 案例研討(5 個真實情境)

每個案例的格式:給現象與資料 → 學員提出假設與驗證計畫 → 揭曉根因與處置。

1. **蝕刻率逐日下降 3%,recipe 未動** —— 線索:匹配電容位置持續漂移、OES F 訊號下降。根因:噴淋頭孔徑被沉積物縮小
2. **單一機台的 CD 比其他三台大 2 nm** —— 線索:聚焦環壽命最長。根因:聚焦環消耗導致邊緣鞘層傾斜
3. **首片良率異常,第二片後正常** —— 線索:清潔後未做 seasoning。根因:first wafer effect
4. **特定產品的閘極漏電偏高** —— 線索:該產品天線比最大。根因:充電損傷,需加天線二極體或改脈衝電漿
5. **微粒數在 PM 後三天內攀升** —— 線索:發生在關電漿瞬間。根因:懸浮微粒落下,需改為功率緩降

## L4 結業測驗

**必考觀念**:

- 低開口率的終點策略選擇
