## 3.1 蝕刻機制(3.0 h)

### 學習目標
- 區分四種蝕刻機制及其 profile 特徵
- 解釋 Coburn–Winters 協同效應為什麼是電漿蝕刻的理論基石
- 說明選擇比的三種來源

### 3.1.1 四種機制

| 機制 | 驅動 | Profile | 選擇比 | 蝕刻率 |
|---|---|---|---|---|
| **物理濺鍍** | 純離子動量轉移 | 異向,但有 45° 斜面效應 | **極差**(對誰都差不多) | 低 |
| **純化學蝕刻** | 中性自由基 | **完全等向** | 極佳 | 高 |
| **離子輔助(反應性離子蝕刻)** | 離子 + 自由基協同 | 異向 | 好 | 高 |
| **抑制劑輔助(側壁鈍化)** | 離子 + 自由基 + 聚合物 | **高度異向** | 極佳 | 中 |

**現代電漿蝕刻 = 後兩者的組合。** 這一句是本章的主軸。

### 3.1.2 Coburn–Winters 實驗:整個領域的奠基實驗

1979 年的經典實驗,用 XeF₂(純化學)與 Ar⁺ 束(純物理)分別與同時作用於 Si:

| 階段 | 條件 | Si 蝕刻率(相對) |
|---|---|---|
| 1 | 只有 XeF₂ 氣體 | ~5 |
| 2 | **XeF₂ + Ar⁺ 離子束** | **~55** |
| 3 | 只有 Ar⁺ 離子束 | ~2 |

**5 + 2 = 7,但一起用得到 55。** 協同效應讓蝕刻率放大近 8 倍。

**為什麼會這樣**(機制解釋):
- 自由基單獨作用時,反應停在表面形成的 SiFx 層,後續反應受限
- 離子轟擊提供活化能:打斷 Si–Si 鍵、產生懸鍵、把 SiFx 打成揮發性 SiF₄ 脫附、混合表面層
- 離子單獨作用時,沒有化學物種可反應,只能靠純動量濺鍍(效率極低)

**這個實驗解釋了異向性的根本**:
- **底部**:有離子 + 有自由基 → 協同 → 蝕刻快
- **側壁**:只有自由基(離子垂直入射打不到) → 蝕刻慢
- → 底部快、側壁慢 = **垂直側壁**

### 3.1.3 側壁鈍化:第二層保險

光靠協同效應,側壁還是會被化學蝕刻慢慢咬。所以現代製程加上第二個機制:**在側壁長一層保護膜**。

三種鈍化層來源:

| 來源 | 鈍化層成分 | 典型製程 |
|---|---|---|
| **氟碳聚合物** | CFx 聚合物 | 介電質蝕刻(C₄F₈) |
| **氧化型鈍化** | SiOBr / SiOCl | Poly-Si 蝕刻(HBr/Cl₂ + O₂) |
| **光阻濺鍍再沉積** | 碳質膜 | 早期製程,現多視為缺陷來源 |

**運作邏輯**(這是 L3 最重要的一段圖像):

```
鈍化層均勻沉積在所有表面
        ↓
底部:垂直離子轟擊持續把它打掉 → 露出材料 → 蝕刻繼續
側壁:離子打不到 → 鈍化層保留並持續增厚 → 蝕刻停止
        ↓
結果:垂直側壁
```

**這也解釋了選擇比**:遮罩(光阻/硬遮罩)頂部雖然被轟擊,但若鈍化沉積速率夠快,淨消耗就低。

### 3.1.4 選擇比的三種來源

| 來源 | 機制 | 範例 |
|---|---|---|
| **化學選擇性** | 產物揮發性差異 | F 蝕刻 Si 快、蝕刻 SiO₂ 慢(需離子破 Si–O) |
| **鈍化選擇性** | 聚合物在不同材料上的淨累積差異 | SiO₂ 有氧消耗聚合物 → 蝕刻;Si 無 → 停止 |
| **閾值選擇性** | 濺鍍閾值能量差異 | 降低 IEDF 使其低於下層材料閾值 |

**選擇比計算**:

```
S = R_target / R_underlayer
```

實務要求:
- Poly gate 對 gate oxide:**> 100**(oxide 只有 1–2 nm,打穿就完蛋)
- 接觸孔 SiO₂ 對 Si:> 20
- SiN spacer 對 Si:> 10

**工程師直覺**:選擇比幾乎永遠是靠**鈍化**做出來的,不是靠化學本身。所以「提高選擇比」= 「加聚合性氣體 / 降 bias / 降 O₂」,而這三者都會降蝕刻率。**選擇比與蝕刻率是根本性的 trade-off。**

### 3.1.5 濺鍍產額與角度效應

```
Y(E) ∝ ( √E − √E_th )     (Sigmund 近似,閾值附近)
```

**角度依賴是關鍵**:濺鍍產額在**入射角 45–70°** 時達到最大,垂直入射(0°)反而不是最高。

**後果**:
- 溝槽的斜面部位被濺鍍得最快 → **faceting**(遮罩肩部被削成斜角)
- 遮罩肩部一旦削出斜面,CD 就開始變大 → CD 控制惡化
- 這也是 **microtrenching** 的成因之一(3.3)

## 3.2 主要蝕刻應用(4.0 h)

### 學習目標
- 對五大蝕刻應用,說出材料、氣體、機台型式與關鍵挑戰
- 解釋 Bosch 製程的循環邏輯與 scallop 的來源

每個應用的敘述格式統一:**目標 → 挑戰 → 氣體設計 → 參數策略 → 常見問題**。

### 3.2.1 Poly-Si Gate 蝕刻

**目標**:在 1–2 nm 的閘極氧化層上蝕刻 50–100 nm 的多晶矽,CD 控制到 nm 級。

**挑戰**:對 gate oxide 選擇比要 > 100;CD 均勻度;不能有 footing 或 notching。

**氣體設計**:`Cl₂ / HBr / O₂`(+ CF₄ 於 BT 步)

**三步策略**:

| 步驟 | 目的 | 特徵 |
|---|---|---|
| **BT**(Breakthrough) | 打穿原生氧化層 | 低壓、高 bias、含氟或純 Cl₂、時間控制 |
| **ME**(Main Etch) | 主要蝕刻,建立 profile | 中壓、Cl₂+HBr+O₂、OES 終點 |
| **OE**(Over Etch) | 清乾淨殘留、保護 oxide | **高壓、低 bias、高 HBr** → 轉向化學、高選擇比 |

**為什麼 OE 要改成高壓低 bias**:此時已接近 gate oxide,必須把離子能量降到 oxide 的濺鍍閾值以下,靠純化學把殘留的 Si 清掉。**這是「閾值選擇性」的教科書應用。**

**常見問題**:notching(SOI 或高選擇比 OE 時)、微負載、footing。

### 3.2.2 介電質接觸孔 / 高深寬比蝕刻

**目標**:在 SiO₂ / SiN / ONO 疊層蝕出 AR 10:1 到 60:1 的孔(3D NAND 可到 100:1)。

**挑戰**:ARDE、bowing、twisting、遮罩選擇比、底部殘留。

**氣體設計**:`C₄F₈ 或 C₄F₆ / Ar / O₂`(+ CO、CH₂F₂ 微調)

**參數策略**:
- **CCP 高離子能量**(數 kV 級)—— 必須打斷 Si–O 鍵並穿透深孔
- 低壓(維持方向性)
- 高聚合氣體(側壁保護 + 對遮罩選擇比)
- O₂ 微調聚合物厚度 —— **這是最敏感的旋鈕**

**先進節點的手段**:
- 低溫 / cryo 蝕刻(−20 到 −60 °C)提升鈍化與選擇比
- 高能量 + 脈衝偏壓,壓窄 IEDF
- 利用負離子中和深孔充電

### 3.2.3 SiN Spacer 蝕刻

**目標**:在 Si 與 SiO₂ 上蝕刻 SiN,保留側壁 spacer,不咬進基板。

**氣體設計**:`CH₂F₂ / CH₃F + O₂ + Ar`(低 F/C,高聚合)

**關鍵**:對 Si 選擇比靠聚合物在 Si 上淨累積、在 SiN 上被 N 消耗的差異。O₂ 比例是選擇比的主旋鈕。

**現代替代**:**準原子層蝕刻(Quasi-ALE)** —— 沉積一層薄聚合物,再用 Ar 電漿活化反應,循環進行。選擇比與 CD 控制遠優於連續蝕刻(見 4.4)。

### 3.2.4 金屬蝕刻:Al 與 W

**Al 蝕刻**:`Cl₂ / BCl₃ / N₂`(+ CHF₃)

三個獨特難題:
1. **原生 Al₂O₃ 必須先移除** → BCl₃ 提供 B 抓氧,這是 BCl₃ 不可取代的原因
2. **側壁殘留 Cl 造成大氣腐蝕** → 出腔後必須做 H₂O 電漿或 NH₃ 處理、DI 水沖洗。**未處理的晶圓幾小時內金屬線就被吃斷**
3. **Cu 含量**(Al-Cu 合金)產生不揮發 CuClx 殘留 → 需要額外物理轟擊

**W 蝕刻**:`SF₆ / NF₃ + O₂`,產物 WF₆ 揮發性佳,相對容易。

**Cu 為什麼不能蝕刻**:所有 Cu 鹵化物沸點都太高(CuCl₂ 993 °C)。業界解法是**大馬士革製程** —— 先蝕介電質溝槽,電鍍填 Cu,再 CMP 磨平。這是製程整合被材料化學逼著轉彎的最著名案例。

### 3.2.5 深矽蝕刻:Bosch 製程

**目標**:MEMS、TSV,深度數十到數百 µm,AR 可達 30:1 以上。

**Bosch 循環**(三步交替,每循環數秒):

```
┌─→ [沉積]  C₄F₈ 電漿 → 全表面鋪一層 Teflon 狀聚合物 (~50 nm)
│      ↓
│   [清底]  高 bias 短脈衝 → 只把溝底的聚合物打掉(側壁保留)
│      ↓
└── [蝕刻]  SF₆ 電漿 → F 等向性快速蝕刻裸露的 Si (~0.5-2 µm)
```

**為什麼要分開**:SF₆ 蝕刻率極高但完全等向。單獨用會把側壁咬爛。分成循環後,側壁在蝕刻步只暴露很短時間就被下一輪聚合物覆蓋。

**Scallop(扇貝紋)**:每個循環在側壁留下一個半圓形凹痕,深度 50–500 nm。

- 循環時間短 → scallop 小 → 側壁光滑,但產率低
- 循環時間長 → scallop 大 → 側壁粗糙,但蝕刻快

**改良**:混合模式(pseudo-Bosch,SF₆ + C₄F₈ 同時通,連續蝕刻)可得光滑側壁但速率較低。

## 3.3 缺陷圖鑑 ★(4.0 h)

> **本階旗艦模組。** 這是工程師最常回頭查的一章,設計成可獨立瀏覽的圖鑑。

### 學習目標
- 由 SEM 剖面特徵辨識 18 種常見缺陷
- 對每種缺陷說出主要成因與 2–3 個對策旋鈕
- 理解「同一個症狀可能有多個成因」,並知道如何區分

### 3.3.1 圖鑑條目格式

每一條缺陷固定五個欄位:

```
【症狀】     SVG 剖面示意圖 + 一句話描述
【物理成因】 完整因果鏈
【診斷區分】 如何跟長得像的其他缺陷區分開
【對策】     旋鈕方向 + 預期副作用
【相關】     連到其他缺陷與章節
```

### 3.3.2 深寬比相關

**① ARDE / RIE Lag(深寬比依賴蝕刻)**
- **症狀**:窄溝槽比寬溝槽淺。同時蝕刻,深度不同
- **成因**(四個疊加):
  1. **Knudsen 傳輸限制** — 中性自由基難以進入深窄孔
  2. **離子遮蔽** — 有角度分佈的離子被孔壁攔截
  3. **產物排出困難** — SiF₄ 出不來,阻礙反應
  4. **孔底充電** — 正電荷累積排斥後續離子
- **對策**:降壓(增加離子方向性)、提高離子能量、脈衝電漿(中和充電)、降低自由基黏著係數
- **反向 ARDE**:某些製程窄孔反而更快(聚合物在窄孔沉積受限),要能分辨

**② Inverse RIE Lag**
- **症狀**:窄的反而深
- **成因**:聚合物前驅物(黏著係數高)進不去窄孔 → 窄孔鈍化少 → 蝕刻快
- **意義**:出現這個現象代表製程處於高聚合區,可作為診斷線索

**③ Microloading(微負載)**
- **症狀**:高圖形密度區域蝕刻較慢
- **成因**:局部自由基被大量消耗(反應物耗盡)
- **對策**:提高流量/自由基供應、降低壓力提升傳輸

**④ Macroloading(巨負載)**
- **症狀**:整片晶圓的蝕刻率隨開口率變化;或第一片與最後一片不同
- **成因**:全腔體自由基被消耗;開口率大 → 消耗多 → 蝕刻率低
- **對策**:調整開口率設計、補償時間、提高氣體供應

### 3.3.3 Profile 形狀缺陷

**⑤ Undercut(側蝕)**
- **症狀**:遮罩下方被橫向咬入
- **成因**:側壁鈍化不足;化學蝕刻成分過強;壓力過高
- **對策**:加聚合性氣體、降壓、降溫、加 O₂(對 Si 系)

**⑥ Bowing(弓形)**
- **症狀**:側壁中段向外鼓出,像個桶子
- **成因**:離子在遮罩肩部斜面**反射/散射**打向側壁中段;或側壁鈍化在中段不足
- **診斷區分**:bowing 最寬處在中段(vs undercut 在頂部)
- **對策**:改善遮罩 profile(減少 faceting)、增加聚合、降低離子角度發散、降壓

**⑦ Tapered / Sloped(錐形)**
- **症狀**:上寬下窄
- **成因**:鈍化過度;離子通量隨深度衰減;遮罩本身有斜角
- **對策**:降聚合性氣體、加 O₂、提高 bias

**⑧ Notching(缺口)**
- **症狀**:靠近底部界面處出現橫向凹口,常見於 SOI 或 poly on oxide,且**只出現在圖形陣列的邊緣**
- **成因**:**充電效應**。絕緣底層累積正電荷,使後續離子軌跡偏折,集中轟擊某一側側壁。陣列邊緣的不對稱幾何讓偏折更嚴重
- **診斷區分**:notching 有明顯的方向性與位置選擇性(陣列邊緣),undercut 則普遍發生
- **對策**:**脈衝電漿**(讓電子在 off 期中和充電)、降低離子能量、縮短 over etch、降低 electron shading

**⑨ Microtrenching(微溝槽)**
- **症狀**:溝底兩側各有一道更深的小溝
- **成因**:離子從側壁**鏡面反射**後集中打在溝底邊緣;側壁鈍化層造成的離子偏折
- **對策**:降低離子入射角發散、調整鈍化厚度、降壓提升方向性

**⑩ Footing(腳)**
- **症狀**:底部界面處未蝕乾淨,呈現外擴的「腳」
- **成因**:底層為絕緣體時的充電;或界面處鈍化累積;或選擇比過高導致停止太早
- **對策**:延長 OE、提高該階段 bias、脈衝電漿

**⑪ Twisting / Wiggling(扭曲)**
- **症狀**:HAR 孔在深處歪掉、彼此靠近甚至相交
- **成因**:充電導致的離子偏折累積;遮罩應力導致的變形
- **對策**:降低遮罩應力、脈衝電漿、優化遮罩材料(改用非晶碳硬遮罩)

**⑫ Striation(條紋)**
- **症狀**:側壁出現垂直細紋
- **成因**:光阻邊緣粗糙度(LER)被複製到下層;遮罩局部剝落
- **對策**:改善光阻 trim、加入遮罩硬化步驟

### 3.3.4 遮罩相關

**⑬ Faceting(肩部削角)**
- **成因**:濺鍍產額的角度依賴(3.1.5),45–70° 面被削得最快
- **後果**:CD 放大、遮罩過早消耗
- **對策**:降 bias、加聚合、換硬遮罩

**⑭ 遮罩選擇比不足 / 遮罩耗盡**
- **後果**:CD 失控、圖形消失
- **對策**:加聚合、降 bias、改用非晶碳或金屬硬遮罩

**⑮ Resist Wiggling / Pattern Collapse**
- **成因**:光阻高深寬比 + 應力 + 加熱軟化
- **對策**:降低晶圓溫度、降低製程時間、改硬遮罩

### 3.3.5 殘留與污染

**⑯ Etch Stop(蝕刻停止)**
- **症狀**:HAR 孔蝕到一半完全停住
- **成因**:聚合物在孔底淨累積超過移除速率;或自由基/離子無法抵達
- **對策**:降聚合、加 O₂、提高離子能量、脈衝製程、分段 recipe

**⑰ 聚合物殘留 / Veil(圍籬)**
- **症狀**:圖形周圍留下一圈膜狀殘留
- **成因**:側壁鈍化層在蝕刻結束後未被移除
- **對策**:加入 O₂ 灰化步、濕式清洗、降低鈍化強度

**⑱ 金屬腐蝕(Corrosion)**
- **症狀**:Al 線路在出腔數小時後斷線、長出白色生成物
- **成因**:殘留 Cl 遇大氣濕氣生成 HCl,持續腐蝕 Al
- **對策**:**強制後處理** —— H₂O 電漿 / NH₃ 處理 / DI 沖洗,且出腔到後處理的等待時間必須管制
- **安全等級**:此項在圖鑑中標記為「高風險」,配安全提醒方塊

### 3.3.6 診斷流程

給一套可操作的收斂流程:

```
1. Recipe 有沒有動?
```

## 3.4 電漿沉積(4.0 h)

### 學習目標
- 說明 PECVD 為什麼能在低溫沉積、代價是什麼
- 解釋 HDP-CVD 為什麼填得進高深寬比溝槽
- 說明 PEALD 的自限制機制與階梯覆蓋率優勢

### 3.4.1 PECVD 基本原理

**核心價值**:熱 CVD 沉積 SiN 要 700–800 °C,PECVD 只要 **300–400 °C**。因為電漿用電子能量取代熱能來解離前驅物。這讓沉積能在有金屬線的晶圓上進行(Al 熔點 660 °C,製程上限約 450 °C)。

**代價**:
- 膜中含大量 **氫**(Si–H、N–H 鍵),影響膜質與可靠度
- 膜密度較低、蝕刻率較高
- 有電漿誘發損傷風險
- 階梯覆蓋率不如熱 CVD/ALD

### 3.4.2 主要 PECVD 膜種

| 膜 | 前驅物 | 用途 |
|---|---|---|
| **SiO₂** | SiH₄ + N₂O 或 **TEOS + O₂** | ILD、passivation |
| **SiN** | SiH₄ + NH₃ + N₂ | passivation、蝕刻停止層、應力層 |
| **SiON** | SiH₄ + N₂O + NH₃ | 抗反射層、調折射率 |
| **a-Si** | SiH₄ | TFT、犧牲層 |
| **SiOC / SiCOH(low-k)** | 有機矽前驅物 + 造孔劑 | 先進 BEOL 介電質 |
| **非晶碳(a-C)** | C₃H₆ / C₂H₂ | 硬遮罩 |

**TEOS 為什麼比 SiH₄ 好**:TEOS 分子在表面**遷移率高**(黏著係數低),沉積後能移動到凹處 → **階梯覆蓋率遠優於 SiH₄**。代價是需要液態源汽化系統。這是 2.3.5 黏著係數概念的直接應用。

### 3.4.3 膜特性的控制

| 特性 | 主旋鈕 | 機制 |
|---|---|---|
| **應力**(壓/張) | **低頻功率比例** | 低頻 → 離子能量高 → 離子撞擊致密化 → **壓應力**;高頻 → 低轟擊 → 張應力 |
| 折射率 | 氣體比(Si/N 比) | 富矽 → n 高 |
| 氫含量 | 溫度、NH₃ 比例 | 溫度高 → H 少 → 膜緻密 |
| 沉積率 | 前驅物流量、功率 | — |
| 均勻度 | 噴淋頭設計、gap、壓力 | — |

**應力控制的重要性**:SiN 應力層(strained layer)是提升 MOSFET 遷移率的標準技術。應力要能從 −3 GPa(壓)調到 +1.5 GPa(張),全靠雙頻功率比。

**常見誤解**:「應力靠溫度調」。
**正解**:溫度是次要旋鈕。**主旋鈕是低頻(LF)功率比例**,它決定離子轟擊致密化的程度。

### 3.4.4 階梯覆蓋率與填溝

**階梯覆蓋率(Step Coverage)**:

```
Step Coverage = 側壁(或底部)膜厚 / 頂部膜厚
```

**為什麼 PECVD 會夾 void**:

```
高黏著係數的前驅物 → 撞到什麼就黏什麼
        ↓
溝槽開口處通量最高 → 長最快
        ↓
開口先合攏(cusping / bread-loafing)
        ↓
內部封閉 → 形成 void(空洞)
```

Void 是可靠度殺手 —— 後續 CMP 或熱製程會讓它裂開。

### 3.4.5 HDP-CVD:邊沉積邊濺鍍

**核心概念**:同時進行**沉積**(SiH₄/O₂)與**濺鍍**(Ar⁺ 高 bias)。

```
淨沉積率 = 沉積率 − 濺鍍率
D/S ratio = Deposition / Sputter
```

**為什麼能填溝**:濺鍍產額在 45° 最大(3.1.5)→ **開口處剛形成的 cusp 正好是 45° 斜面 → 被優先濺掉**。開口保持敞開,溝槽由下往上填滿。

**被濺掉的材料還會重新沉積到溝底** —— 進一步幫助由下而上填充。

**極限**:AR 太高(> 6:1)時濺鍍再沉積會在溝底形成「帽子」而夾 void。這是 HDP-CVD 被 **流動式 CVD(FCVD)** 與 **旋塗介電質** 在先進節點取代的原因。

### 3.4.6 PEALD:自限制的沉積

**四步循環**:

```
1. [前驅物脈衝]  前驅物吸附到表面,**自限制**於一個單層
2. [Purge]       抽走多餘前驅物(關鍵!殘留會造成 CVD 模式)
3. [電漿脈衝]    電漿產生的自由基與吸附層反應,形成薄膜並移除配位基
4. [Purge]       抽走副產物
   ↓ 重複,每循環 ~0.05–0.1 nm
```

**自限制是一切的關鍵**:因為第 1 步吸附滿了就停,所以**厚度只由循環數決定**,與流量、時間、位置都無關。

**帶來的三個優勢**:
1. **階梯覆蓋率接近 100%** —— 深孔內外一樣厚
2. **厚度控制到原子級** —— 循環數即厚度
3. **均勻度極佳** —— 不依賴流場均勻

**PEALD vs 熱 ALD**:電漿提供高活性自由基 → 可在更低溫進行、膜質更好、可沉積熱 ALD 做不到的材料(如金屬氮化物)。代價是**方向性** —— 電漿自由基在深孔底部較少,極高 AR 時 PEALD 的覆蓋率反而不如熱 ALD。

**主要應用**:HKMG 的 HfO₂、spacer SiN、DRAM capacitor、封裝阻障層、多重曝光的 spacer(SADP/SAQP)。

## 3.5 濺鍍 PVD 與其他應用(2.5 h)

### 學習目標
- 說明磁控濺鍍為什麼比二極濺鍍有效率
- 解釋反應式濺鍍的遲滯現象
- 說出灰化與腔體清潔的設計邏輯

### 3.5.1 濺鍍基礎

**濺鍍產額 Y**:每個入射離子平均打出幾個靶材原子。

| 靶材 | Y(Ar⁺ 500 eV) |
|---|---|
| Al | ~1.0 |
| Ti | ~0.6 |
| Cu | ~2.3 |
| W | ~0.6 |
| Ta | ~0.6 |

**閾值能量 E_th** 約為昇華熱的 4 倍,典型 20–40 eV。低於此不濺鍍。

**濺鍍原子的能量**:1–10 eV,遠高於蒸鍍(~0.1 eV)→ 附著力好、膜緻密。這是 PVD 的核心優勢。

### 3.5.2 磁控濺鍍(Magnetron)

**問題**:單純的二極濺鍍游離效率低,需要高壓才能維持電漿,但高壓會散射濺出的原子。

**解法**:在靶材背後放磁鐵,產生平行靶面的磁場。電子被 **E × B 漂移** 束縛在靶面附近繞圈,路徑長度大增 → 游離效率大增 → **可在 1–5 mTorr 的低壓運作**。

**代價:Racetrack 侵蝕**
電子被束縛在特定環形區域 → 該處離子轟擊最強 → 靶材被挖出一圈溝。

- 靶材利用率只有 **20–40%**
- 侵蝕輪廓改變 → 沉積率與均勻度隨靶材壽命漂移 → 需要 **kWh 補償**
- 解法:旋轉磁鐵、多磁鐵組態

### 3.5.3 反應式濺鍍與遲滯

用金屬靶 + 反應氣體(N₂ 或 O₂)沉積化合物膜(TiN、TaN、AlN、ITO)。

**遲滯(hysteresis)現象**:

```
金屬模式(N₂ 少) → 高沉積率、膜偏金屬
     ↓ N₂ 增加到臨界點,靶面被氮化
中毒模式(poisoned) → 沉積率驟降(化合物濺鍍產額低)
     ↓ N₂ 減少,但要降到比原臨界點更低才會恢復
```

**這是一個不穩定的雙值區**,製程若設在中間會來回跳。

**對策**:
- 用 **OES 或靶電壓做閉迴路回饋控制**,把工作點鎖在過渡區
- 提高抽速讓遲滯迴圈變窄
- 脈衝 DC 供電

**TiN 的顏色是製程指標**:化學計量的 TiN 是金黃色,富 Ti 偏銀灰,富 N 偏棕。目視就能粗判。

### 3.5.4 進階 PVD

- **離子化 PVD(IMP / iPVD)**:在靶與晶圓間加 ICP 線圈,把濺出的中性原子游離 → 可用晶圓 bias 控制入射方向 → **改善高深寬比孔的底部覆蓋**
- **準直濺鍍(Collimated)**:加金屬柵格擋掉斜向原子,代價是沉積率大降
- **長距離濺鍍(Long-throw)**:拉大靶到晶圓距離,只讓垂直的原子抵達

### 3.5.5 光阻灰化(Ashing / Strip)

**目標**:去除光阻,不損傷下層。

**主氣體**:O₂(O + 光阻 → CO₂ + H₂O)

**添加**:
- N₂ / H₂ → 用於 low-k 製程,避免 O₂ 抽走 low-k 膜裡的碳(**碳耗盡會使 k 值上升**)
- CF₄ 微量 → 幫助去除離子佈植後硬化的表層光阻

**為什麼用 downstream/remote**:
- 灰化不需要方向性(要移除的是整層)
- 離子轟擊會造成閘極損傷與充電
- → **把電漿放在上游,只送 O 自由基下來** = 高速率 + 零損傷

**離子佈植後光阻(implanted resist)的難題**:高劑量佈植會讓光阻表層碳化成殼,一般 O₂ 灰化去不掉且會爆殼噴出微粒。需要低溫起步、慢速升溫的分段 recipe。

### 3.5.6 腔體清潔

**目的**:移除腔內累積的沉積物,避免剝落成微粒、避免製程漂移。

**主流:NF₃ 遠端電漿清潔**
- 遠端源解離 NF₃ 產生大量 F
- F 進入腔體與 SiO₂/SiN 反應成 SiF₄ 抽走
- **無離子 → 不傷腔體零件**,可頻繁執行(常常每片之間都做)

**為什麼 NF₃ 取代 C₂F₆**:解離率高(遠端源中幾乎 100% 分解)→ 清潔快、氣體用量少、**逃逸的溫室氣體少**。

**Seasoning(預膜)**:清潔後腔壁變成裸露的鋁或陽極處理面,表面複合係數與帶製程時不同 → 第一片製程結果會偏(first wafer effect)。所以清潔後要跑 seasoning wafer 或 dummy 沉積,把腔壁恢復到穩態。

## 3.6 均勻度與腔體工程(2.5 h)

### 學習目標
- 由均勻度 map 的形狀推論成因
- 說明 ESC 的兩種夾持原理與 He 背吹的角色
- 解釋 first wafer effect 與 seasoning

### 3.6.1 均勻度的量化

```
不均勻度 (%) = (Max − Min) / (2 × Mean) × 100      [半幅]
1σ / Mean × 100                                     [標準差法]
```

務必註明用哪種定義 —— 半幅法算出來的數字大約是 1σ 法的 2–3 倍,兩邊在對數字時常常雞同鴨講。

### 3.6.2 由 Map 形狀反推成因

這是本節最實用的一張表:

| Map 形狀 | 可能成因 |
|---|---|
| **中心快**(bull's eye) | 氣體從中心進、電漿密度中心高、中心溫度低 |
| **邊緣快** | 邊緣自由基供應足、聚焦環消耗、邊緣鞘層畸變 |
| **W 形 / M 形** | 氣流與電場效應疊加,或噴淋頭孔徑分佈 |
| **單邊偏斜**(tilt) | **泵口方向的抽氣不對稱**、機械傾斜、RF 進入點不對稱 |
| **同心圓環紋** | 噴淋頭多區設計的分區邊界、多區溫控邊界 |
| **極邊緣急降/急升(edge roll)** | 聚焦環高度與消耗、edge exclusion、晶圓夾持 |
| **隨機斑點** | 微粒、背面污染造成局部溫度異常 |

**單邊偏斜是最容易確認的一種**:轉 90° 放晶圓再跑一次。若圖形跟著轉 → 晶圓/圖形問題;若不跟著轉 → **腔體幾何問題**(泵口、RF 饋入)。這個「轉片實驗」應該是每個工程師的標配。

### 3.6.3 影響均勻度的硬體

| 零件 | 影響 | 消耗特性 |
|---|---|---|
| **噴淋頭(Showerhead)** | 氣流分佈、RF 電場分佈 | 孔徑被沉積物堵塞 → 分佈改變 |
| **聚焦環(Focus Ring)** | 晶圓邊緣的鞘層形狀 | **消耗最快的零件** → 邊緣蝕刻率隨壽命漂移 |
| **邊緣環 / Edge ring** | 邊緣電場終結 | 同上 |
| **腔體內襯(Liner)** | 自由基表面複合、熱環境 | 沉積累積 |
| **ESC 表面** | 熱接觸、夾持 | 磨損、He 洩漏上升 |

**聚焦環是先進製程的關鍵消耗件**:它一消耗,晶圓邊緣的鞘層就從垂直變成傾斜 → 邊緣圖形開始傾斜(edge tilt)。先進機台已導入 **可動聚焦環(自動補償高度)**。

### 3.6.4 溫度控制:ESC 與 He 背吹

**靜電夾盤(ESC)兩種原理**:

| 型式 | 原理 | 材料 | 特性 |
|---|---|---|---|
| **庫倫式(Coulombic)** | 純靜電吸引,介電質絕緣 | Al₂O₃ | 需高電壓(數 kV),脫附快 |
| **Johnsen–Rahbek** | 微弱漏電流在界面累積電荷,吸附力大 | 摻雜陶瓷(半導體性) | 低電壓(數百 V),吸力強,**脫附較慢(殘留吸附)** |

**He 背吹為什麼不可少**:真空中沒有對流,晶圓與 ESC 之間即使貼合也只有微觀點接觸,熱阻極大。灌入 5–20 Torr 的 He 填滿微觀間隙 → 熱傳導係數提升數十倍。

**He 洩漏率是最重要的機台健康指標之一**:
- 洩漏上升 → 夾持不良或 ESC 磨損 → 晶圓局部過熱 → 製程飄、光阻燒焦
- 應納入每片監控與 FDC(L4 4.2)

**多區溫控**:先進 ESC 有 2–10 個獨立控溫區,可刻意做出徑向溫度梯度來補償蝕刻率不均。**溫度是修均勻度最直接的旋鈕**(因為蝕刻率的 Arrhenius 依賴)。

### 3.6.5 腔體記憶:First Wafer Effect 與 Seasoning

**現象**:PM 或清潔後的第一片(甚至前幾片)結果與穩態不同。

**物理原因**:
1. **表面複合係數改變** —— 乾淨的金屬壁對 F、O 自由基的複合率高 → 自由基被吃掉 → 蝕刻率低
2. **腔壁溫度未達穩態** —— 前幾片的熱環境不同
3. **腔壁吸附的水氣與殘留氣體** 慢慢釋放
4. **腔體記憶(memory effect)** —— 前一道製程的殘留物參與反應

**對策**:
- **Seasoning**:清潔後跑數片 dummy,讓腔壁回到製程狀態
- **Idle time 管制**:機台閒置越久,腔壁狀態偏離越多 → 設定 idle 上限與 idle 後的預跑
- **腔壁溫控**:主動加熱腔壁到定溫,減少熱漂移
- 監控:**OES 基線** 與 **匹配電容位置** 是最靈敏的腔體狀態指標

### 3.6.6 微粒與電弧

**微粒來源**:
- 腔壁沉積物剝落(熱應力循環)
- 電漿中懸浮的**負電微粒**(被鞘層電場困在 bulk 邊界)—— 關電漿的瞬間電場消失,微粒全部落到晶圓上
- 零件磨損、機械手臂

**對策**:
- **關電漿時緩降功率**(ramp down)而非硬切,讓微粒有時間被氣流帶走
- 定期清潔與 PM
- 抑制電弧(arcing)—— 電弧是微粒與零件損傷的主因

**電弧的成因**:局部電場集中(尖角、剝落處)、絕緣件表面污染、Paschen 谷底的寄生放電(L1 1.4.2)。現代 RF 電源有 arc detection 並會瞬間切斷。

## 3.7 封裝電漿清潔與表面處理(2.5 h)

**規劃完成後增補的模組。** 前段的電漿製程講完之後,後段(封裝廠)的電漿幾乎是
另一個世界:目標不是把材料刻掉,而是**把表面弄乾淨、弄粗、弄親水**;
材料不是矽而是有機物;溫度上限不是 80 °C 而是 **~100–150 °C 就開始劣化**;
面積不是 300 mm 晶圓而是整條料條或整盤基板。

### 學習目標
- 說出封裝電漿的四個實際用途,以及各自「不做會怎樣」
- 解釋為什麼封裝端幾乎不用氟系氣體
- 用表面能/接觸角判斷處理是否足夠,以及為什麼會「處理過頭」
- 區分低壓電漿與大氣電漿(APPJ / 電暈)的適用場合
- 說明疏水回復(hydrophobic recovery)為什麼決定了製程的等待時間上限

### 3.7.1 四個用途:不做會怎樣

| 用途 | 目標 | 不做的後果 |
|---|---|---|
| **打線前 pad 清潔** | 去除 Al/Cu pad 上的有機殘留與氧化物 | 銲球不沾、**NSOP**(non-stick on pad)、拉力測試不過 |
| **封膠前接著力活化** | 提高 die / 基板 / 銅箔的表面能 | **分層(delamination)**、爆米花現象、可靠性測試(MSL)失效 |
| **助焊劑殘留去除** | 清掉迴銲後的助焊劑與有機物 | underfill 有孔洞、離子殘留造成電遷移 |
| **Underfill 潤濕** | 讓底填膠爬得進窄間隙 | 填不滿、空洞、熱循環後裂 |

另外一個獨立的題目:**電漿切割(plasma dicing)** —— 它其實是前段的深矽蝕刻
(SF₆ 系、Bosch)被搬到封裝流程裡用,與上面四項的機制完全不同。

### 3.7.2 氣體選用:為什麼不用氟系

前段的直覺是「要刻乾淨就上氟」,封裝端反過來 —— **氟系在這裡幾乎是禁忌**:

| 氣體 | 作用 | 封裝端的角色 |
|---|---|---|
| **Ar** | 純物理濺射 | 最安全的萬用選擇;去氧化層、打粗表面。不引入化學殘留 |
| **O₂** | 氧化、灰化有機物 | 去有機殘留與助焊劑的主力;**但會氧化 Cu/Ag,也會咬有機基板** |
| **H₂**(常配 N₂ 或 Ar) | 還原 | 還原 Cu/Ag 氧化物 —— O₂ 做不到的事只有它做得到 |
| **N₂** | 稀釋、活化、接一點氮 | 大氣電漿的主要載氣;成本低 |
| **CF₄ / SF₆** | 氟化 | **一般不用** —— 見下 |

**為什麼不用氟系(三個理由,全部與前段相反)**:

1. **殘留的氟會腐蝕**。封裝件有大量 Cu、Ag、Al 與焊料,吸附的 F 遇濕氣形成 HF,
   造成後續的腐蝕與可靠性失效。晶圓廠有完整的後處理去氟,封裝線通常沒有。
2. **氟會讓表面變疏水**,正好與「提高表面能」的目標相反 ——
   CF<sub>x</sub> 是鐵氟龍的成分,那是全世界最不沾的東西。
3. **選擇比在這裡沒有意義**,反而是「不要傷到旁邊的東西」比較重要;
   氟系對有機物與金屬都太兇。

**Cu pad 的順序題**:先 O₂ 去有機、再 H₂ 或 Ar 去氧化。
順序顛倒的話 O₂ 又把剛還原好的 Cu 氧化回去。

### 3.7.3 低壓電漿 vs 大氣電漿

| | **低壓電漿**(真空腔) | **大氣電漿**(APPJ / 電暈 / DBD) |
|---|---|---|
| 壓力 | 0.1–1 Torr | 1 atm |
| 均勻度 | 整批一致,**批次處理** | 噴嘴掃過,**線上選擇性處理** |
| 氣體 | Ar / O₂ / H₂ / N₂ 皆可 | 多為 N₂ 或空氣(氣體成本主導) |
| 產能 | 需抽真空,cycle time 長 | inline,無抽真空 |
| 處理深度 | 較均勻,可進窄縫 | 只處理視線可及的表面 |
| 熱負荷 | 低 | **較高** —— 有機材料要小心 |

**選擇邏輯**:要進 BGA 底部或窄縫 → 低壓;要接在 inline 產線上、只處理特定區域
→ 大氣。**不要用大氣電漿處理深孔或屏蔽區**,因為它靠的是視線可及。

### 3.7.4 怎麼知道處理夠了:接觸角與表面能

封裝端沒有「蝕刻深度」可以量,量的是**表面能**:

- **接觸角**(水滴)是最直接的現場指標。Young 方程 → 接觸角越小,表面能越高
- 典型判準:處理前 EMC / PI 約 **70–90°**,處理後要求 **< 30°**(常見規格 < 20°)
- **達因筆 / 達因液**是產線上的快速版本
- 拉力/剪力測試(die shear、wire pull)才是最終驗證,但太慢,不能當製程監控

**兩條非直覺的曲線,是本節的重點**:

1. **飽和**:表面能隨處理時間上升,但很快飽和。
   再延長時間**不會更好**,只是多花 cycle time。
2. **處理過頭**:繼續處理會開始**傷害**基材 —— 有機材料被過度氧化、
   產生低分子量的降解層(LMWOM),接著力反而**下降**。
   加上熱累積,料條可能變形。

→ 所以封裝電漿的製程窗有**上限**,這一點和「蝕刻刻久一點總會刻穿」完全不同。

### 3.7.5 疏水回復:為什麼處理完要趕快接下一站

處理後的高表面能**不是永久的**。極性基團會逐漸翻轉回材料內部,
低分子量物質也會遷移回表面 —— 接觸角在**數小時到數天**內回升。

**現場後果**:電漿處理與下一站(打線 / 封膠 / 底填)之間有**佇留時間上限**(queue time),
通常訂在**數小時**。超過就要重工。這是封裝廠排程的硬約束,
而它的成因是純粹的高分子表面科學,不是電漿的問題。

### 3.7.6 與晶圓級製程的差異總表

| | 前段(晶圓) | 後段(封裝) |
|---|---|---|
| 目的 | 移除材料、定義圖案 | 改變表面狀態 |
| 材料 | Si、SiO₂、SiN、金屬 | 有機物(EMC / PI / 綠漆)+ 金屬 |
| 溫度上限 | 80 °C 級 | **~100–150 °C 就劣化** |
| 尺寸 | 300 mm 晶圓 | 料條、基板、整盤 |
| 主要氣體 | 氟系、氯系 | **Ar / O₂ / H₂ / N₂** |
| 成功指標 | CD、深度、選擇比、profile | **接觸角、接著力、拉力** |
| 製程窗 | 通常「多做一點沒差」 | **有上限,做過頭會壞** |
| 電漿參數 | 高 bias、方向性 | **低能量、無方向性需求** |

**一句話**:前段要的是**方向性**,後段要的是**溫和而均勻**。
所以封裝端幾乎都用低偏壓、遠端或下游電漿 —— 要的是自由基,不是離子轟擊。
