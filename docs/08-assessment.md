# 08 — 評量設計

## 設計原則

1. **考理解不考背誦** —— 不出「Ar 的游離能是多少」這種查表題,出「為什麼 Ar 常被選為濺鍍氣體」
2. **情境優先** —— 高階測驗以現場情境題為主,給資料讓學員判斷
3. **解析比題目重要** —— 每題的答案解析必須解釋**為什麼其他選項錯**,而不只是說哪個對
4. **允許重測但換題** —— 題庫大於出題數,重測時抽不同題,避免背答案
5. **自我檢測不計分** —— 章末檢測是學習工具,只有結業測驗有通過門檻

## 題型

### 型 1:單選題(基礎理解)

```
在 10 mTorr 的 Ar 電漿中,離子穿越鞘層時大約發生幾次碰撞?
(鞘層厚度約 3 mm)

A. 幾乎不碰撞
B. 約 1 次          ← 正解
C. 約 10 次
D. 約 100 次

解析:
10 mTorr 時 λ ≈ 5/10 = 0.5 cm = 5 mm。鞘層厚 3 mm,
所以 3/5 ≈ 0.6,約略是 1 次的量級。
A 錯:那是 1 mTorr(λ ≈ 5 cm)的情況。
C 錯:要到 100 mTorr 才有這個量級。
D 錯:那已經是接近 1 Torr 的高壓 PECVD 條件。
```

### 型 2:多選題(完整性)

```
下列哪些是 ARDE(深寬比依賴蝕刻)的成因?(複選)

□ 中性自由基的傳輸受限        ← 正解
□ 離子被孔壁遮蔽              ← 正解
□ 蝕刻產物排出困難            ← 正解
□ 孔底累積正電荷排斥離子      ← 正解
□ 光阻選擇比不足
□ 腔體壓力控制不穩

解析:前四項是 3.3.2 列出的四個成因。後兩項雖然也會
造成蝕刻問題,但影響全部圖形而非「隨深寬比不同」,
所以不是 ARDE 的成因。
```

### 型 3:數值計算題

```
腔體體積 40 L,製程壓力 30 mTorr,總流量 300 sccm。
滯留時間約為多少秒?

輸入答案:____ 秒   (容差 ±15%)

解析:τ = 79.0 × P[Torr] × V[L] / Q[sccm]
        = 79.0 × 0.03 × 40 / 300 = 0.316 s
```

**容差設計**:計算題允許 ±10–20% 誤差(依題目),因為重點是量級與方法,不是算術精度。

### 型 4:圖形判讀題(L3 主力)

顯示 SVG 剖面圖或 SEM 示意圖,要求命名缺陷或推論成因。

```
[SVG:側壁中段外鼓的溝槽剖面]

這個 profile 缺陷的名稱與最可能的成因是?

A. Undercut — 側壁鈍化不足
B. Bowing — 離子在遮罩肩部散射後打向側壁中段    ← 正解
C. Tapering — 鈍化過度
D. Microtrenching — 離子鏡面反射集中於溝底

解析:最寬處在**中段**是 bowing 的辨識特徵。
A 錯:undercut 的最寬處緊貼遮罩下方(頂部)。
C 錯:tapering 是上寬下窄的錐形,方向相反。
D 錯:microtrench 是溝底兩側的小溝,不影響側壁形狀。
```

### 型 5:情境分析題(L2–L4 主力)

給一段現場情境與資料,問診斷或對策。

```
【情境】
某 poly-Si 蝕刻機台,recipe 三個月未改動。近兩週觀察到:
· 蝕刻率下降約 5%
· 匹配電容 C_load 位置持續往同一方向漂移
· OES 的 Cl 譜線強度上升,SiCl 譜線下降
· He 背吹洩漏率正常
· 節流閥開度略微增大

最可能的根本原因是?

A. 流量計失準,Cl₂ 實際流量偏低
B. 腔體內襯累積沉積物,改變自由基表面複合與阻抗   ← 正解
C. ESC 夾持不良導致晶圓溫度上升
D. RF 電源輸出功率衰減

解析:
關鍵線索是「匹配位置持續單向漂移」+「Cl 上升、SiCl 下降」。
Cl 上升代表反應物沒被消耗完 → 蝕刻反應變慢;
SiCl 下降代表產物變少 → 確認蝕刻率下降。
匹配位置漂移指向腔體電氣特性改變 = 結垢。
A 錯:流量計失準會讓 Cl 譜線**下降**而非上升。
C 錯:He 洩漏率正常,且溫度問題通常表現為均勻度異常。
D 錯:功率衰減會讓 Cl 與 SiCl **同時**下降。
```

**這是最有價值的題型。** L3/L4 的結業測驗應有 30% 以上是這類題。

- 把 DC 輝光的分區依位置排序
- 把氣體與其主要用途配對
- 把 ALE 四步驟排序

## 各階段測驗規格

| 階段 | 題數 | 時限 | 通過 | 題型分佈 |
|---|---|---|---|---|
| **L1** | 20 | 30 min | 75% | 單選 12 / 多選 3 / 計算 3 / 情境 2 |
| **L2** | 30 | 50 min | 75% | 單選 14 / 多選 5 / 計算 5 / 情境 6 |
| **L3** | 40 | 70 min | 75% | 單選 12 / 多選 5 / 圖形 12 / 情境 11 |
| **L4** | 30 | 60 min | **80%** | 單選 8 / 多選 4 / 計算 3 / 圖形 5 / 情境 10 |

**L4 門檻較高(80%)** —— 專家級認證應該有意義。

> **實作補記(這一條被斷言守住了)**
>
> 「L4 一半以上是情境分析與判讀」是 80 % 門檻的**論證前提**,不是修辭。
> 但實作出來的題庫一度只有 10 % 是情境題 —— 也就是說 L4 當時考的仍以記憶型
> 單選為主,80 % 的門檻其實站不住腳。而 `check-quiz.mjs` 當時那條斷言寫成相對式的
> 「L3+L4 占比 > L1 的兩倍」,在 L1 只有 2 % 的情況下照樣全綠,等於用一條
> 永遠會過的斷言守著一個沒做到的規格。
>
> 現已補到 **L4 50 %**(13 題新寫的情境題 + 24 題把既有單選改寫成給數據、
> 要判斷的情境題),並把斷言換成絕對判準 `scenarioRate("4") >= 0.5`。
> L4 題庫受「2.5–3 倍出題數」上限所限只能到 90 題,所以 50 % 是**剛好踩線**,
> 沒有餘裕:之後每加一題 L4 單選,就要同步加一題情境題。

**題庫規模**:每階段題庫應為出題數的 **2.5–3 倍**,確保重測時題目大幅不同。

| 階段 | 出題 | 題庫 |
|---|---|---|
| L1 | 20 | 55 |
| L2 | 30 | 80 |
| L3 | 40 | 110 |
| L4 | 30 | 85 |
| 章末自我檢測 | — | 約 150 |
| **合計** | | **約 465 題** |

> `00-curriculum-map.md` 估算的「約 280 題」是**首版**目標(結業題庫先做到 1.5 倍出題數)。上表 465 題是完整版目標,於 Phase 4 後補齊。

## 題目資料格式

```js
// data/quiz/level-2.js
{
  id: "L2-042",
  chapter: "2.2",
  type: "single",              // single | multi | numeric | image | scenario | order
  difficulty: 2,               // 1-3
  tags: ["氣體選用", "F/C比"],
  question: "…",
  image: "…svg 路徑或 inline id(選填)",
  options: [
    { id: "A", text: "…", correct: false, why: "為什麼錯" },
    { id: "B", text: "…", correct: true,  why: "為什麼對" }
  ],
  // numeric 型專用
  answer: 0.316, unit: "s", tolerance: 0.15,
  explanation: "整體解析",
  reference: "2.1.3"           // 連回章節
}
```

**每個錯誤選項都必須有 `why`** —— 這是本題庫的品質底線。學員選錯時要能立刻知道自己的誤解在哪。

## 認證

### 徽章

完成各階段測驗後獲得徽章,顯示在 `/progress/`:

| 徽章 | 條件 |
|---|---|
| 電漿入門 | L1 通過 |
| 電漿實務 | L2 通過 |
| 製程整合 | L3 通過 |
| 電漿專家 | L4 通過 |
| **全程完訓** | 四階全通過 + 所有章節完成 |

### 證書

`/progress/` 可產生一張證書(HTML,可列印為 PDF),包含:姓名(學員自行輸入)、完成階段、完成日期、涵蓋模組清單。

**明確標示**:「本證書由學習者本機產生,供內部訓練紀錄參考,非第三方認證。」不要假裝這是有公信力的外部認證。

### 企業導入

提供 `/progress/` 的 JSON 匯出,承辦人可蒐集學員的匯出檔做訓練紀錄。不做後端帳號系統(見 `06-site-architecture.md` 的理由)。

## 出題品質檢核

每題送審前必須通過:

- [ ] 題幹沒有洩漏答案的線索(選項長度不一致、文法暗示)
- [ ] 錯誤選項是**似是而非**的常見誤解,不是明顯荒謬的干擾項
- [ ] 每個錯誤選項都有 `why` 解析
- [ ] 解析連回具體章節編號
- [ ] 數值題的容差合理(不會因為四捨五入而誤判)
- [ ] 圖形題的 SVG 特徵明確,不同缺陷不會混淆
- [ ] 情境題提供的資料足夠推導,沒有需要外部知識的跳躍
- [ ] 沒有兩題考完全相同的觀念(除非在不同難度層)
- [ ] **技術正確性經過第二人審閱**(見 `09-content-style-guide.md`)
