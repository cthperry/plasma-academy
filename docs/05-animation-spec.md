# 05 — 動畫與互動元件規格書

**33 件互動元件。** 全部以原生 Canvas 2D + SVG + CSS 實作,零外部依賴、零 CDN。

---

## 通用規範

### 技術選型準則

| 呈現內容 | 技術 | 理由 |
|---|---|---|
| 粒子模擬、場、即時演化 | **Canvas 2D** | 數百至數千個物件,DOM 撐不住 |
| 曲線、座標軸、剖面示意、可標註結構 | **SVG** | 向量清晰、可加 `<title>` 無障礙、易做 hover |
| 狀態轉場、面板動效 | **CSS transition** | 交給瀏覽器合成,不吃主執行緒 |
| 分子式、公式 | **HTML + CSS** | 可選取、可搜尋、可讀屏 |

**混用是常態**:多數元件是「SVG 座標軸與曲線 + Canvas 粒子層 + HTML 控制面板」三層疊起來。

### 統一控制面板語彙

每個元件的控制區使用同一套元件庫:

```
[滑桿]      連續參數(壓力、功率、溫度…),即時更新,顯示數值與單位
[分段控制]  離散選項(氣體種類、機台型式)
[開關]      布林(顯示向量、顯示標註)
[▶ 播放/⏸]  時間軸動畫
[↺ 重設]    回到預設值
[數值面板]  即時輸出的計算結果,固定位置不跳動
```

### 效能預算

| 項目 | 上限 |
|---|---|
| 單一元件 JS 檔 | 30 KB(未壓縮) |
| 首次可互動時間 | < 300 ms |
| 動畫幀率 | 60 fps(粒子數上限據此反推) |
| 粒子數上限 | 桌機 2000 / 行動 600 |
| 記憶體 | 單元件 < 20 MB |

### 生命週期契約

每個元件匯出統一介面:

```
init(container, options)   建立 DOM/Canvas,綁事件,不自動播放
start()                    開始 rAF 迴圈
stop()                     停止 rAF(離開視窗時必呼叫)
reset()                    參數回預設
destroy()                  移除事件、釋放 Canvas
```

**強制規則**:使用 `IntersectionObserver`,元件離開視窗時自動 `stop()`。頁面上可能同時有 3 個元件,不得同時跑滿。

### 無障礙與降級

| 需求 | 做法 |
|---|---|
| `prefers-reduced-motion` | 停止自動播放,改為單步/滑桿驅動的靜態狀態;所有元件必須在無動畫下仍可完整傳達概念 |
| 鍵盤操作 | 所有滑桿、按鈕可 Tab 到達;滑桿支援方向鍵 |
| 讀屏 | 每個元件有 `aria-label` 與一段文字摘要,說明當前狀態的物理意義 |
| 色盲 | 不以顏色作為唯一區辨方式,必須搭配形狀或標籤 |
| 無 JS | `<noscript>` 顯示對應的靜態說明圖與文字 |

### 規格欄位定義

以下每個元件的規格包含:

```
【章節】     所屬模組
【目標】     學員操作完應該理解什麼
【視覺】     畫面組成
【參數】     可調項與範圍
【模型】     背後的計算式
【觀察點】   引導文字提示學員該注意什麼
【驗收】     可驗證的行為條件
```

# L1 元件(A01–A07)

## A01 — 氣體→電漿相變粒子動畫

**章節** 1.1 · **技術** Canvas 2D

- **目標**:建立「電漿是氣體中極少數粒子被游離」的直覺,並看到游離度有多低
- **視覺**:方形腔體內約 800 個中性粒子(灰點)。施加電場後,少數變成離子(紅)+ 電子(藍),電子快速移動、離子緩慢。旁邊即時顯示游離度計數器
- **參數**:
  - 電場強度滑桿 0–500 V/cm
  - 氣壓滑桿 1–100 mTorr
  - 顯示模式:全部粒子 / 只顯示帶電粒子
- **模型**:簡化的機率游離模型 —— 電子動能超過該氣體游離能時,以碰撞截面比例的機率產生游離事件;離子與電子以固定機率在邊界複合
- **觀察點**:
  - 「注意帶電粒子有多少 —— 切到『只顯示帶電粒子』模式看看」
  - 「電子跑得多快?離子幾乎沒動」
- **驗收**:游離度計數器顯示 10⁻³ 量級(視覺化需求下的誇大值),並以文字標註「實際製程電漿約 10⁻⁵,這裡為了看得見而放大了 100 倍」——**必須誠實標註誇大**

## A02 — Debye 遮蔽互動

**章節** 1.2 · **技術** Canvas 2D + SVG

- **目標**:理解 λ_D 的物理意義與它對 n_e、T_e 的依賴
- **視覺**:均勻分佈的電子(藍)與離子(紅)。中央放一個可拖曳的正測試電荷。周圍電子被吸引形成雲,離子被排開。疊加一條「電位 vs 距離」曲線,並畫出 λ_D 的虛線圓
- **參數**:
  - n_e 滑桿 10⁹–10¹² cm⁻³(對數)
  - T_e 滑桿 1–10 eV
  - 測試電荷極性:正/負
- **模型**:`φ(r) = (q/4πε₀r)·exp(−r/λ_D)`,λ_D 由滑桿即時計算
- **觀察點**:「把 n_e 調高十倍,遮蔽圈縮小多少?」「λ_D ∝ √(T_e/n_e) —— 驗證看看」
- **驗收**:數值面板顯示 λ_D 的 mm 值,與 1.2.4 表格的 CCP/ICP 兩組數字一致

## A03 — 平均自由徑粒子模擬

**章節** 1.3 · **技術** Canvas 2D

- **目標**:把「壓力決定方向性」變成可見的
- **視覺**:左側從鞘層射出一束離子(平行向下),穿越腔體區域。碰撞以閃光標示,碰撞後方向隨機偏折。底部有一片晶圓,累積記錄入射角分佈的直方圖
- **參數**:
  - 壓力滑桿 1–200 mTorr(對數)
  - 氣體種類:He / Ar / Xe(改變碰撞截面)
  - 顯示 λ 標尺:開/關
- **模型**:`λ = kT/(σP)`,σ 依氣體種類查表;碰撞為卜瓦松過程
- **數值面板**:λ(cm)、穿越腔體平均碰撞次數、入射角 FWHM
- **觀察點**:「1 mTorr 時幾乎沒有碰撞,入射角分佈很窄 → 這就是異向性蝕刻」「調到 100 mTorr,看直方圖散開」
- **驗收**:1 mTorr 時 λ ≈ 5 cm(Ar);入射角 FWHM 隨壓力單調變寬

## A04 — 電子雪崩動畫

**章節** 1.4 · **技術** Canvas 2D

- **目標**:看見指數成長,理解 α 與 γ 的角色
- **視覺**:左為陰極、右為陽極。單一種子電子出發,被電場加速,碰撞後產生新電子與離子。離子往陰極漂移,撞擊陰極時以機率 γ 打出二次電子(用不同顏色標記,強調它是「自持」的來源)。右側即時畫電子數的對數圖
- **參數**:
  - 電場 E/p 滑桿
  - γ 滑桿 0.01–0.2
  - 間距 d 滑桿
  - 播放速度
- **模型**:`n(x) = n₀·e^(αx)`,α 用 Townsend 經驗式 `α/p = A·exp(−B/(E/p))`
- **觀察點**:「沒有二次電子的話,雪崩衝到陽極就結束了 —— 把 γ 調到 0 看看」
- **驗收**:γ = 0 時放電無法自持(數次雪崩後熄滅);滿足 `γ(e^αd − 1) = 1` 時進入穩態

## A05 — Paschen 曲線互動 ★

**章節** 1.4 · **技術** SVG + Canvas

**旗艦元件之一。**

- **目標**:讀懂 Paschen 曲線,理解左右兩支的物理成因
- **視覺**:
  - 主圖:V_b vs pd 的對數座標曲線,可疊加多種氣體比較
  - 游標定位在當前 (pd, V) 點,依據是否在曲線上方顯示「點火 ✅ / 不點火 ❌」
  - 側邊:小型放電腔示意,即時顯示電極間距與是否有輝光
  - 左右支各有一個小插圖說明成因(左支:電子直接飛到陽極;右支:碰撞太頻繁能量不足)
- **參數**:
  - 氣體:Ar / He / N₂ / Air / O₂(切換時曲線與最小值標註更新)
  - 壓力 p 滑桿 0.01–100 Torr(對數)
  - 間距 d 滑桿 0.1–10 cm(對數)
  - 施加電壓 V 滑桿 50–5000 V
  - 顯示所有氣體曲線:開/關
- **模型**:`V_b = B·pd / (ln(A·pd) − ln(ln(1+1/γ)))`,A、B、γ 依氣體查表
- **數值面板**:pd 值、崩潰電壓 V_b、當前 V、餘裕(V − V_b)
- **觀察點**:
  - 「找出這個氣體的 Paschen 最小值 —— 對照 1.4.2 的表格」
  - 「把壓力固定在製程值 10 mTorr,間距 3 cm → pd = 0.03 Torr·cm,你在左支。這就是為什麼點火要先衝壓力」
  - 「試著讓 pd 落在谷底 —— 這正是腔體裡不該有的寄生放電條件」
- **驗收**:五種氣體的 Paschen 最小值與 1.4.2 表格數字誤差 < 10%

## A06 — 鞘層形成時間軸動畫 ★

**章節** 1.5 · **技術** Canvas 2D + SVG

**旗艦元件之一 —— L1 最重要的觀念。**

- **目標**:看懂鞘層形成的四個階段,理解離子方向性的來源
- **視覺**:
  - 上半:腔體剖面,電子(藍)與離子(紅)粒子。底部是晶圓表面
  - 下半:三條同步的曲線 —— 電位 φ(x)、電子密度 n_e(x)、離子密度 n_i(x)
  - 時間軸控制:可拖曳到四個階段的任一時刻,也可自動播放
- **四個階段**(可單步):
  1. `t=0` 均勻,準中性,無電場
  2. `t=t₁` 電子快速流失到表面,表面帶負電
  3. `t=t₂` 鞘層形成,電子被排開,離子過剩區出現
  4. `t=穩態` 離子被加速垂直轟擊,流量平衡
- **參數**:
  - 時間軸拖桿
  - n_e 與 T_e 滑桿(改變鞘層厚度)
  - 顯示電場向量:開/關
- **模型**:定性動畫 + 穩態的鞘層厚度由 Child–Langmuir 計算
- **數值面板**:V_p、V_f、鞘層厚度 s、離子入射能量
- **觀察點**:「注意鞘層裡沒有電子 —— 準中性在這裡不成立」「電場全部指向表面,而且是垂直的」
- **驗收**:穩態時 V_p − V_f ≈ 4.7 × T_e(Ar);鞘層厚度隨 n_e 上升而變薄

**實作備註(P1 完成後補記)**

- **時間軸改為四顆分段按鈕**,不用拖桿 —— 四個階段本來就是離散的,拖桿會讓人誤以為中間有連續狀態。
- **鞘層電位降取浮動條件的 V_p − V_f,不外加偏壓。** 這一章還沒教 V_dc(2.4 才教),
  硬塞一個固定的 100 V 會讓數值面板自相矛盾:厚度用 100 V 算、電位降卻顯示 14 V。
  改成同一個值之後兩條驗收條件同時成立,而且帶出一個更有用的教學點 ——
  **浮接表面只有十幾 eV,蝕刻不動,所以才需要偏壓**。
  代價是鞘層只剩 0.02–1.7 mm,因此畫面與曲線的視野固定為 **2 mm**(而非 10 mm)。
- **三條曲線改用推導式,不用湊出來的形狀**:
  φ 用 Child–Langmuir 的 x^(4/3);n_e 用 Boltzmann 關係 exp(−eΔφ/kT_e);
  n_i 用通量守恆 n·v = 定值(v ∝ √E,離子以 ½T_e 進入)。
  壁面處 n_e ≈ 0.01、n_i ≈ 0.31 —— 「電子排空、離子過剩」直接從式子長出來,不是畫上去的。
- **電子粒子的鞘層穿透深度依指數分佈抽樣**(平均 0.22 × s),
  這是上圖 n_e 指數衰減的粒子版本,畫面與曲線同一套物理。
- 數值面板實作為:階段 / 鞘層厚度 s / V_p − V_f / 離子入射能量。
  V_p 與 V_f 的絕對值需要知道接地參考,L1 還沒建立,先只給差值。
- 驗收條件已寫進 `tools/check-model.mjs`:浮接鞘層厚度、n_e 百倍 → 鞘層 1/10、
  全參數範圍落在 2 mm 視野內,外加 1.5.2 的五種氣體倍數表。

# L2 元件(A08–A16)

## A08 — 腔體流場與滯留時間計算器

**章節** 2.1 · **技術** Canvas 2D + HTML

- **目標**:建立 τ 的量級感,理解流量與壓力是兩個獨立旋鈕
- **視覺**:腔體剖面,氣體從噴淋頭進、從泵口出。示蹤粒子以顏色表示已停留時間(新=藍,久=紅)。泵口有節流閥開度示意
- **參數**:總流量 10–1000 sccm、目標壓力 1–1000 mTorr、腔體體積 5–100 L
- **模型**:`τ[s] = 79.0 × P[Torr] × V[L] / Q[sccm]`;粒子以簡化流場移動
- **數值面板**:τ、有效抽速、節流閥開度(%)
- **觀察點**:「把流量加倍但壓力不變 → τ 減半,但腔內粒子數不變。你改變的是『換氣速度』不是『濃度』」
- **驗收**:2.1.3 的範例(30 L、20 mTorr、200 sccm)算出 ≈ 0.24 s

**實作備註(P2)**

- **粒子壽命抽自指數分佈,不是固定值。** 理想混合腔體(CSTR)的停留時間本來就是
  指數分佈 —— τ 是平均值,不是每個分子都待滿 τ。加了一張分佈直方圖把這件事畫出來,
  並疊上理論曲線 e^(−t/τ) 對照。
- **動畫時間軸經過縮放。** τ 橫跨 0.0004 s 到 790 s,照實播不是眨眼就是不動,
  因此模擬跑在「τ = 1」的正規化時間裡,再乘回真實 τ 顯示。
- **「模擬實測 τ」是本元件的自我驗證**,但它踩到一個真實的統計陷阱,值得記下來:
  一開始用「已抽走那批的平均停留時間」估計,結果系統性偏低 7–40 %。
  原因是**右設限** —— 待得久的分子還沒被抽走就漏掉了,而且這個偏差只以 1/T 衰減,
  觀測 17 個 τ 仍有 6 % 誤差(理論值 0.94,實測 0.94,吻合)。
  改用指數分佈的最大概似估計 **τ̂ = 總曝險時間 ÷ 事件數**(存活者的時間仍計入分子)
  之後,三個情境全部落在 ±2 %。這個坑在零件壽命分析裡一模一樣,已寫進觀察點。
- 腔內粒子在重設時就以穩態年齡分佈填滿,省掉暖機期;但這批不列入直方圖 ——
  隨機時刻抓到的分子其總停留時間是長度偏差抽樣(inspection paradox),平均是 2τ 不是 τ。
- 額外加了 Knudsen 數與流體區間讀數,把 2.1.4 接進同一個元件。

## A09 — 氣體選用決策樹 ★

**章節** 2.2 · **技術** SVG + HTML

**旗艦元件。**

- **目標**:把配方設計的推理過程外顯化
- **視覺**:互動式決策流程。學員逐步選擇,樹狀圖即時展開路徑,右側同步顯示「目前的推理」
- **提問序列**:
  1. 要處理的材料?(Si / poly-Si / SiO₂ / SiN / Al / W / Cu / 光阻 / low-k / 有機膜)
  2. 蝕刻還是沉積?
  3. 下層是什麼(不能動的)?
  4. 需要什麼 profile?(垂直 / 錐形 / 等向)

- **A15 一開始匹配不了,而且是物理上的錯,不是數值問題。** 原本照規格寫成

### 實作備註(P3)—— 這份規格被實作修正了五處

驗收條件寫著「八種 profile 全部可重現」。**第一次實作跑出來只有三種成立**,
其餘五種要嘛看不出差別、要嘛被判成別的缺陷。逐項追下去,發現的不只是調參問題:

1. **物理必須與 UI 分離。** 「八種都可重現」如果只能靠人眼看畫面,就等於沒有驗收。
   所以把物理抽成 `src/js/lab/profile-shapes.js`,`tools/check-shapes.mjs` 在 Node 裡
   跑**同一份程式碼**做斷言;`a18.js` 只剩 UI。判定一律走 `classify()`,
   而 `classify()` 只看量出來的尺寸,不看使用者選了哪個預設。
2. **比較必須在同一深度。** 原本固定步數跑,結果八種輪廓停在不同深度 ——
   淺的看起來全都像垂直,三段寬度沒有可比性。改成**蝕到終點(膜/下層界面)
   再過蝕刻 10 % 才量**,與現場量 CD 的時機一致。
3. **ARDE 的主因不是自由基通量,是表面覆蓋率。** 引擎的離子輔助項原本只乘全域的
   自由基密度,沒有乘**本地**的自由基通量 —— 於是深窄溝與淺寬溝刻得一樣快
   (實測落差 < 2 %)。這同時違反 3.1.2 協同效應的內容:離子只是把已生成的
   SiF<sub>x</sub> 打掉,本地沒有 SiF<sub>x</sub> 就沒有協同。改成 Langmuir 型
   覆蓋率 `θ = 供應 / (0.6 + 供應)` 後,三個不同 CD 的深度落差變成 **39 / 51 / 67**。
4. **側壁的聚合物原本會被無離子地清掉。** 聚合物移除有兩條路(離子濺射、
   基材的氧把碳燒成 CO/CO₂),第二條原本寫成與離子無關 —— 側壁因此也被清乾淨,
   直接違反 3.1.4「側壁離子打不到 → 鈍化層留著 → 蝕刻停止」的整個圖像。
   加上離子閘之後側壁才真的受保護。
5. **faceting 與 undercut 用三段寬度分不開**,兩者在膜裡都是「上面比下面寬」。
   真正的判別是**遮罩開口有沒有自己變寬**:faceting 的遮罩被削掉、undercut 的遮罩完好。
   因此新增「遮罩開口(倍)」讀數,並寫進 3.1.6 的常見誤解方塊。

**一處規格層級的錯誤**:原本把 bowing 歸因於「鈍化不足」,參數也給了低鈍化。
實作後發現低鈍化會讓**頂部**先被咬開,量出來是 undercut 而不是 bowing。
bowing 要成立,頂部必須被沉積保護住(沉積通量在開口處最高),
中段則靠離子反射被打開 —— 所以 bowing 的鈍化必須**偏高**,不是偏低。

參數因此不再手寫:`tools/shapes-search.mjs` 在**受限的**參數空間
(每一維的範圍由圖鑑寫的成因決定)裡搜尋,找出真的能重現該缺陷的設定,
再寫回 `data/defects.js`。`tools/shapes-sweep.mjs` 是配套的探測工具。
兩支都是開發工具,不進品質門。

**目前進度:八種之中五種成立**(垂直 / Taper / Footing / Faceting / Etch stop),
加上多溝槽視圖的 ARDE。`npm run check:shapes` 21 / 32。

第二輪補上的物理(四項):

1. **濺鍍產額的角度依賴 Y(θ)** —— Yamamura 型,峰值 60°、約 1.8 倍。
   加上之後 faceting **才是真的削出斜面**(遮罩開口 1.00 → 1.77),
   而不是靠「遮罩整體變薄」冒充。
2. **物理濺射與離子輔助化學蝕刻的角度依賴必須分開。**
   第一版把完整的 Y(θ) 也套在化學項上,結果任何斜面都被清得特別快,
   溝變成**完美矩形**,taper 與 footing 被抹平。化學項改用 `1 + 0.35(Y−1)`
   —— **這一項讓成立數從 4 變成 5**。
3. **再沉積(redeposition)** —— 溝底打下來的材料落在附近表面重新黏住,
   集中在溝的下半段。taper 與 footing 的機制之一。
4. **鏡面反射的通量門檻太高**(0.02),把側壁那份掠射入射的通量整個丟掉;改為 0.002。

**剩下三種的具體診斷**:

- **Undercut 做不出來其實是模型對了**:A18 的膜是 SiO₂,而 F 蝕 SiO₂ 需要離子先破
  Si–O(3.1.4 的化學選擇性),純化學側蝕本來就小。undercut 是 poly-Si / 金屬蝕刻的
  缺陷。→ 修法是**讓目標膜可選(Si / SiO₂ / SiN)**,順帶讓 A18 也能示範選擇比。
- **Bowing / Microtrench**:側壁的 `poly` 會累積到 4×polyCrit,`block` 飽和成 0 ——
  模型只有「完全保護 / 完全清開」兩態,沒有梯度,側壁不可能「中段多被咬一點」。
  → 修法是把側壁聚合物 clamp 在略高於 polyCrit,讓 block 可變;會動到 etch-stop
  的 F/C 邊界,要一併重新確認。

狀態表見 `docs/11` 的 A18 狀態;3.1 的課文已如實標註這些限制。

## A33 — 封裝電漿處理計算器

**章節** 3.7 · **技術** SVG(plot.js)

規劃完成後增補的元件,對應同樣增補的模組 3.7。

- **目標**:讓學員親眼看到「封裝電漿的製程窗有**上限**」—— 這與前段的直覺相反
- **視覺**:兩條共用 y 軸的曲線
  - **接觸角**(實線)—— 單調下降
  - **接著力指數 ×30**(虛線)—— **先升後降**
  - 30° 規格線;目前條件以圓點標在兩條曲線上
- **參數**:氣體(Ar / O₂ / H₂-Ar / N₂)、材料(EMC / PI / 綠漆 / Cu pad)、
  電漿型式(低壓 / 大氣)、處理時間 0–240 s、功率 50–800 W、壓力 0.05–1.5 Torr
- **預設**:四個現場情境 —— 封膠前活化、打線前 pad 清潔、助焊劑殘留去除、大氣電漿 inline
- **模型**(`src/js/lab/package-model.js`,三條規則):
  ```
  活化  γ(t) = γ0 + (γsat − γ0)·(1 − e^(−k t))       k ∝ 氣體活化效率 × 自由基通量 ÷ 材料耐受度
  損傷  劑量超過門檻後超線性累積(LMWOM 降解層)
  回復  處理後 γ 朝「永久保留值」指數衰退 → queue time

  接觸角  cos θ = 2√(γs/γl) − 1                       (Girifalco–Good)
  接著力  = 附著功增益 × (1 − 0.85·損傷) × (1 − 0.55·氧化)
  ```
  接著力會轉彎是因為前者飽和、後者持續上升 —— **乘積必然先升後降**,不是畫上去的。
- **讀數**:接觸角、表面能、接著力指數、基材損傷 %、金屬氧化 %、queue time 上限、判定
- **判定**:用量出來的數字,而且**金屬與有機材料走不同判準** ——
  金屬看氧化狀態(NSOP),有機材料才看接觸角。混用是現場常見誤用。
- **驗收**:
  - 接著力隨時間**先升後降**,且過度處理的接著力低於未處理(< 1.0)
  - Cu pad 上 H₂/Ar 的去氧化效果最好、O₂ 反而讓氧化更嚴重並判為 NSOP
  - 大氣模式的熱負荷明顯高於低壓,時間上限因此更短
  - queue time 落在「數小時」量級,且回復最快的材料 queue time 最短
  - 氣體清單不含任何氟系氣體
- **檢查**:`tools/check-package.mjs`(34 項,已進品質門)

## A19 — Bosch 製程循環動畫

**章節** 3.2 · **技術** Canvas 2D

- **目標**:理解循環邏輯與 scallop 的來源
- **視覺**:深溝槽剖面,三步循環演示。聚合物層以顏色標示,每循環在側壁留下一個 scallop

- **觀察點**:
  - 「縮短循環時間 → scallop 變小但總蝕刻速率下降。這是表面粗糙度與產率的 trade-off」
  - 「把沉積步關掉 → 側壁立刻被 SF₆ 咬爛」

### 實作備註(P3)

物理在 `src/js/lab/bosch-model.js`,只做一件事:在兩組 profile-engine 參數之間交替
(沉積步 F/C 低、離子能量低;蝕刻步 F/C 高、離子能量高)。
**scallop 沒有任何一行程式在畫它** —— 它是「蝕刻步把新露出的側壁咬一口、
沉積步再把它封住」的必然結果。

過程補上兩個引擎參數(都預設 1,不影響既有元件):

- `polySputterRel` —— 聚合物濺射係數 0.03 是照介電質校準的(那裡靠 SiO₂ 自身的氧
  清聚合物)。**矽沒有氧**,只剩這一項,沿用會讓沉積步一輪就把溝封死(實測深度 1 列)。
- `chemRel` —— 自發化學蝕刻係數 0.35 是照氟碳化學校準的,而 **SF₆ 對 Si 又快又等向**。
  沿用會讓「關掉沉積步」時側壁只鼓 10 %,而課文說的是「立刻被咬爛」。

**規格層面補上一項**:「循環時間短 → scallop 小但產率低」在第一版模型裡是
**反過來的** —— 短循環 scallop 更小、每秒深度還更高。少的是**每循環固定的切換開銷**
(換氣、抽殘氣、電漿穩定;模型取 0.6 s/次,一循環兩次)。
加上之後短循環開銷佔 19 %、長循環佔 6 %,課文的結論才成立。
**讓這個 trade-off 成立的是機台的切換時間,不是化學。**

`tools/check-bosch.mjs` 13 項,已進品質門。
- **數值面板**:總深度、scallop 深度、有效蝕刻率、循環數
- **驗收**:scallop 深度隨蝕刻步時間單調增加;關閉沉積步時 profile 變成等向

## A26 — Langmuir 探針 I-V 互動 ★

**章節** 4.1 · **技術** SVG + Canvas

**旗艦元件。**

- **目標**:實際操作一次探針分析,學會四參數的求法
- **視覺**:三個可切換的分頁
  1. **線性 I-V 圖** —— 標出三個區域,游標可拖曳讀值
  2. **半對數圖** ln(I_e) vs V —— 學員拖曳擬合直線,系統即時顯示斜率算出的 T_e
  3. **二次微分** d²I/dV² —— 顯示由 Druyvesteyn 公式得到的 EEDF
- **參數**:
  - 電漿條件:n_e、T_e、氣體種類(產生對應的理論 I-V 曲線)
  - **RF 補償開關** ← 教學重點
  - 雜訊程度(展示真實資料的樣子)
  - 探針鍍膜程度(展示故障模式)
- **互動任務**:
  1. 找出 V_f(I = 0)
  2. 切到半對數圖,拖曳擬合線求 T_e
  3. 找出 V_p(dI/dV 極大)
  4. 由離子飽和電流求 n_e
  5. 與系統設定的真值比對,顯示誤差
- **教學重點**:
  - **關掉 RF 補償** → 曲線被塗抹,學員算出的 T_e 被高估數倍。這是本元件最重要的一課
  - 探針鍍膜 → 曲線變形甚至完全失真
- **驗收**:無 RF 補償時 T_e 高估至少 2 倍;學員正確操作時誤差 < 10%
- **實作狀態**:⚠️ 第二項達成(四個參數誤差 < 0.1–2.5 %),
  **第一項未達成,而且是可以證明做不到的**:
  ⟨exp((V−V_p−V_rf·f(t))/T_e)⟩ = exp((V−V_p)/T_e)·⟨exp(−V_rf·f/T_e)⟩,
  後項與 V 無關 → 任何波形的 RF 調變在指數區都只是**整條平移,斜率不變**。
  要讓 T_e 真被高估需要模型沒有的東西(探針雜散電容分壓、非 Maxwellian EEDF)。
  但模型確實顯示了同樣嚴重的錯誤:**V_p 從真值 20 V 被推到 −10 V**(V_f 同步平移),
  而離子能量 ≈ V_p − V_wafer,下游全錯。課文完整說明兩者的差別

**章節** 4.2 · **技術** SVG + Canvas

- **目標**:理解 SNR 隨開口率崩壞,以及替代方案
- **視覺**:左右分割

  - **開口率 0.01%–50%(對數)** ← 核心參數

  - 演算法:原始 / 移動平均 / 一階微分 / 歸一化

  - 「開口率降到 0.1% → OES 訊號被雜訊淹沒,演算法開始誤觸發」
  - 「同樣條件下看右邊 —— 干涉訊號完全不受影響,因為它量的是厚度不是產物」
  - 「試試不同演算法,哪個在低 SNR 下最穩?」

- **實作狀態**:✅ 兩項都達成(`tools/check-endpoint.mjs` 35 項斷言)。
  「不可靠」用 24 顆雜訊種子的**失敗率**(誤差 > 10 %)驗證,不是單次結果 ——
  單跑一次會給出離散的階梯,看起來像模型壞掉,其實只是一個雜訊實現。
  開口率 5 %→1 %→0.3 %→0.1 %→0.01 %,OES 失敗率 0→18→70→88→**90 %**(單調)；
  干涉在同樣五個條件下失敗率**全部是 0 %**,而且偵測到的終點時間**逐位元相同**
  (訊號的計算式裡根本沒有開口率這一項,所以這一條可以用等號斷言)。

  實作過程改掉了三件原規格沒說對的事,都寫進 4.2 課文:
  1. **原規格的四個演算法選項有三個是同一件事。** 「移動平均 / 一階微分 /
     歸一化」實測跑出**位元完全相同**的結果 —— 微分法本來就要先平滑,
     而歸一化只是除以常數、argmax 對縮放免疫。改成四種判準真的不同的方法
     (不平滑微分 / 拖尾 9 點 / 拖尾 31 點 / 平台間 50 % 門檻)。
  2. **平滑必須是「拖尾」才有延遲代價。** 置中平滑的有號偏差只有 −0.05 %,
     因為對稱平滑不移動對稱轉折的反曲點。改成拖尾(因果)之後:
     不平滑 +0.02 %、9 點 +1.25 %、31 點 **+4.64 %** —— 真機控制器看不到未來的取樣點。
  3. **誤差最小的判準不能拿來停機。** 「平台間 50 % 門檻」在每個開口率下誤差都最小
     (0.3 % 開口率時 0.7 %,微分法已經 56 %),但它要用到蝕刻**結束後**的平台,
     是非因果的。模型用 `causal` 旗標標記,課文明確區分即時法與事後法。

  另外補上干涉法**自己的**失效邊界(與開口率無關):條紋預算 < 1 個週期時
  直接回報 `usable: false`,不硬給數字;固有時間解析度 = λ/(2n) ÷ 蝕刻率
  (SiO₂ @ 5 nm·s⁻¹ = 43 s),四種膜厚的終點誤差都落在一個條紋週期內。

## A29 — 天線效應充電動畫

**章節** 4.3 · **技術** Canvas 2D + SVG

- **目標**:理解充電損傷的完整路徑,以及天線比為什麼重要
- **視覺**:
  - 上:晶圓剖面,顯示金屬圖形 → 連接線 → 閘極 → 閘極氧化層 → 基板
  - 電子(藍)與離子(紅)入射。**電子被高深寬比結構遮蔽(electron shading)** 以視覺強調
  - 電荷在金屬圖形累積 → 沿導線匯集 → 電位計顯示閘極電位上升
  - 超過臨界值時,閘極氧化層出現穿隧電流動畫,最終崩潰
- **參數**:
  - 天線面積(改變天線比)
  - 閘極面積
  - 深寬比(改變 electron shading 程度)
  - **脈衝電漿開關** ← 教學重點
  - 天線二極體:有/無
- **數值面板**:天線比、累積電荷、閘極電位、氧化層電場(MV/cm)、預估壽命
- **觀察點**:
  - 「開啟脈衝電漿 → off 期電子自由抵達,電位被中和,再也沒有累積」
  - 「加上天線二極體 → 電荷從二極體洩放,閘極電位維持安全」
  - 「把天線比從 100 加到 1000 → 看氧化層電場」
- **驗收**:脈衝模式下閘極電位不再單調累積;天線比與閘極電位近似線性關係
- **實作狀態**:第一條 ✅ 達成;**第二條被實作推翻 —— 原規格把線性關係掛錯了對象**
  (`tools/check-charging.mjs` 31 項斷言)。

  實測 log-log 斜率(天線比 10 → 3000,跨 2.5 個數量級):

  | 量 | 斜率 |
  |---|---|
  | 閘極電位 V | **0.078** ← 幾乎是平的 |
  | 注入電荷 q | **0.979** ← 線性的是這一個 |
  | 到崩潰時間 t_bd | **−0.979** |

  物理上必然如此:電位由電子遮蔽的**電位天花板**(T_e 與結構深寬比)決定,
  而氧化層導通對電壓是指數的,所以再多的電流也只把電位推高一點點;
  天線比改的是**單位閘極面積要吞多少電流**,那是劑量,不是電位。
  具體地說:天線比 100 → 1000,電位只多 19 %,劑量剛好 ×9.5。
  這正是設計規則寫成面積比上限、而不是寫成電位上限的理由,
  也直接推翻現場那個很常見的推理「電位只多了 10 %,應該還好吧」。

  元件與課文因此**同時呈現電位與劑量兩個讀數**,並把原規格的錯誤釘成一條
  反向斷言:若哪天模型真的跑出「電位與天線比線性」,測試會亮紅燈。

  實作逼出來的另外三件事:
  1. **沒有氧化層漏電就沒有天線效應。** 第一版只放 FN 穿隧,天線比從 10 掃到 3000
     時電位與劑量**一位數都沒變**。原因不是數值問題:浮動天線的電位被電漿自己釘住
     (電漿導納 ∝ 天線面積),而驅動也 ∝ 天線面積,兩邊完全對消。
     天線比只能透過 `V_ox = V_天花板 · G_電漿/(G_電漿+G_氧化層)` 這個**分壓器**生效,
     而 FN 式在直接穿隧區低估好幾個數量級,等於把 G_氧化層 設成 0,分壓器就退化了。
     改用擬合公開閘極漏電 t_ox 標度的經驗式之後,機制才成立。
  2. **脈衝不會降低尖峰電位。** 三種 duty 的 V_max 完全相同,只有時間平均與劑量下降
     (劑量 ≈ ×duty)。所以脈衝救得了磨耗失效,**救不了硬崩潰**(場強判準)。
     這個區分原規格沒有,但它決定了對策選得對不對。
  3. **Q_bd 必須隨 t_ox 變化。** 取常數會得到「1.5 nm 的核心元件比 10 nm 的 I/O 元件
     更容易被天線打死」這個與現場完全相反的結論。加上每薄 0.5 nm 約一個數量級的趨勢後,
     模型跑出正確且反直覺的結果:**最脆弱的是 4–5 nm 的中間厚度**,兩頭都有保護。

- **協同度計算**:提供「只做步驟 1、2」與「只做步驟 3、4」的模式,讓學員自己算出 α、β 與協同度 S
- **觀察點**:「把能量調到窗外上緣 —— EPC 開始隨能量變化,這就不是 ALE 了,只是慢速濺鍍」
- **驗收**:窗內時 EPC 與能量無關(變化 < 5%);協同度計算功能可得出 > 90% 的理想值
- **實作狀態**:✅ 兩項都達成(`tools/check-advanced.mjs` 39 項斷言,含 A31)。
  窗內 EPC 變異 **0.00 %**、協同度 **99.6 %**、EPC = 0.136 nm/循環。

  ⚠️ 但「窗」必須定義對,這是實作推翻的一件事:
  照兩個閾值取窗(18–55 eV)去掃 EPC,變異高達 **239 %**,完全不像自限制。
  原因不是模型壞掉 —— **閾值只說移除「開始」,沒說移除「來得及完成」**。
  剛過閾值時產額極小(20 eV 時 Y_mod 只有 0.067),移除步的離子劑量清不完改質層。
  所以可用窗的下緣不是 E_th,而是「t_clear ≤ 移除步時間」的那一點,
  **它會隨移除步時間移動**(0.3 s → 窗寬 8.5 eV;3 s → 34.5 eV)。
  元件因此同時畫兩條窗,課文也照實寫:窗寬不是材料常數,是配方決定的。

  三種失效模式全部重現:能量過低 EPC→0.004 ML;能量過高 EPC 隨能量單調上升
  且協同度從 99.6 % 崩到 41.6 %;改質時間不足時 EPC 跟著時間跑。
  另外補了第四種(規格沒列):**purge 不足 → EPC 要好幾個循環才穩,而且偏高 63 %**,
  對應現場「同一批前幾片偏淺、後面越來越深」。

## A31 — 脈衝電漿時序互動

**章節** 4.4 · **技術** SVG + Canvas

- **目標**:理解脈衝的四個效益從何而來
- **視覺**:
  - 上:時序圖 —— source power、bias power、n_e、T_e、鞘層電位、負離子密度 隨時間的波形,全部對齊同一時間軸
  - 下:腔體剖面動畫,同步顯示 on 期與 off 期的粒子行為(off 期鞘層塌陷、電子與負離子抵達表面)
  - 右:深孔剖面,顯示孔底電荷在 off 期被中和
- **參數**:
  - 脈衝頻率 0.1–10 kHz
  - 佔空比 10–90%
  - 模式:source / bias / synchronized(可設相位差)
  - 氣體電負性(有/無負離子)
- **觀察點**:
  - 「off 期 T_e 快速下降,但 n_e 衰減慢 —— 這就是為什麼脈衝能得到『高密度低溫』的電漿」
  - 「看孔底的電荷:連續模式一直累積,脈衝模式每個 off 期被清零」
  - 「開啟電負性氣體 → off 期有負離子抵達晶圓,中和效果更好」
- **驗收**:off 期 T_e 衰減時間常數顯著小於 n_e;連續與脈衝模式的孔底電荷累積行為明顯不同
- **實作狀態**:✅ 兩項都達成(`tools/check-advanced.mjs`)。
  實測 τ(T_e) = **6.7 µs**、τ(n_e) = **71 µs**(比值 10.7),而且是**量出來的** ——
  T_e 的衰減不是單一指數(ν_iz 一關掉就換了機制),拿參數當答案會給錯的數字。
  孔底:CW 充到 10.5 V 之後回落 0 %;脈衝每週期回落 97 %,平均電位掉到 CW 的 18 %。

  模型多做出兩件規格沒要求、但很有價值的事:
  1. **脈衝頻率的上下限是跑出來的。** 下限:off 期太長 → n_e 掉到 CW 的 1 % 以下
     (≤ 1 kHz 時電漿等於熄了再點);上限:off 期太短 → 孔底來不及放電
     (100 kHz 時回落 0 %)。兩者夾出數 kHz 的可用區間,與現場經驗值同量級。
  2. **Bias 脈衝治不了充電。** 三種模式實測:bias 脈衝把平均離子能量從 92 降到 52 eV,
     但 n_e、T_e、孔底電位**完全不動**(天花板由 T_e 決定)。這個區分規格沒寫。
  3. 相位差**不改變**平均離子能量(46.2 eV 不動),改變的是它落在哪裡 ——
     落在後輝光的劑量比例從 0.5 % 變成 87 %。

  實作逼出來的兩個修正,兩次都是填錯數字造成的假象:
  · 孔底電容隨手填 2e-8 F/m² → 電位瞬間跟著 T_e 的天花板跑,脈衝反而讓尖峰**變高**
    (點火瞬間 T_e 會過衝)。改用「剩餘 100 nm SiO₂」導出的 3.45e-4 F/m² 才對。
  · 表面高於電漿電位時仍套幾何遮蔽 → 後輝光每週期只放電 0.2 V,模型宣稱
    「脈衝對孔底充電幾乎沒用」,與現場完全相反。補上**吸引態收集**
    (電位比電漿正時電子被漏斗進洞裡)之後才對;該項在 4.3 的所有情形下都是
    關閉的,check-charging 仍 31/31。
  · 附著係數第一版用 1.2e-16,跑出電負度 α = 1800。改成 8e-18(文獻量級)後
    α 落在 0.67(on)/ 3.9(off),後輝光的離子-離子電漿才是文獻上的樣子。

## A32 — 0-D 全域模型計算器

**章節** 4.5 · **技術** HTML + SVG

- **目標**:親手驗證「T_e 與功率無關、n_e 正比功率」這兩個結論
- **視覺**:
  - 左:輸入面板(氣體、壓力、腔體尺寸、吸收功率、流量)
  - 中:平衡方程的圖示求解 —— 兩條曲線的交點即為解
  - 右:輸出(T_e、n_e、離子通量、自由基密度)+ 掃描圖表
- **參數**:氣體種類、壓力、腔體半徑與高度、吸收功率、流量
- **掃描模式**:選定一個參數做掃描,自動畫出輸出隨該參數的變化曲線
- **關鍵教學任務**:
  1. 掃描功率 → 看 T_e 幾乎水平、n_e 線性上升 → **驗證 2.6.3 與 4.5.2 的結論**
  2. 掃描壓力 → 看 T_e 下降 → 驗證「T_e 由 p·L 決定」
  3. 縮小腔體尺寸 → T_e 上升(損失面積相對變大)
- **驗收**:功率掃描時 T_e 變化 < 10%、n_e 近似線性;壓力掃描時 T_e 單調下降
- **實作狀態**:✅ 三項都達成(`tools/check-global.mjs` 26 項斷言)。
  功率掃 20 倍(100 → 2000 W):**T_e 變化 0.0000 %、n_e 線性偏差 0.0000 %** ——
  不是「近似」,是**恆等**:粒子平衡兩邊的 n_e 直接消掉,方程式裡沒有功率。
  這正是 2.6.3「加功率主要加密度」的完整證明,也是 A32 存在的理由。
  壓力 2 → 200 mTorr:T_e 3.70 → 1.55 eV(單調),E_c 34 → 513 eV。
  腔體半徑 0.05 → 0.30 m:T_e 2.44 → 2.16 eV(單調)。
  T_e 是對粒子平衡做**二分法求根**解出來的,不是查表。

  模型多做了一件規格沒要求的事:**把理想結論的破口做成可切換的開關**。
  打開「氣體加熱」(高功率 → T_g 上升 → n_g 下降 → T_e 上升)之後,
  同一組掃描的 T_e 變化從 0.00 % 變成 **27 %**、n_e 線性偏差 21 %。
  預設是關的,課文明講它是理想 0-D 第一件會失準的事 ——
  理想結論要先立得住,才談它什麼時候失準。

  實作逼出來的一個修正:第一版的自由基平衡**沒有母氣體耗盡**,
  跑出 SF₆ 的自由基密度是氣體密度的 **2957 %**。正確寫法是解耦合平衡
  f = k_d·n_e/(L + k_d·n_e),它自然被 f → 1 卡住。改完之後
  O₂ 80 %、Cl₂ 86 %、CF₄ 90 %、SF₆ 97 % 解離度,與 ICP 的文獻值同量級。
