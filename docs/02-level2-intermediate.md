## 2.1 氣體動力學與真空(2.0 h)

### 學習目標
- 由流量與壓力算出滯留時間,並解釋它為什麼重要
- 區分黏滯流與分子流,知道各自用什麼泵、什麼管路設計
- 選對壓力計

### 2.1.1 理想氣體定律的製程版本

```
PV = NkT     (N 為粒子數)
```

改寫成工程師要的形式 —— **由壓力直接算粒子密度**:

```
n [cm⁻³] = 9.66 × 10¹⁶ × P[Torr] / T[K]
```

室溫(300 K)速算:

```
n [cm⁻³] ≈ 3.2 × 10¹³ × P [mTorr]
```

10 mTorr → n ≈ 3.2 × 10¹⁴ cm⁻³。對照 L1 的 n_e ≈ 10¹⁰ → 游離度 ≈ 3 × 10⁻⁵。**數字對得起來**,這是 L1 1.1.3 的驗算。

### 2.1.2 道爾頓分壓:混氣 recipe 的算法

```
P_i = P_total × (Q_i / Q_total)
```

範例:`Ar 100 / CF₄ 50 / O₂ 10 sccm`,總壓 20 mTorr
→ Ar 12.5 mT、CF₄ 6.25 mT、O₂ 1.25 mT

**常見誤解**:「流量比就是腔體內的濃度比」。
**正解**:只有在**沒有消耗**的前提下成立。實際上 CF₄ 被大量解離、O₂ 被表面反應消耗、蝕刻產物(SiF₄)加入氣相。腔內真實組成需要 RGA 或質譜才知道(L4 4.1)。這個落差在高消耗製程可以到數倍。

### 2.1.3 滯留時間:被低估的關鍵參數

```
τ = P · V / Q
```

實用形式:

```
τ [s] = 79.0 × P[Torr] × V[L] / Q[sccm]
```

**範例**:V = 30 L、P = 20 mTorr、Q = 200 sccm
→ τ = 79.0 × 0.02 × 30 / 200 ≈ **0.24 s**

**為什麼它重要**:τ 決定一個氣體分子在腔內平均待多久,也就決定了:

| τ 太短 | τ 太長 |
|---|---|
| 氣體來不及被解離 → 自由基少、蝕刻率低 | 產物累積 → 再解離、再沉積 |
| 氣體浪費、成本高 | 副產物參與反應 → 製程不可控 |
| 但腔體乾淨、產物迅速抽走 | 均勻度變差(中心與邊緣停留時間不同) |

**工程師直覺**:當你把總流量從 200 sccm 加到 400 sccm 卻維持壓力不變,你其實是把 τ 砍半。蝕刻率可能不升反降(自由基來不及生成),但均勻度可能改善(產物快速排除)。**流量與壓力是兩個獨立旋鈕,不要只調其中一個。**

### 2.1.4 流體區間:Knudsen 數

```
Kn = λ / d      (d = 特徵尺寸,如管徑或 gap)
```

| Kn | 區間 | 行為 |
|---|---|---|
| < 0.01 | 黏滯流(Viscous) | 分子互撞為主,像流體 |
| 0.01 – 1 | 過渡流(Transition) | 兩者混合,最難算 |
| > 1 | 分子流(Molecular) | 分子只跟器壁碰,彼此不相干 |

**製程對照**:
- PECVD(1–10 Torr,gap ~1 cm)→ Kn ≪ 1 → 黏滯流 → **氣流分佈設計(噴淋頭)決定均勻度**
- 蝕刻(10 mTorr,gap ~3 cm)→ Kn ~ 0.2 → 過渡流
- 高真空管路 → 分子流 → **導傳(conductance)由幾何決定,與壓力無關**

**設計啟示**:在分子流區,管路加粗比加短更有效(導傳 ∝ D³/L)。這解釋了為什麼腔體到泵之間永遠是又粗又短的管子。

### 2.1.5 泵浦鏈與壓力控制

| 泵 | 工作區間 | 角色 |
|---|---|---|
| 乾式幫浦(Dry pump) | 大氣 → 10⁻² Torr | 前級,排氣端 |
| 渦輪分子泵(TMP) | 10⁻² → 10⁻⁸ Torr | 主泵,製程用 |
| 冷凝泵(Cryo) | 高真空 | PVD 常用,抽水氣強 |

**壓力如何被控制**:節流閥(throttle valve)在泵前調節有效抽速。閉迴路:Baratron 讀壓力 → 控制器調閥位。

**現場故障對應**:
- 閥開度異常大 → 可能漏氣或流量計飄
- 閥開度異常小 → 泵抽速衰退或管路阻塞
- **閥位本身就是最好的健康指標**,應納入 FDC 監控(L4 4.2)

### 2.1.6 壓力量測:選對計

| 計種 | 原理 | 範圍 | 特性 |
|---|---|---|---|
| **電容薄膜計(Baratron)** | 隔膜位移 | 10⁻⁴ – 1000 Torr | **與氣體種類無關**,製程控制標準 |
| Pirani | 熱傳導 | 10⁻³ – 10 Torr | 依氣體種類校正,便宜 |
| 離子規(Ion gauge) | 游離電流 | 10⁻¹⁰ – 10⁻³ Torr | 量 base pressure |

**關鍵**:Baratron 讀值不受氣體種類影響,所以製程壓力一律用它。Pirani 讀 Ar 和讀 He 會差好幾倍,只能當粗略指示。

## 2.2 製程氣體選用學 ★(4.0 h)

> **本站最重要的一章。** 學員最常問的問題就是「為什麼這道製程要用這支氣體」,這一章要把它徹底講清楚。

### 學習目標
- 說出七大氣體家族各自的角色與典型應用
- 用 **F/C 比** 解釋氟碳氣體從蝕刻模式到沉積模式的轉換
- 針對指定材料組合,提出合理的氣體配方並說明每支氣體的作用
- 判斷氣體的危害等級與相容材質

### 2.2.1 選氣體的四個問題

任何配方設計都在回答這四題:

1. **要移除/沉積的材料是什麼?** → 決定主蝕刻劑(產物必須揮發)
2. **不能動到的材料是什麼?** → 決定選擇比策略(通常靠鈍化)
3. **要什麼樣的 profile?** → 決定鈍化劑與離子轟擊比重
4. **有什麼限制?** → 損傷、殘留、安全、成本、環保

**揮發性是第一原則**。蝕刻的本質是「把固體變成能被抽走的氣體」。若產物不揮發,它就沉積在原地,蝕刻停止。

| 材料 | 蝕刻劑 | 產物 | 沸點 | 可行? |
|---|---|---|---|---|
| Si | F | SiF₄ | −86 °C | ✅ |
| Si | Cl | SiCl₄ | 57 °C | ✅ |
| SiO₂ | F(+ 離子) | SiF₄ + CO/CO₂ | 低 | ✅ |
| Al | Cl | AlCl₃ | 178 °C(昇華) | ✅ |
| **Al** | **F** | **AlF₃** | **1291 °C** | **❌ 完全不行** |
| Cu | Cl | CuCl₂ | 993 °C | ❌ 需高溫或 IBE |

**這張表解釋了整個金屬蝕刻的歷史**:Al 只能用氯系;Cu 沒有揮發性鹵化物,所以業界改走**大馬士革製程(鑲嵌 + CMP)**,而不是蝕刻。

### 2.2.2 七大氣體家族

#### (1) 惰性氣體 — 物理轟擊與稀釋

| 氣體 | 質量 | 角色 |
|---|---|---|
| **He** | 4 | 稀釋、熱傳(背吹)、穩定電漿、抑制 arcing |
| **Ar** | 40 | **主力物理轟擊源**、稀釋、穩定電漿、OES actinometry 內標 |
| Kr / Xe | 84 / 131 | 重離子,高濺鍍產率,特殊應用 |

**Ar 的三重身分**:
1. 物理濺鍍(打斷鍵、移除鈍化層、促進離子輔助反應)
2. 稀釋劑(調整反應氣體分壓而不改總壓)
3. 電漿穩定劑(游離能適中,容易維持放電)

**He 背吹(backside He)不是製程氣體**:它走晶圓背面,在 ESC 與晶圓之間導熱。壓力典型 5–20 Torr。**He 洩漏率是機台健康的核心指標** —— 洩漏代表夾持不良,晶圓溫度失控,製程立刻飄。

#### (2) 氟碳系(Fluorocarbon)— 介電質蝕刻的核心

| 氣體 | F/C 比 | 主要用途 |
|---|---|---|
| CF₄ | 4.0 | 通用蝕刻、Si/SiO₂/SiN、腔體清潔 |
| CHF₃ | 3.0 | SiO₂ 蝕刻,中度聚合 |
| CH₂F₂ | 2.0 | SiN spacer,高聚合、高選擇比 |
| CH₃F | 1.0 | 極高聚合,SiN 對 Si 高選擇比 |
| C₄F₈ | 2.0 | **HAR 接觸孔蝕刻主力**、Bosch 鈍化步 |
| C₄F₆ | 1.5 | 更高聚合,先進節點 HAR |
| C₅F₈ | 1.6 | HAR |

**F/C 比是這一節的核心概念**:

```
高 F/C(CF₄ 系) ←─────────────────→ 低 F/C(C₄F₆ 系)
   蝕刻模式                              沉積模式
   F 自由基多                            CFx 聚合物多
   等向性強                              側壁鈍化強
   選擇比低                              選擇比高
```

**加 O₂ 會提高有效 F/C**(O 消耗 C 形成 CO/CO₂,釋放更多 F)
**加 H₂ 會降低有效 F/C**(H 消耗 F 形成 HF)

這兩句話是介電質蝕刻工程師的日常工具。

**離子輔助聚合物移除機制** —— 為什麼 SiO₂ 對 Si 有選擇比:

- 聚合物在所有表面沉積
- 在 SiO₂ 表面:離子轟擊 + 氧化物本身的氧 → 消耗聚合物 → 蝕刻繼續
- 在 Si 表面:無氧可消耗聚合物 → 聚合物越積越厚 → 蝕刻停止
- 在**側壁**:無離子轟擊 → 聚合物保留 → **側壁受保護 → 異向性**

**這一段是整個電漿蝕刻最精妙的設計**,值得單獨一個互動元件(A10)。

#### (3) 其他氟系

| 氣體 | 特性 |
|---|---|
| **SF₆** | F 產率極高、無碳(不聚合)→ **等向性強**;深矽蝕刻、快速 Si 移除 |
| **NF₃** | F 產率最高、無碳、易解離 → **遠端電漿腔體清潔標準** |
| F₂ | 直接提供 F,不需解離,但劇毒且腐蝕 |

**環保註記**:CF₄、C₂F₆、SF₆、NF₃ 都是強效溫室氣體(GWP:SF₆ ≈ 23,500、CF₄ ≈ 6,630、NF₃ ≈ 16,100)。NF₃ 之所以取代 C₂F₆ 做腔體清潔,除了解離效率高,也因為它在遠端電漿中幾乎完全分解,**逃逸率遠低於 C₂F₆**。這是 L4 4.6 的伏筆。

#### (4) 氯 / 溴系 — 導體蝕刻

| 氣體 | 用途 |
|---|---|
| **Cl₂** | Poly-Si、Al、W 主蝕刻劑;蝕刻率高,對 SiO₂ 選擇比佳 |
| **HBr** | Poly-Si 高選擇比與異向性主力;形成 SiOBr 側壁鈍化 |
| **BCl₃** | Al 蝕刻不可或缺 —— **清除 Al 表面的原生 Al₂O₃**(B 抓氧);也提供 Cl |
| SiCl₄ | 特殊材料、鈍化調整 |

**Poly gate 蝕刻的 Cl₂/HBr/O₂ 三重奏**:
- Cl₂:提供蝕刻率
- HBr:提供對 gate oxide 的選擇比與異向性
- O₂:與 Si、Br 形成 SiOBr 鈍化側壁

**安全提醒**:Cl₂、HBr、BCl₃ 皆為劇毒兼強腐蝕。管路必須乾燥 —— BCl₃ 遇水生成 HCl,腐蝕管路並產生微粒。**晶圓出腔後的後處理(去離子水沖洗 / H₂O 電漿)是防止 Al 腐蝕的必要步驟**,殘留的 Cl 遇到大氣濕氣會持續腐蝕 Al 線路,幾小時內就能吃斷。

#### (5) 氧化性氣體

| 氣體 | 用途 |
|---|---|
| **O₂** | 光阻灰化主力;氟碳製程中調 F/C;側壁鈍化(SiOBr/SiOCl);PECVD 氧化劑 |
| N₂O | PECVD SiO₂ 溫和氧化劑 |
| CO₂ / CO | 先進 HAR 蝕刻中調控聚合物與側壁 |

**O₂ 在蝕刻中的雙面性** —— 這是最容易搞混的地方:
- 加少量 O₂ → 清除聚合物、釋放 F → **蝕刻率上升**
- 加過量 O₂ → 表面氧化 + 稀釋 → **蝕刻率下降**
- 存在一個**最佳點**,這是經典的 DOE 題目

#### (6) 氮化 / 還原 / 前驅物

| 氣體 | 用途 | 危害 |
|---|---|---|
| N₂ | 稀釋、PECVD SiN、表面氮化、腔體 purge | 惰性 |
| **NH₃** | PECVD SiN 氮源、表面處理 | 毒性、腐蝕 |
| **H₂** | 降 F/C、還原、HAR 蝕刻改善 profile | **爆炸性** |
| **SiH₄** | PECVD Si 源 | **自燃(pyrophoric)** — 最高等級管制 |
| TEOS | PECVD SiO₂ 源(液態源,需汽化) | 低毒 |
| **WF₆** | W CVD | 劇毒、腐蝕 |

#### (7) 特殊與新興

CH₄(有機金屬蝕刻)、COS、SO₂(先進鈍化)、稀釋 F₂ 混氣。

## 2.3 電漿化學基礎(2.5 h)

### 學習目標
- 解釋 EEDF 如何決定各種反應的速率
- 說明為什麼「調功率」與「調壓力」對自由基密度的影響方向不同
- 區分氣相反應與表面反應的角色

### 2.3.1 速率係數

```
k = ⟨σ(E) · v(E)⟩ = ∫ σ(E) v(E) f(E) dE
```

反應速率 = k · n_e · n_gas

**關鍵洞察**:k 是 σ(E) 與 EEDF f(E) 的重疊積分。σ 有閾值,f 的高能端呈指數衰減,所以**兩者的重疊區在高能尾巴**。

**推論**:T_e 只要小幅上升,游離速率就大幅上升。這是電漿「自我調節」的機制 —— 電漿會自動把 T_e 穩定在一個窄範圍(2–5 eV),因為稍高就損失太快,稍低就維持不住。

**工程師直覺**:所以你幾乎無法用旋鈕直接調 T_e。T_e 主要由**氣體種類 × 壓力 × 腔體尺寸**決定(粒子平衡),而不是功率。**功率主要調 n_e,不調 T_e。** 這是 2.6 因果鏈的重要基石。

### 2.3.2 EEDF:Maxwellian 不總是對的

| 分佈 | 形狀 | 何時出現 |
|---|---|---|
| **Maxwellian** | f ∝ exp(−E/T_e) | 高密度、電子-電子碰撞頻繁(ICP 高功率) |
| **Druyvesteyn** | f ∝ exp(−(E/E₀)²) | 低密度、彈性碰撞主導(低壓 CCP);**高能尾巴較少** |
| **雙溫(Bi-Maxwellian)** | 兩段斜率 | CCP 中隨機加熱產生高能電子束 |

**為什麼工程師要在乎**:同樣的 T_e,Druyvesteyn 分佈的高能電子數量遠少於 Maxwellian → 游離與解離速率差好幾倍。**當你用簡單模型算出來的自由基密度跟量測差很多,EEDF 形狀往往是原因。**

### 2.3.3 解離、自由基與產物

以 CF₄ 為例的解離鏈:

```
e + CF₄ → e + CF₃ + F           (主要)
e + CF₄ → 2e + CF₃⁺ + F         (解離游離)
e + CF₃ → e + CF₂ + F
e + CF₂ → e + CF + F
```

**重點**:CF₄ 本身不蝕刻任何東西。真正蝕刻 Si 的是解離出來的 **F 原子**。CFx 則是**聚合物的前驅物**。

自由基密度的平衡:

```
生成率(電子碰撞解離) = 損失率(表面複合 + 抽走 + 氣相反應)
```

**表面損失係數(loss coefficient)γ** 是關鍵而常被忽略的參數。F 在石英表面的複合機率很低(長壽命),在金屬表面高。**這就是為什麼腔體內襯材質換了、製程就變了。**

### 2.3.4 氣相 vs 表面:反應在哪裡發生

| | 氣相 | 表面 |
|---|---|---|
| 主要反應 | 電子碰撞解離、游離 | 蝕刻、沉積、複合 |
| 決定因素 | n_e、T_e、EEDF | 自由基通量、離子能量、溫度 |
| 工程旋鈕 | 功率、壓力、氣體配比 | 溫度、bias、表面材質 |

**分開理解這兩層**,是診斷問題的關鍵。蝕刻率不對,先問:是自由基不夠(氣相問題,查功率/氣體/壓力),還是表面反應被抑制(表面問題,查溫度/鈍化/污染)?

### 2.3.5 表面反應動力學

- **黏著係數(sticking coefficient)s**:自由基撞到表面後留下的機率。s 小 → 能鑽進深孔 → **階梯覆蓋率好**;s 大 → 在開口就被吃掉 → 覆蓋率差。這是 3.4 PEALD 的核心
- **Arrhenius 溫度依賴**:R ∝ exp(−E_a/kT)。純化學蝕刻對溫度極敏感;離子輔助蝕刻對溫度不敏感(離子提供活化能)
- **Langmuir 吸附** 與飽和覆蓋 —— ALE 自限制的基礎(4.4)

**工程師直覺**:如果你的蝕刻率對晶座溫度很敏感,代表製程偏化學;如果幾乎不敏感,代表偏離子輔助。**這是一個免費的診斷實驗。**

## 2.4 鞘層物理進階(2.5 h)

### 學習目標
- 說出 Bohm 判準的意義與 u_B 的計算
- 用 Child–Langmuir 估鞘層厚度
- 解釋 IEDF 雙峰的成因,以及頻率、壓力、偏壓如何改變它

### 2.4.1 Bohm 判準:進鞘層前就要先加速

鞘層要穩定存在,離子必須以**至少 Bohm 速度**進入:

```
u_B = √( k T_e / M )
```

Ar⁺、T_e = 3 eV → u_B ≈ 2.7 × 10³ m/s。

**為什麼**:若離子進得太慢,鞘層內的離子密度會在深處堆積過高,無法維持單調的電位分佈 → 解不存在。

**推論:預鞘層(Presheath)必然存在**。bulk 到鞘層之間有一段弱電場區,把離子從熱速度加速到 u_B。預鞘層電位降約 T_e/2 ≈ 1.5 V,厚度是離子平均自由徑的量級(比鞘層厚很多)。

**離子流量(Bohm 通量)**:

```
Γ_i = 0.61 · n_e · u_B
```

**這是最有用的一條公式**。它讓你從 n_e 直接算出**打到晶圓的離子通量**:

n_e = 10¹⁰ cm⁻³、Ar、T_e = 3 eV → Γ_i ≈ 1.6 × 10¹⁶ cm⁻²s⁻¹

拿去跟 Si 表面原子密度(~7 × 10¹⁴ cm⁻²)比:**每秒約 20 個離子打到每個表面原子上**。這個數量級感讓「離子轟擊」變得具體。

### 2.4.2 Child–Langmuir:鞘層厚度

無碰撞、空間電荷限制的鞘層:

```
s = (√2 / 3) · λ_D · ( 2 V₀ / T_e )^(3/4)
```

**速算範例**:n_e = 10¹⁰ cm⁻³、T_e = 3 eV → λ_D ≈ 0.13 mm
V₀ = 500 V → (2×500/3)^0.75 = (333)^0.75 ≈ 78
→ s ≈ 0.47 × 0.13 × 78 ≈ **4.8 mm**

**兩個重要的比例關係**:

```
s ∝ V^(3/4)        偏壓加倍,鞘層厚 1.7 倍
s ∝ n_e^(−1/2)     密度加倍,鞘層薄 0.7 倍
```

**工程師直覺**:ICP 的 n_e 高 100 倍 → 鞘層薄 10 倍 → 離子穿越鞘層時碰撞次數少 10 倍 → **能量分佈窄、方向性好**。這就是導體蝕刻選 ICP 的物理原因。

### 2.4.3 自偏壓的完整圖像

回顧 L1 1.5.3,補上定量:

**面積比定律**:

```
V₁ / V₂ = ( A₂ / A₁ )^q
```

理想推導給 q = 4,實際量測 q ≈ 1–2.5(因為鞘層並非純 Child-Langmuir、有雜散電容、電漿並非均勻)。

**RF 電壓與 V_dc 的關係**:在不對稱系統中,V_dc ≈ −(V_rf 峰值 − V_p)。所以要提高離子能量,就是提高 RF 電壓振幅。

**雙頻 CCP 的解耦**:
- 高頻(60 / 100 MHz)→ 主要產生電漿,控 n_e
- 低頻(2 / 13.56 MHz)→ 主要在鞘層上產生電壓降,控離子能量

**但解耦不完美**:低頻功率提高也會增加電漿密度(鞘層加熱),高頻也會貢獻部分偏壓。**三頻機台就是為了把這個耦合再切開一層。**

### 2.4.4 IEDF:離子能量分佈,以及那個雙峰

打到晶圓的離子不是單一能量,而是一個分佈。形狀由**離子穿越鞘層的時間 τ_ion** 與 **RF 週期 τ_rf** 的比值決定。

**離子穿越時間**:

```
τ_ion ≈ 3s / √(2eV/M)
```

**三種情況**:

| 條件 | 行為 | IEDF |
|---|---|---|
| τ_ion ≪ τ_rf(低頻) | 離子瞬間穿越,感受瞬時電壓 | **寬的雙峰**,間距 = 全 RF 振幅 |
| τ_ion ≈ τ_rf | 部分平均 | 中等雙峰 |
| τ_ion ≫ τ_rf(高頻) | 離子只感受時間平均場 | **窄的單峰** |

**雙峰為什麼是雙峰**:RF 電壓在極值附近停留的時間最長(正弦波的駐點),所以離子最容易帶著極大值或極小值的能量抵達 → 分佈在兩端堆積。

**峰間距**:

```
ΔE ∝ 1 / (f · s · √M)
```

→ 頻率越低、鞘層越薄、離子越輕,雙峰分得越開。

**碰撞的影響**:壓力升高 → 鞘層內發生電荷交換 → 產生大量**低能離子** → IEDF 出現長長的低能尾巴。這些低能離子沒有足夠能量做離子輔助蝕刻,只會增加等向性成分。

**為什麼工程師要在乎 IEDF**:
- 選擇比取決於「有多少離子的能量落在 A 材料的閾值以上、B 材料的閾值以下」
- **只看平均能量會誤判**。兩個平均能量相同但分佈不同的製程,選擇比可能差兩倍
- 先進製程用**脈衝偏壓**或**方波偏壓(tailored waveform)** 刻意把 IEDF 壓成單能量峰,這是 L4 4.4 的主題

## 2.5 電漿源與功率耦合(3.0 h)

### 學習目標
- 對比 CCP / ICP / ECR / Remote 的原理與適用場合
- 解釋 E-mode 到 H-mode 的跳變
- 說明匹配網路在做什麼、反射功率高時往哪裡查

### 2.5.1 CCP:電容耦合

**結構**:兩片平行板電極,RF 經耦合電容加在其中一片。

**功率如何進入電子**:
1. **歐姆加熱(Ohmic / collisional)**:電子在振盪電場中碰撞,把有序振盪能轉成熱能。**高壓下主導**
2. **隨機加熱(Stochastic / collisionless)**:振盪的鞘層邊界像活塞一樣「拍打」電子,把能量傳給它們。**低壓下主導**

**隨機加熱是低壓 CCP 能維持電漿的關鍵**。這也是為什麼高頻(60/100 MHz)CCP 效率高 —— 鞘層振盪更快,拍打更有效。

**特性**:
- n_e 低(10⁹–10¹⁰),T_e 中等
- 離子能量高(V_dc 可到數百伏至 kV)
- 結構簡單、耐用、易放大
- **能量與密度耦合**(單頻時無法獨立調)

**主戰場**:介電質蝕刻(需要高離子能量打斷 Si–O 鍵)、PECVD。

**多頻演進**:
```
單頻 13.56 MHz  →  雙頻 (60 + 2 MHz)  →  三頻 (100 + 13.56 + 2 MHz)
```
每增一頻,就多切開一層耦合。

### 2.5.2 ICP:電感耦合

**結構**:平面渦捲或圓柱形線圈,經介電質窗(石英/氧化鋁)把 RF 磁場送入腔體。變化磁場感應出**方位角方向的電場**,加速電子繞圈。

**特性**:
- n_e 高(10¹¹–10¹²),鞘層薄
- Source power 控密度、Bias power 獨立控離子能量 → **良好解耦**
- 介電質窗會被蝕刻/沉積,是消耗件與微粒來源

**主戰場**:導體蝕刻(poly、金屬)—— 需要高自由基通量 + 可獨立調的低離子能量。

**E-mode → H-mode 跳變**(重要現場現象):

| 模式 | 耦合 | 密度 | 外觀 |
|---|---|---|---|
| **E-mode(容性)** | 線圈的**電壓**經雜散電容耦合 | 低(10⁹) | 暗淡 |
| **H-mode(感性)** | 線圈的**電流**經磁場耦合 | 高(10¹¹) | 明亮 |

功率上升到某個閾值,電漿**突然**從 E 跳到 H,密度躍升一到兩個數量級。而且有**遲滯(hysteresis)** —— 下降時的跳回點比上升時的跳出點低。

**現場意義**:
- 若製程點太靠近跳變閾值,**電漿會在兩個模式間反覆跳動**,製程完全不穩
- Recipe 的第一步常刻意用高功率確保進 H-mode,再降到製程功率(靠遲滯留在 H-mode)
- **法拉第屏蔽(Faraday shield)** 用來抑制容性耦合,減少窗口濺鍍與模式跳變

### 2.5.3 ECR 與微波源

**ECR**:在 875 Gauss 磁場下,電子迴旋頻率恰好等於 2.45 GHz 微波頻率 → **共振吸能**。

- 極高密度(10¹²),極低壓(0.1–1 mTorr)可運作
- T_e 低 → 損傷小
- 磁場系統複雜、成本高、均勻度難做大

**表面波電漿 / RLSA**:微波經天線在介電質板下形成表面波,產生大面積、極低 T_e 的高密度電漿。低損傷應用(如 low-k、有機膜)。

### 2.5.4 遠端與下游電漿

**Remote plasma**:電漿產生在腔體外的獨立源(常為微波或 RF ICP),只有**中性自由基**流進製程腔。離子與電子在傳輸途中複合殆盡。

**應用**:
- **NF₃ 遠端腔體清潔** —— 業界標準。高 F 產率、無離子轟擊 → 不傷腔體零件
- **無損傷光阻灰化** —— 沒有離子,就沒有電漿誘發損傷與充電
- 表面處理

**代價**:沒有方向性(純化學,等向性),不能做圖形定義。

### 2.5.5 阻抗匹配:反射功率的物理

RF 源與傳輸線設計為 50 Ω。電漿的阻抗**不是** 50 Ω,而且隨壓力、功率、氣體種類、腔體狀態動態變化(典型 1–20 Ω,含電容性虛部)。

**匹配網路(L 型)**:兩個可變真空電容 —— `C_tune`(調虛部)、`C_load`(調實部),把電漿阻抗轉換成 50 Ω。

**反射係數與駐波比**:

```
Γ = (Z_L − 50) / (Z_L + 50)
P_reflected = |Γ|² · P_forward
```

**現場診斷表**(高價值內容):

| 現象 | 可能原因 |
|---|---|
| 反射功率持續偏高、電容位置貼到極限 | 電漿阻抗跑出匹配範圍;檢查壓力/氣體/腔體結垢 |
| 匹配電容位置與 golden 差很多 | **腔體狀態改變的敏感指標**,應納入 chamber matching 指紋 |
| 匹配震盪不收斂 | 電漿本身不穩(E/H 跳變、電負性振盪) |
| 點火瞬間反射衝高 | 正常(無電漿時阻抗完全不匹配),但過久代表點火困難 |
| 反射功率突然尖峰 | Arcing |

**工程師直覺**:**匹配電容位置是免費的電漿診斷儀。** 它每天都在告訴你腔體的阻抗有沒有變,而大多數人只看有沒有報警。把 C_tune / C_load 位置納入 SPC,能提早幾天發現腔體異常。

## 2.6 參數因果鏈 ★(2.0 h)

> **本階的收束模組。** 前五章的知識在這裡被組裝成工程師每天要用的心智模型。

### 學習目標
- 對五大旋鈕中的任一個,說出它影響的完整因果鏈
- 預測調整後的主要效果與副作用
- 用 trade-off 矩陣判斷該動哪個旋鈕

### 2.6.1 五大旋鈕

| 旋鈕 | 直接影響 | 典型範圍 |
|---|---|---|
| **壓力** | n_gas、λ、鞘層碰撞、τ | 5–100 mTorr |
| **Source power** | n_e、自由基密度 | 200–2000 W |
| **Bias power** | 離子能量、鞘層厚度 | 0–500 W |
| **氣體流量與配比** | 化學組成、τ、F/C | 10–500 sccm |
| **溫度**(晶座/腔壁/噴淋頭) | 表面反應速率、鈍化厚度、產物再沉積 | 20–80 °C |

第六個常被忽略的旋鈕:**Gap(電極間距)** —— 影響鞘層佔比、氣體停留與均勻度。

### 2.6.2 完整因果鏈:壓力

```
壓力 ↑
 ├─→ n_gas ↑ → 自由基密度 ↑ ─────────→ 化學蝕刻率 ↑
 ├─→ λ ↓ → 鞘層內碰撞 ↑ → IEDF 低能尾巴 ↑ → 方向性 ↓ → undercut/bowing
 ├─→ λ ↓ → 電子平均能量 ↓ → T_e ↓ → 解離效率 ↓ (反向作用)
 ├─→ τ ↑ → 產物滯留 ↑ → 再沉積 ↑ → 聚合物殘留
 └─→ 電漿趨向侷限於中心 → 均勻度改變
```

**淨效果不是單向的** —— 這正是為什麼壓力常有最佳點,而不是越低越好或越高越好。

### 2.6.3 完整因果鏈:Source power

```
Source power ↑
 ├─→ n_e ↑ → 離子通量 ↑ ────→ 蝕刻率 ↑
 ├─→ n_e ↑ → 自由基密度 ↑ ──→ 蝕刻率 ↑
 ├─→ T_e 幾乎不變(由粒子平衡鎖定)
 ├─→ 鞘層變薄 (s ∝ n_e^−1/2) → 方向性略改善
 ├─→ 解離度 ↑ → 高 F/C(對氟碳氣體)→ 聚合減少 → 選擇比 ↓
 └─→ 熱負荷 ↑ → 腔壁/晶圓溫度 ↑ → 二次效應
```

**工程師直覺**:「加功率」的第一效果是**加自由基**,不是加離子能量。想加能量請動 bias。

### 2.6.4 完整因果鏈:Bias power

```
Bias power ↑
 ├─→ V_dc ↑ → 離子能量 ↑ ──→ 物理濺鍍 ↑ → 蝕刻率 ↑
 ├─→ 離子能量 ↑ → 對光阻/遮罩濺鍍 ↑ → **選擇比 ↓**
 ├─→ 離子能量 ↑ → 鈍化層被打穿 → 側壁保護 ↓ → bowing 風險
 ├─→ 鞘層變厚 (s ∝ V^3/4) → 鞘層內碰撞次數 ↑ → 方向性略降(高壓時)
 ├─→ 深孔底部帶電效應 → notching / twisting 風險 ↑
 └─→ 電漿誘發損傷 ↑
```

**Bias 是最危險的旋鈕**:提升蝕刻率最快,但幾乎所有副作用都跟著來。

### 2.6.5 Trade-off 矩陣

主線圖表:五個旋鈕 × 七個結果指標(蝕刻率、選擇比、異向性、均勻度、殘留、損傷、產能),每格標 ↑ / ↓ / ~ / 依情況。

| 旋鈕 ↑ | 蝕刻率 | 選擇比 | 異向性 | 均勻度 | 殘留 | 損傷 |
|---|---|---|---|---|---|---|
| 壓力 | ↑ | ↑ | **↓** | 依情況 | ↑ | ↓ |
| Source power | ↑ | ↓ | ~ | 依情況 | ↓ | ↑ |
| Bias power | ↑ | **↓** | ↑ 後 ↓ | ~ | ↓ | **↑** |
| 聚合性氣體比 | ↓ | **↑** | ↑ | ~ | ↑ | ~ |
| O₂ 比例 | 有最佳點 | 依材料 | ↑ | ~ | ↓ | ~ |
| 溫度 | ↑ | ↓ | ↓ | 依情況 | ↓ | ~ |

### 2.6.6 診斷心法:三個問題

當製程結果不對時,依序問:

1. **是氣相還是表面問題?**(自由基不夠 vs 表面被抑制)
2. **是通量問題還是能量問題?**(調 source vs 調 bias)
3. **是製程問題還是腔體問題?**(recipe 沒動卻飄了 → 查腔體:匹配位置、He 洩漏、閥位、OES 基線)
