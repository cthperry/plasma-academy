## 1.1 物質第四態(1.0 h)

### 學習目標
- 說出電漿與一般氣體的三個本質差異
- 解釋什麼是「弱游離電漿」,以及製程電漿的游離度為何低到不可思議
- 判斷一團帶電粒子是否夠格被稱為「電漿」

### 1.1.1 從點火那一刻說起

開場不從定義開始,而從現場畫面開始:腔體抽真空 → 通氣 → RF on → **紫色的光亮起來**。這一秒鐘發生了什麼?

拆解三件事:電子被電場加速 → 撞掉中性分子的束縛電子 → 產生更多電子(連鎖)。同時,被撞到激發態的分子掉回基態時放出光子 —— 那就是我們看到的輝光。

**工程師直覺**:輝光的顏色是氣體的身分證。Ar 是紫粉色,O₂ 偏白藍,N₂ 偏橘紫,CF₄ 系偏藍白。老師傅隔著 viewport 看顏色就知道氣體有沒有切錯,這不是玄學,是 L4 OES 的肉眼版。

### 1.1.2 四態的排序

固 → 液 → 氣 → 電漿,每一次相變都在對抗某種束縛能:

| 相變 | 打斷什麼 | 典型能量尺度 |
|---|---|---|
| 熔化 | 晶格位置束縛 | ~0.01–0.1 eV |
| 汽化 | 分子間吸引力 | ~0.1–0.5 eV |
| **游離** | **原子核對電子的束縛** | **~10–25 eV** |

Ar 的第一游離能 15.76 eV、O₂ 12.07 eV、N₂ 15.58 eV、CF₄ 約 16 eV。這些數字之後會反覆出現。

**常見誤解**:「電漿 = 很熱的氣體」。
**正解**:製程電漿的氣體溫度常常只有 50–150 °C(手摸腔壁不會燙傷)。熱的只有電子。詳見 1.2。

### 1.1.3 游離度:製程電漿有多「弱」

游離度定義:

```
α = n_i / (n_i + n_n)
```

- n_i:離子密度 · n_n:中性粒子密度

| 電漿種類 | 游離度 α |
|---|---|
| 太陽核心(完全游離) | ≈ 1 |
| 聚變電漿 | ≈ 1 |
| **CCP 蝕刻電漿** | **10⁻⁶ ~ 10⁻⁴** |
| **ICP / 高密度電漿** | **10⁻⁴ ~ 10⁻²** |
| 日光燈 | ~10⁻⁵ |

**工程師直覺**:在 CCP 腔體裡,每一百萬個粒子只有一個是離子。所以腔體裡**絕大多數的化學反應是中性自由基做的**,不是離子。離子的角色不是「量」,是「方向性」—— 這一句話會貫穿整個 L3。

### 1.1.4 準中性(Quasi-neutrality)

在電漿主體(bulk)裡,n_e ≈ n_i。不是巧合,是靜電力強制的結果:只要有一點點電荷分離,產生的電場就大到立刻把它拉回來。

**數量級演示**(公式卡):若一個 1 cm³ 的區域裡電子比離子少 0.1%,n_e = 10¹⁰ cm⁻³,算出的電位差會達到數十萬伏特。自然界不允許,所以電漿自己維持中性。

但**鞘層裡不中性** —— 這是 1.5 的主題,也是整個電漿製程的關鍵。

### 1.1.5 三個判準:什麼才算電漿

一團帶電粒子要被稱為電漿,必須同時滿足:

| 判準 | 意義 |
|---|---|
| λ_D ≪ L | Debye 長度遠小於容器尺寸(否則「集體行為」談不上) |
| N_D ≫ 1 | Debye 球內粒子數遠大於 1(否則是稀薄帶電粒子,不是流體) |
| ω_pe · τ > 1 | 電漿振盪比碰撞快(否則被中性碰撞主宰,行為像氣體) |

λ_D 與 ω_pe 在 1.2 定義。這裡先建立「電漿的定義是行為上的,不是成分上的」這個觀念。

## 1.2 電漿基本參數(1.5 h)

### 學習目標
- 說出 n_e、T_e、T_i 的典型數值與單位
- 解釋為什麼電子熱、離子冷
- 用 λ_D 判斷鞘層的量級

### 1.2.1 五個你必須記住的數字

| 參數 | 符號 | CCP 蝕刻典型值 | ICP 典型值 |
|---|---|---|---|
| 電子密度 | n_e | 10⁹ – 10¹⁰ cm⁻³ | 10¹¹ – 10¹² cm⁻³ |
| 電子溫度 | T_e | 2 – 5 eV | 2 – 4 eV |
| 離子溫度 | T_i | 0.03 – 0.05 eV | 0.03 – 0.05 eV |
| 氣體溫度 | T_g | 300 – 500 K | 400 – 800 K |
| 電漿電位 | V_p | 10 – 30 V | 15 – 25 V |

**先記住這張表**,後面所有推算都從這裡出發。

### 1.2.2 為什麼用 eV 當溫度單位

電漿界不用 K,用 eV。換算:

```
1 eV = 11,605 K ≈ 11,600 K
```

原因是實用:T_e = 3 eV 時,電子的典型動能就是 3 eV 級,直接跟游離能(Ar 15.76 eV)比較,一眼看出「只有分佈的高能尾巴撞得動」。

**公式卡**:嚴格說 T_e 是分佈參數,平均動能為 (3/2)kT_e。所以 T_e = 3 eV 對應平均動能 4.5 eV。教材全站統一以 T_e 表示溫度參數,不混用。

### 1.2.3 為什麼電子熱、離子冷:質量的暴政

RF 電場同時作用在電子與離子上,但兩者反應完全不同。

**理由一:加速能力**
同樣的電場,加速度 a = qE/m。Ar⁺ 的質量是電子的 **73,000 倍**,所以電子被甩得飛快,離子幾乎不動。

**理由二:跟不上頻率**
13.56 MHz 的電場一秒振盪 1,356 萬次。電子輕,能跟著場來回振盪並持續吸能;離子重,來不及反應,只感受到**時間平均**的場。

**理由三:碰撞交換能量效率極低**
電子撞中性分子時(彈性碰撞),能量傳遞比例約 2m_e/M ≈ 10⁻⁵。撞一萬次才交出 10% 的能量。所以電子吸了能量卻散不掉 → 溫度高。而離子與中性粒子質量相當,一撞就熱平衡 → T_i ≈ T_g。

**工程師直覺**:電漿是一個**熱非平衡**系統。這正是它在半導體製程中無可取代的原因 —— 我們得到了高能化學反應(電子提供),卻不必把晶圓加熱到幾千度。低溫、高活性,兩者兼得。

### 1.2.4 Debye 長度

```
λ_D = √(ε₀ k T_e / (n_e e²))
```

實用形式(工程單位):

```
λ_D [mm] ≈ 7.43 × √( T_e[eV] / n_e[cm⁻³] ) × 10³
```

| 條件 | λ_D |
|---|---|
| CCP:n_e = 10¹⁰ cm⁻³, T_e = 3 eV | ≈ 0.13 mm |
| ICP:n_e = 10¹² cm⁻³, T_e = 3 eV | ≈ 0.013 mm |

**物理意義**:電漿把任何外來電荷的電場「遮蔽」掉所需的距離。超過 λ_D,外來電荷幾乎感受不到。

**為什麼工程師要在乎**:鞘層厚度是 λ_D 的數倍到數十倍。ICP 的 λ_D 小一個數量級 → 鞘層薄 → 離子穿越鞘層時碰撞少 → 能量分佈窄、方向性好。這是高密度電漿源的一大優勢。

### 1.2.5 電漿頻率

```
ω_pe = √(n_e e² / (ε₀ m_e))
f_pe [Hz] ≈ 8,980 × √(n_e [cm⁻³])
```

n_e = 10¹⁰ cm⁻³ → f_pe ≈ 900 MHz。

**為什麼 13.56 MHz 是黃金頻率**:

```
f_pi (離子) ≈ 3 MHz  <  13.56 MHz  <  f_pe ≈ 900 MHz
```

在這個頻率,**電子跟得上、離子跟不上**。這正是我們要的:電子負責吸功率維持電漿,離子只感受直流平均場而被穩定加速。頻率選擇不是法規決定的(雖然 13.56 MHz 確實是 ISM 頻段),而是物理決定的。

## 1.3 碰撞與平均自由徑(1.5 h)

### 學習目標
- 由壓力推算平均自由徑
- 區分五種電子碰撞及其製程意義
- 在 Torr / mTorr / Pa 之間換算,理解 sccm

### 1.3.1 壓力單位與換算

| 單位 | 換算 |
|---|---|
| 1 Torr | 133.3 Pa |
| 1 mTorr | 0.1333 Pa |
| 1 atm | 760 Torr = 101,325 Pa |
| 1 mbar | 100 Pa = 0.75 Torr |

**典型製程壓力**

| 製程 | 壓力 |
|---|---|
| HAR 介電質蝕刻 | 5 – 50 mTorr |
| Poly gate 蝕刻 | 5 – 20 mTorr |
| PECVD | 1 – 10 Torr |
| PVD 濺鍍 | 1 – 10 mTorr |
| 光阻灰化 | 0.5 – 2 Torr |
| 大氣電漿處理 | 760 Torr |

**sccm 是什麼**:standard cubic centimeter per minute —— 標準狀態(0 °C, 1 atm)下每分鐘幾立方公分。它是**質量流量**不是體積流量,所以與腔體壓力無關。這是它好用的原因。

### 1.3.2 平均自由徑

```
λ = 1 / (n σ) = k T / (σ P)
```

實用近似(室溫、Ar):

```
λ [cm] ≈ 5 / P [mTorr]
```

| 壓力 | λ(Ar, 室溫) | 腔體尺度比較 |
|---|---|---|
| 1 mTorr | ≈ 5 cm | 與 gap 相當 → 幾乎無碰撞 |
| 10 mTorr | ≈ 5 mm | 穿越 3 cm gap 撞約 6 次 |
| 100 mTorr | ≈ 0.5 mm | 撞約 60 次 |
| 1 Torr | ≈ 50 µm | 撞約 600 次 |

**工程師直覺**:這一個數字決定了你的製程是「方向性的」還是「等向性的」。

- **低壓** → λ 大 → 離子穿越鞘層幾乎不碰撞 → 垂直入射 → **異向性蝕刻**
- **高壓** → λ 小 → 離子一路散射 → 入射角散開 → 方向性變差,但自由基多、蝕刻率高

「壓力調低 profile 會變直」這句現場老話,物理根源就在這裡。

### 1.3.3 碰撞截面不是常數

σ 隨電子能量變化,而且變化劇烈。要建立的關鍵圖像:

- **游離截面有閾值**:低於游離能完全為零,超過後上升,在 ~50–100 eV 達峰後下降
- **激發截面**閾值更低(數 eV),所以低 T_e 的電漿仍會發光,但不見得游離得動
- **動量轉移截面**在低能量可能出現 Ramsauer 極小(Ar、Kr 明顯)

### 1.3.4 五種電子碰撞與製程意義

| 碰撞 | 反應式範例 | 製程意義 |
|---|---|---|
| **彈性** | e + Ar → e + Ar | 幾乎不交換能量;決定電子遷移率 |
| **激發** | e + Ar → e + Ar* | 放光 → **OES 的來源**(L4) |
| **游離** | e + Ar → 2e + Ar⁺ | 維持電漿的命脈 |
| **解離** | e + CF₄ → e + CF₃ + F | **產生蝕刻自由基**,L3 主角 |
| **附著** | e + SF₆ → SF₆⁻ | 產生負離子;電負性氣體特有,影響甚大 |

再加上兩個沒有電子參與的:
- **複合**(recombination):e + Ar⁺ → Ar,主要發生在**器壁**而非氣相
- **電荷交換**(charge exchange):Ar⁺(快) + Ar(慢) → Ar(快) + Ar⁺(慢),鞘層裡造成 IEDF 低能尾巴

**常見誤解**:「電漿裡離子和電子一直在複合」。
**正解**:低壓電漿的氣相複合機率很低(三體碰撞需求),損失主要靠**擴散到器壁**再複合。所以**器壁狀態直接影響電漿密度** —— 這就是 seasoning 和 first wafer effect 的物理根源(L3 3.6)。

### 1.3.5 電負性氣體:負離子改寫規則

O₂、Cl₂、SF₆、NF₃、CF₄ 都是電負性氣體,會抓走電子形成負離子。後果:

- n_e 下降(電子被鎖進負離子)→ 相同功率下電漿更難維持
- 電漿要靠提高 T_e 補償 → 電負性電漿的 T_e 通常較高
- 負離子被鞘層電場擋住,**出不去、打不到晶圓**(但脈衝電漿可以放它們出來,L4 4.4)
- 電漿可能出現不穩定振盪(attachment-driven instability)

## 1.4 輝光放電與點火(1.5 h)

### 學習目標
- 說明電子雪崩如何導致崩潰
- 讀 Paschen 曲線,解釋為什麼太低壓與太高壓都點不著
- 認出 DC 輝光的分區並說出各區在做什麼

### 1.4.1 Townsend 雪崩

一個種子電子被電場加速 → 游離出第二個 → 兩個各自再游離 → 指數成長。

```
n(d) = n₀ · e^(αd)
```

α = 第一 Townsend 係數(每公分產生幾個電子離子對)。

**但光靠 α 不會自持**:雪崩衝到陽極就結束了。要持續,必須有機制補回種子電子 —— 這就是 **第二 Townsend 係數 γ**:離子撞擊陰極打出二次電子。

**自持條件(崩潰條件)**:

```
γ (e^(αd) − 1) = 1
```

**工程師直覺**:γ 依賴陰極材料。腔體零件換過、電極被鍍上一層聚合物之後,γ 變了,**點火電壓就變了**。「同一支 recipe 換了 PM 之後點不著」常常是這個原因。

### 1.4.2 Paschen 定律

把自持條件代入 α 的經驗式,得到崩潰電壓只依賴 **pd 乘積**:

```
V_b = (B · pd) / (ln(A · pd) − ln(ln(1 + 1/γ)))
```

**Paschen 曲線是 U 形的**,有一個最小值。

| Paschen 最小值 | p·d (Torr·cm) | V_min (V) |
|---|---|---|
| Ar | 0.9 | 137 |
| He | 4.0 | 156 |
| N₂ | 0.67 | 251 |
| Air | 0.57 | 327 |
| O₂ | 0.70 | 450 |

**兩支各自的物理**:

- **右支(pd 大 / 高壓)**:λ 太短,電子在兩次碰撞間累積不到游離能 → 需要更高電壓
- **左支(pd 小 / 低壓)**:λ 太長,電子還沒撞到任何分子就抵達陽極 → 碰撞次數不夠 → 需要更高電壓

**現場應用**:
1. 為什麼點火時要先「衝壓力」再降到製程壓力 —— 製程壓力常常落在左支,直接點不著
2. 為什麼腔體裡意外的窄縫(pd 小)或大空腔(pd 大)會出現異常放電
3. 為什麼真空管路裡有時會出現不該有的輝光 —— 那一段的 pd 剛好落在谷底

**安全提醒**:高壓區(如 RF 匹配盒內、氣體管路法蘭)若 pd 落在 Paschen 谷底附近,會導致寄生放電與電弧,是設備損壞與微粒的常見來源。

### 1.4.3 DC 輝光的分區

從陰極到陽極:

| 區域 | 特徵 | 在做什麼 |
|---|---|---|
| Aston 暗區 | 暗 | 二次電子剛出發,能量太低,激發不動 |
| 陰極輝光 | 亮 | 電子開始有能量,激發中性粒子 |
| Crookes 暗區(陰極暗區) | 暗 | **電位降幾乎全落在這裡**,電子能量過高、激發截面反而下降 |
| 負輝光 | **最亮** | 高能電子減速到激發截面峰值 → 大量發光 |
| Faraday 暗區 | 暗 | 電子能量耗盡 |
| 正柱區 | 均勻微亮 | 準中性、電場很小,日光燈的主體 |
| 陽極區 | — | 電子被收集 |

**關鍵對應**:RF 電漿中的 **鞘層 ≈ Crookes 暗區**,**bulk ≈ 負輝光/正柱區**。看到腔體裡電極表面附近有一層暗帶,那就是鞘層,厚度可以目視估計。

### 1.4.4 從 DC 到 RF:為什麼要用 RF

DC 放電有個致命問題:**絕緣體不能當電極**。介電質表面很快累積電荷,把電場屏蔽掉,放電熄滅。

而半導體製程要蝕刻的偏偏就有 SiO₂、SiN 這類絕緣膜,晶圓本身也常被絕緣層覆蓋。

RF 的解法:電場方向不斷反轉,一個半週累積的電荷在下半週被中和。**電容耦合(CCP)** 讓 RF 功率穿過介電質進入電漿,絕緣不再是問題。

## 1.5 鞘層入門(1.5 h)

### 學習目標
- 解釋鞘層為什麼一定會形成
- 區分電漿電位 V_p、浮動電位 V_f、自偏壓 V_dc
- 說明「離子方向性從何而來」

### 1.5.1 鞘層為什麼必然存在

思想實驗,四步:

1. **t = 0**:假設腔體裡電子與離子均勻分佈,器壁電中性
2. **電子先跑掉**:電子熱速度是離子的 √(M/m_e · T_e/T_i) 倍 —— Ar、T_e = 3 eV、T_i = 0.03 eV 時約 **2,700 倍**。器壁瞬間收到大量電子
3. **器壁帶負電**:相對於電漿變成負電位
4. **建立平衡**:負電位排斥後續電子、吸引離子,直到兩者流量相等 → 穩態

結果:器壁附近出現一層**電子被排空、離子過剩**的區域 —— 這就是**鞘層(Sheath)**。

**鞘層是電漿製程的一切**。沒有鞘層,離子就是四面八方亂飛的化學物種,做不出垂直的溝槽。

### 1.5.2 三個電位,不要搞混

| 電位 | 定義 | 典型值 |
|---|---|---|
| **電漿電位 V_p** | 電漿 bulk 相對於接地的電位 | +10 ~ +30 V |
| **浮動電位 V_f** | 絕緣或浮接表面自然達到的電位 | 比 V_p 低 10–20 V |
| **自偏壓 V_dc** | 加了 RF 的電極上出現的直流電位 | −50 ~ −1000 V |

**關鍵事實:V_p 永遠是正的。** 電漿相對於所有接觸到的表面都是正的,所以**所有表面都在被離子轟擊** —— 包含腔壁、噴淋頭、聚焦環。這就是零件消耗與微粒的根源。

**浮動電位公式卡**:

```
V_p − V_f = (kT_e / 2e) · ln( M / (2π m_e) )
```

對 Ar:V_p − V_f ≈ 4.7 × T_e。T_e = 3 eV → 約 14 V。

### 1.5.3 自偏壓:離子能量的旋鈕

在 CCP 中,RF 電極通常經由**耦合電容**接 RF 源。因為:

- 電子在 RF 正半週大量湧入電極
- 離子在負半週只能慢慢流入
- 電容不允許有淨直流電流

電極必須自行降到一個負的直流電位,讓一個週期內的電子與離子流量相等。這個電位就是 **V_dc(自偏壓)**。

**面積比效應(公式卡)**:

```
V₁ / V₂ = (A₂ / A₁)^q,q ≈ 1 ~ 2.5
```

小電極分到大電位。這解釋了為什麼:
- 晶圓所在的下電極(小)得到大的負偏壓 → 離子猛打晶圓
- 接地的腔壁(大)只有小電位 → 腔壁被打得輕 → 零件壽命長

**設計啟示**:腔體接地面積是刻意做大的。當接地面積因為結垢或零件消耗而改變,V_dc 會漂移,製程就飄了。

### 1.5.4 離子的方向性從何而來

完整的因果鏈,這是 L1 最重要的一段:

```
電子跑得比離子快
   ↓
表面帶負電,形成鞘層
   ↓
鞘層裡有很強的垂直電場(數百 V 落在 <1 mm)
   ↓
離子進入鞘層被垂直加速
   ↓
若鞘層內無碰撞(低壓),離子保持垂直
   ↓
垂直入射的高能離子轟擊晶圓
   ↓
異向性蝕刻(垂直側壁)
```

任何一環被破壞,方向性就壞掉:
- 壓力太高 → 鞘層內碰撞 → 入射角散開 → 側壁被咬(undercut)
- 表面充電 → 局部電場歪斜 → 離子偏折 → notching(L4 4.3)

### 1.5.5 鞘層厚度的量級

先給結論,推導留到 L2 2.4:

```
s ≈ λ_D × (V_sheath / T_e)^(3/4) × 常數
```

| 條件 | 鞘層厚度 |
|---|---|
| CCP,V_dc = −500 V,n_e = 10¹⁰ | ~2 – 5 mm |
| ICP,V_bias = −100 V,n_e = 10¹² | ~0.1 – 0.3 mm |

拿去跟 1.3 的 λ 對照:CCP 在 10 mTorr 時 λ ≈ 5 mm ≈ 鞘層厚度 → **鞘層內大約碰撞一次**,IEDF 會出現低能尾巴(L2 2.4)。

## 1.6 製程電漿地圖(1.0 h)

### 學習目標
- 說出六大類電漿製程各自的目的、氣體與參數窗
- 定位自己負責的製程在地圖上的位置

### 1.6.1 六大類應用

| 類別 | 目的 | 主要氣體 | 壓力 | 機台型式 |
|---|---|---|---|---|
| **電漿蝕刻** | 移除材料、定義圖形 | 氟系/氯系/溴系 + Ar/O₂ | 5–100 mTorr | CCP(介電質)、ICP(導體) |
| **PECVD** | 低溫沉積薄膜 | SiH₄, TEOS, NH₃, N₂O | 1–10 Torr | CCP 平行板 |
| **PVD 濺鍍** | 沉積金屬 | Ar(+ N₂/O₂ 反應式) | 1–10 mTorr | DC/RF magnetron |
| **光阻灰化** | 去除光阻 | O₂(+ N₂/H₂/CF₄) | 0.5–2 Torr | Downstream / microwave |
| **腔體清潔** | 去除腔內沉積 | NF₃, C₂F₆ | 1–5 Torr | Remote plasma |
| **表面處理** | 活化、除膠、親水化 | O₂, Ar, N₂, H₂ | 0.1–1 Torr | 多樣 |

### 1.6.2 為什麼壓力差這麼多

一句話總結各自的取捨:

- **蝕刻要方向性** → 低壓(λ 大、鞘層無碰撞)
- **沉積要覆蓋率與產率** → 高壓(自由基多、氣相反應充分)
- **濺鍍要靶材原子飛得到晶圓** → 低壓(λ 大,少散射)
- **灰化只要化學反應、不要方向性也不要損傷** → 高壓 + 下游(離子留在上游)

### 1.6.3 機台型式速覽

給每種型式一張結構示意 + 一句話定位:

- **CCP 平行板**:結構簡單、離子能量高、密度低。介電質蝕刻與 PECVD 主力
- **ICP / TCP**:線圈感應耦合,密度高、能量可獨立調(source/bias 解耦)。導體蝕刻主力
- **ECR / 微波**:高密度、低損傷,設備複雜
- **Downstream / Remote**:電漿產生在別處,只送自由基過來。灰化與清潔
- **Magnetron PVD**:磁場束縛電子提升游離率

### 1.6.4 讀一份真實 recipe

以一支 poly gate 蝕刻 recipe 作為壓軸練習,逐行拆解:

```
Step   Press  Src   Bias   Cl2   HBr   O2    He    EPD
BT      4mT   400W   80W    40    -     5     -    time
ME      8mT   500W  120W    20    80    8     -    OES
OE     40mT   400W   50W     -   100   10     -    time
```

逐欄問「為什麼」:
- 為什麼 BT(breakthrough)壓力最低、用 Cl₂?→ 打穿原生氧化層,要方向性與物理轟擊
- 為什麼 ME(main etch)加 HBr?→ 提升對氧化層選擇比、側壁鈍化
- 為什麼 OE(over etch)壓力升到 40 mT、bias 降到 50 W?→ 保護下方閘極氧化層,轉向化學蝕刻降低轟擊
- O₂ 在幹嘛?→ 與 Si 形成 SiOBr 側壁鈍化層

**這一節是 L1 的收束點**:所有前五節的概念在這裡合流。學員如果能講清楚這支 recipe,L1 就過了。
