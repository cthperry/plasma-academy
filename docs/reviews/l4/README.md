# L4 三道審閱

本目錄由三位具名責任者分別負責：技術審閱由診斷、控制、損傷、進階模型與量產專家執行，教學審閱由專家階目標學員執行，一致性審閱由撰稿統籌執行。封包建立不代表核准。

審閱前執行 `npm run check` 與 `npm run verify:ui`，固定待審 `reviewed_commit`。審閱者逐項記錄 `findings` 與 `evidence`；OES 分子帶來源仍 pending 時不得把來源審閱寫成完成。只有結論為通過時，才能把 `status` 改為 `approved`，並填妥姓名、角色、`reviewed_commit`、`approved_at`。
