# 外部專業核准交接表

更新日期：2026-08-09

本表只用於交接待辦，不是核准證據。請由實際責任者逐筆核對並將已簽核的個別證據檔提交到 `docs/reviews/evidence/`；不得以本表、供應商公開文件或候選文獻直接改寫核准狀態。

## 完成方式

1. 每筆廠區 SDS 核准建立 `docs/reviews/evidence/sds-<gasId>-local-approval.md`，記錄實際廠區、供應濃度、在地 SDS 版本、供氣/材料相容、abatement、程序版本、具名 EH&S 責任者與 RFC 3339 核准時間。
2. 每筆分子 OES 來源審閱建立 `docs/reviews/evidence/oes-<lineId>-source-review.md`，記錄採用來源、species、電子態/振動帶、air 或 vacuum wavelength、光譜解析度、積分窗口、重疊風險、具名光譜審閱者與 RFC 3339 審閱時間。
3. 證據檔進入 Git `HEAD` 後，才由具有資料維護權限者更新 `src/data/sds-evidence.js` 或 `src/data/spectra.js` 的狀態與 evidence 陣列。
4. 執行 `npm run check:reviews` 與 `npm run audit:roadmap -- --strict`。兩者都通過才代表核准資料完整。
