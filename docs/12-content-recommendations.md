## 2. 內容缺口(有證據、建議處理)

### 2.1 ⭐ 題型分佈與 docs/08 的規格不符 —— **L4 部分已完成**

> **狀態更新**:下列診斷是掃描當下的實測值。其中 **L4 已補到 50 %**
> (見本節末的「已執行」),並把 `check-quiz.mjs` 那條會永遠通過的相對式斷言
> 換成絕對判準。**L1–L3 與全站圖形判讀題仍未做**,診斷維持原樣。

`docs/08-assessment.md` 明列題型應包含「情境診斷題、參數推算題、輪廓判讀題」,
並說 L4 應有一半以上是情境分析與判讀(這也是 L4 門檻訂 80 % 的理由)。

**實測分佈**:

| 階段 | 題數 | 單選佔比 | 情境 + 圖形判讀佔比 |
|---|---|---|---|
| L1 | 54 | 69 % | **2 %** |
| L2 | 78 | 79 % | 6 % |
| L3 | 92 | 85 % | 8 % |
| L4 | 77 | 81 % | **10 %** |

全站 301 題裡:單選 239、計算 29、情境 18、複選 11、圖形判讀 3、排序 1。

**問題**:L4 的情境判讀只有 10 %,離「一半以上」差很遠 ——
**L4 的 80 % 門檻目前站不住腳**,因為它考的仍然以記憶型單選為主。
圖形判讀全站只有 3 題,而這個網站有 19 張缺陷剖面圖與 33 個互動元件可以出題。

**建議**(優先度最高):
1. L4 增補 25–30 題情境診斷題,把情境佔比拉到 40 % 以上。
   素材現成:`data/faults.js` 的五個故障情境、A26–A32 的實測結論。
2. 全站增補 15–20 題**圖形判讀題**,直接用 `data/defect-svg.js` 的 19 張剖面圖
   當題幹(「看到這個剖面,最可能的成因是什麼」)—— 這正是缺陷圖鑑的教學目的,
   而且 SVG 已經是現成資產,不必另外畫圖。
3. ⚠️ 增補時**四條反洩漏斷言一條都不能放寬**(選項長度命中率 < 25 %、
   選項不得含粗體、同章題幹相似度 < 0.32、同章 tags 不得完全相同)。
   歷史上七批擴充有三批在同一條上翻車,寫完**一定要先跑 `check-quiz`**。

#### ✅ 已執行:L4 情境題 10 % → 50 %

| | 之前 | 之後 |
|---|---|---|
| L4 題數 | 77 | 90(觸及 2.5–3 倍上限) |
| L4 情境 + 判讀 | 8 題(10 %) | **45 題(50 %)** |
| 守門斷言 | 相對式,L4 只有 10 % 時照樣綠 | `scenarioRate("4") >= 0.5` |

做法分兩批,兩批都不是只改 `type` 欄位:

- **新寫 13 題**(`L4-078`~`L4-090`),覆蓋 4.1–4.6,素材取自站內既有結論
  (例如 L4-078 直接用上 A26 這輪才做出來的偏壓相依鞘層電容分壓:
  探針 16 eV vs OES 3 eV,要學員判斷是探針缺補償而非 OES 內標選錯)。
- **改寫 24 題既有單選的題幹**,把「這個現象的原因是什麼」改成
  「給你這組數據與現場條件,你怎麼判斷」。選項本身多半不動 ——
  那些選項本來就是乾淨的主張句,問題出在題幹沒給情境。

⚠️ 過程中撞到兩次重複判準,都是**整題重寫**而不是放寬門檻:
`L4-089` 與既有 `L4-027` 相似度 0.36(兩題都在問「要角度分佈該用哪種模型」),
把 L4-089 換成計算成本與校準範圍的取捨情境;
另外刻意**避開**把 `L4-015`/`L4-035`/`L4-016`/`L4-065` 改成情境題,
因為它們與新寫的 `L4-084`/`L4-085`/`L4-086`/`L4-087` 同題材,改了必撞。

### 2.2 ⭐ 4.6 是唯一沒有互動元件的模組

25 個模組裡只有 4.6(量產、良率與安全)沒有任何互動元件。
它的內容是五個故障情境研討 + SPC/DOE + 氣體安全,已資料化為 `data/faults.js`
(21 項斷言守著交叉引用),但學員只能讀,不能操作。

**建議**:新增 **A34 故障診斷情境練習**(對應現有的 `faults.js`,不必新增資料):
給學員一組 FDC 訊號與量測值,讓他用「排除法」逐步收斂到根因 ——
這正是 4.6 章末強調的「會用一條線索排除三種可能的人不多」。
與 A21 缺陷診斷器的差別:A21 是「症狀 → 成因排序」,A34 是「多條線索 → 排除」。

### 2.3 術語表有 31 % 的條目從未在課文中出現

242 條術語裡有 **75 條**(31 %)在 25 章的正文裡完全找不到,
也就是說這些條目**永遠不會以 tooltip 的形式被學員看到**,只能靠翻術語表。

抽樣:非彈性碰撞、空間電荷限制、離子能量分佈函數、雙峰結構、離子角度分佈、
離子穿越時間、電子能量分佈函數、Druyvesteyn 分佈、毫托、標準立方公分每分、
道爾頓分壓定律、Pirani 真空計、基礎壓力、釋氣……

**判讀**:這 75 條分成兩類,處理方式不同 ——

- **(a) 課文其實有講,但用了不同的寫法**(例如課文寫「IEDF」、術語表收
  「離子能量分佈函數」;課文寫「mTorr」、術語表收「毫托」)。
  → 這類要補的是**別名(alias)**,不是課文。建議 `glossary.js` 增加
  `alias` 欄位,讓 tooltip 能同時掛在中文全名與英文縮寫上。
- **(b) 課文真的沒提到**(例如 Pirani 真空計、釋氣、道爾頓分壓定律
  —— 2.1 真空章的規格有列,但正文沒展開)。
  → 這類要補的是課文,而且集中在 2.1。

**建議**:先寫一支 `tools/check-glossary-coverage.mjs` 把 75 條分成 (a)/(b) 兩類,
再決定各自怎麼補。**不要盲目刪術語**,也不要為了讓數字好看硬塞進課文。

### 2.4 1.1 的篇幅明顯偏薄

章節正文字數:1.1「物質第四態」**4,567 字**,其餘 24 章都在 6,800–7,800 字以上。

1.1 是**全站第一章**,也是唯一一章要把「電漿是什麼」從零講起的。
篇幅最短反而不合理 —— 尤其它要承擔三判準(λ_D ≪ L、N_D ≫ 1、ωτ > 1)、
準中性、游離度三個概念。

**建議**:補到 6,500 字以上,重點補「電漿三判準」的物理意義
(目前只列了式子)。可連動 A02 Debye 遮蔽互動出圖形判讀題(見 2.1)。

## 3. 工程缺口(非內容,但影響內容可信度)

### 3.1 ⭐ A18 輪廓模擬器:三種形狀仍未收斂(成因已定位)

`npm run check:shapes` 目前 **21/32**,八種 profile 有三種做不出來
(undercut / bowing / microtrench)。**這一輪找到了真正的成因**,
而且證明先前 docs/11 寫的診斷是錯的 —— 完整記錄見 docs/11 的
「四項未達成驗收條件的收斂」。

摘要:`ionFluxVec()` 的射線從固體格本身往上追,側壁格正上方就是側壁的延續,
所以側壁的離子通量**恆為 0**,連帶讓整段鏡面反射計算失效。
引擎已支援修正(參數 `wallFlux`),打開後 microtrench 立刻長得出來
(µtr −2 → +8),但**預設關閉**,因為八組預設需要一併重新校準。

**建議**(這是四項裡最接近完成的一項):
開 `wallFlux` → 用 `tools/shapes-search.mjs` 重搜 `defects.js` 的八組
profile 參數(尤其 `reflect`)→ 目標 32/32。
⚠️ 已確認**行不通**的路:再乘幾何投影 cos θ 壓側壁(會與 `angularYield()`
重複計算,實測八種形狀一個都做不出來)。

**為什麼這件事影響內容**:3.3 缺陷圖鑑的「診斷區分」要靠 A18 驗證,
模擬器做不出來的形狀,圖鑑的說法就少一層證據。

### 3.2 A20 反向 ARDE / A23 HDP 填溝極限

兩項都維持未達成,診斷見 docs/11。A20 這一輪把診斷從定性升級成定量
(需要 `polyStrength > 27.8` 但又必須 < 12.5,兩個條件沒有交集),
結論是**需要空間解析的聚合物收支**,不是 0-D 傳輸模型的範圍。

**建議**:這兩項的投入產出比低於 3.1,建議排在 A18 之後。
課文與 check 腳本都已如實標註,**不要為了讓測試變綠而放寬斷言**。
